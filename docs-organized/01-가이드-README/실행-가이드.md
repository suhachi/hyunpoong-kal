# 🚀 rebrand.sh 스크립트 실행 가이드 (Windows)

## 필수 준비사항

1. **Git Bash 설치 확인**
   - 시작 메뉴에서 "Git Bash" 검색
   - 없으면: https://git-scm.com/download/win 에서 설치

## 단계별 실행 방법

### Step 1: Git Bash 열기

프로젝트 폴더(`hyunpoong-kal`)에서:
- 우클릭 → **"Git Bash Here"** 선택
- 또는 시작 메뉴에서 "Git Bash" 실행 후:
  ```bash
  cd /d/projectsing/hyun-poong/hyunpoong-kal
  ```

### Step 2: 스크립트 실행 권한 부여 (최초 1회만)

```bash
chmod +x rebrand-scripts/rebrand.sh
```

### Step 3: 현재 상태 확인

```bash
# 현재 가게명 확인
grep "name:" src/config/env.ts

# 현재 컬러 확인
grep "primary:\|secondary:\|accent:" src/constants/colors.ts
```

### Step 4: 스크립트 실행

**기본 형식:**
```bash
./rebrand-scripts/rebrand.sh "가게명" "#Primary" "#Secondary" "#Accent"
```

**연습 예시 (부산갈비집):**
```bash
./rebrand-scripts/rebrand.sh "부산갈비집" "#8B4513" "#FF6B35" "#D4AF37"
```

**다른 예시들:**
```bash
# 치킨집
./rebrand-scripts/rebrand.sh "황금치킨" "#FF6B35" "#F7B733" "#C0392B"

# 피자집
./rebrand-scripts/rebrand.sh "나폴리피자" "#E74C3C" "#F39C12" "#27AE60"

# 카페
./rebrand-scripts/rebrand.sh "브루잉커피" "#6F4E37" "#D4AF37" "#8B7355"
```

### Step 5: 확인 메시지

스크립트가 실행되면:
1. 변경할 정보를 보여줍니다
2. "계속하시겠습니까? (y/N):" 메시지가 나옵니다
3. `y` 입력 후 Enter

### Step 6: 결과 확인

스크립트가 완료되면:
- ✅ 백업 폴더 생성됨: `backup-YYYYMMDD-HHMMSS/`
- ✅ 6개 파일 자동 변경됨
- ✅ 변경 사항 검증 완료

### Step 7: 변경 사항 확인

```bash
# 변경된 가게명 확인
grep "name:" src/config/env.ts

# 변경된 컬러 확인
grep "primary:\|secondary:\|accent:" src/constants/colors.ts
```

### Step 8: 개발 서버 실행하여 확인

```bash
npm run dev
```

브라우저에서 http://localhost:5173 열어서 확인

### Step 9: 원래대로 복원 (필요시)

백업 폴더에서 복원:
```bash
# 백업 폴더 이름 확인
ls backup-*

# 복원 (예시)
cp backup-20241108-120000/env.ts src/config/env.ts
cp backup-20241108-120000/colors.ts src/constants/colors.ts
cp backup-20241108-120000/design-tokens.ts src/constants/design-tokens.ts
cp backup-20241108-120000/globals.css src/styles/globals.css
cp backup-20241108-120000/design-lock.css src/styles/design-lock.css
cp backup-20241108-120000/index.html .
```

## 문제 해결

### 문제 1: "Permission denied"
```bash
chmod +x rebrand-scripts/rebrand.sh
```

### 문제 2: "No such file or directory"
- 프로젝트 루트(`hyunpoong-kal`)에서 실행했는지 확인
- `pwd` 명령어로 현재 위치 확인

### 문제 3: "sed: command not found"
- Git Bash를 사용하고 있는지 확인
- PowerShell이 아닌 Git Bash에서 실행

### 문제 4: 컬러 형식 오류
- 컬러는 반드시 `#`으로 시작하는 6자리 hex 코드
- 예: `#8B4513` ✅, `8B4513` ❌, `#8B4` ❌
