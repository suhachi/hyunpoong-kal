```
미리보기 실패 원인:
├─ 1️⃣ import.meta.env 접근 실패 (Figma Make 환경 미지원)
├─ 2️⃣ BrowserRouter 복잡한 라우팅
├─ 3️⃣ 외부 의존성 (Firebase, Providers)

심각도: ⚠️ 중간
영향: Figma Make 미리보기만 (로컬/프로덕션 정상)

```

## 🔍 1. 근본 원인 분석

### 1.1 Figma Make 환경 특성

Figma Make는 **샌드박스 환경**에서 React 앱을 실행합니다:

```typescript
// ❌ Figma Make에서 실패할 수 있는 코드
import.meta.env.MODE          // undefined 또는 접근 불가
import.meta.env.VITE_*        // 환경 변수 없음
BrowserRouter                  // History API 제한
Service Worker                 // 등록 불가
```

**결과:** 앱 초기화 단계에서 실패하여 빈 화면 표시

---

### 1.2 발견된 문제점 (5가지)

#### ❌ 문제 1: import.meta.env 접근

**파일:** `/config/env.ts` (라인 9, 24)

```typescript
// 현재 코드 (방어적이지만 불완전)
export const ENV = (() => {
  try {
    return import.meta.env.MODE || 'development';  // ← Figma Make에서 실패
  } catch {
    return 'development';
  }
})();

const getEnv = (key: string, defaultValue: string = '') => {
  try {
    const value = import.meta.env[key] || '';  // ← 여기도 실패 가능
    return value || defaultValue;
  } catch (error) {
    return defaultValue;
  }
};
```

**문제점:**
- `import.meta.env`가 Figma Make에서 `undefined`일 수 있음
- `undefined[key]` 접근 시 TypeError 발생 가능

**영향:**
- 전체 앱이 초기화 실패
- 빈 화면 표시

---

#### ❌ 문제 2: BrowserRouter 복잡도

**파일:** `/App.tsx` (라인 53)

```typescript
<BrowserRouter>
  <AuthProvider>      // ← Firebase 의존
    <CartProvider>    // ← Firebase 의존
      {/* 50+ 라우트 */}
    </CartProvider>
  </AuthProvider>
</BrowserRouter>
```

**문제점:**
- BrowserRouter는 History API 필요
- Figma Make에서 History API 제한적
- AuthProvider, CartProvider가 Firebase 초기화 시도

**영향:**
- 라우팅 실패
- Provider 초기화 실패

---

#### ❌ 문제 3: Firebase 초기화

**파일:** `/lib/firebase.ts` (라인 26-36)

```typescript
if (USE_FIREBASE) {
  try {
    app = initializeApp(firebaseConfig);  // ← 환경 변수 필요
    authInstance = getAuth(app);
    firestoreDb = getFirestore(app);
    // ...
  } catch (error) {
    console.error('[Firebase] 초기화 실패:', error);
  }
}
```

**문제점:**
- `USE_FIREBASE`가 false여도 AuthProvider가 Firebase 객체 참조
- Firebase SDK가 로드되는 과정에서 에러 발생 가능

**영향:**
- Provider 초기화 실패
- 빈 화면 또는 에러

---

#### ❌ 문제 4: Service Worker 등록

**파일:** `/main.tsx` (라인 9-11)

```typescript
if (import.meta.env.PROD) {
  registerServiceWorker();  // ← Figma Make에서 실패
}
```

**문제점:**
- `import.meta.env.PROD` 접근 실패
- Service Worker API가 Figma Make에서 미지원

**영향:**
- 미미 (try-catch 필요)

---

#### ❌ 문제 5: 외부 웹폰트

**파일:** `/index.html` (라인 15-16)

```html
<link rel="stylesheet" as="style" crossorigin
  href="https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/variable/pretendardvariable-dynamic-subset.min.css" />
```

**문제점:**
- 외부 CDN 로딩 실패 시 FOUC (Flash of Unstyled Content)
- Figma Make에서 CORS 문제 가능

**영향:**
- 폰트만 안 보임 (앱 작동은 가능)

## 🚀 4. 권장 해결책

### ✅ 최종 권장: **방안 2 (방어적 코드) + App.simple.tsx 옵션**

#### Step 1: env.ts 수정 (방어적 코드)

```typescript
// config/env.ts
export const ENV = (() => {
  try {
    if (typeof import.meta === 'undefined' || !import.meta.env) {
      console.log('[Env] Figma Make 또는 특수 환경 감지 - 개발 모드');
      return 'development';
    }
    return import.meta.env.MODE || 'development';
  } catch {
    return 'development';
  }
})();

const getEnv = (key: string, defaultValue: string = '', required: boolean = false): string => {
  try {
    // import.meta 안전 체크
    if (typeof import.meta === 'undefined' || !import.meta.env) {
      if (DEBUG && required) {
        console.warn(`[Env] ${key} 접근 불가 (Figma Make?), 기본값 사용: ${defaultValue}`);
      }
      return defaultValue;
    }
    
    const value = import.meta.env[key] || '';
    
    if (!value && required && !defaultValue) {
      console.error(`[Env] Required environment variable ${key} is not set`);
      if (ENV === 'production') {
        throw new Error(`Required environment variable ${key} is not set`);
      }
    }
    
    return value || defaultValue;
  } catch (error) {
    if (DEBUG) {
      console.warn(`[Env] ${key} 에러:`, error, '- 기본값 사용');
    }
    return defaultValue;
  }
};
```

#### Step 2: main.tsx 수정 (Service Worker 안전 처리)

```typescript
// main.tsx
import React from 'react';
import ReactDOM from 'react-dom/client';
import App from './App';
import './styles/globals.css';

// Service Worker 등록 (안전하게)
if (typeof import.meta !== 'undefined' && import.meta.env?.PROD) {
  try {
    const { registerServiceWorker } = await import('./lib/utils/pwa');
    registerServiceWorker();
  } catch (error) {
    console.warn('[PWA] Service Worker 등록 실패:', error);
  }
}

// 온라인/오프라인 리스너도 안전하게
if (typeof window !== 'undefined' && 'addEventListener' in window) {
  try {
    const { setupNetworkListeners } = await import('./lib/utils/pwa');
    const { toast } = await import('sonner@2.0.3');
    
    setupNetworkListeners(
      () => toast.success('인터넷에 연결되었습니다.'),
      () => toast.error('인터넷 연결이 끊겼습니다.')
    );
  } catch (error) {
    console.warn('[PWA] 네트워크 리스너 설정 실패:', error);
  }
}

ReactDOM.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>,
);
```
