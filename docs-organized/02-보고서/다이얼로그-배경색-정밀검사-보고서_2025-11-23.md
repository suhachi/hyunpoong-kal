## 🔧 CSS 우선순위 분석

### `cn()` 함수 동작
`cn()` 함수는 `clsx`와 `tailwind-merge`를 사용하여 클래스를 병합합니다.

**중요**: `tailwind-merge`는 동일한 유틸리티 클래스(예: `bg-white`와 `bg-gray-50`)가 충돌할 때, **나중에 오는 클래스가 우선순위가 높습니다**.

**예시:**
```tsx
// dialog.tsx 기본값
className={cn("bg-gray-50 ...", className)}

// MenuCreateDialog.tsx에서 전달
<DialogContent className="... bg-white">
  // 결과: bg-white가 bg-gray-50을 덮어씀 ❌
</DialogContent>
```

**해결책:**
1. 기본 컴포넌트에서 기본값 설정 (`dialog.tsx` ✅)
2. 개별 컴포넌트에서 명시적으로 `bg-gray-50` 지정 (권장)
3. 또는 `bg-white`를 제거하고 기본값에 의존
