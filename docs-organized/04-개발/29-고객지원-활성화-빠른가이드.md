## ⚡ 빠른 실행 (3단계)

### 1단계: .env 파일 생성

프로젝트 루트 디렉토리에서 실행:

```bash
# .env.example을 복사하여 .env 생성
cp .env.example .env
```

또는 직접 생성:

```bash
# 새 .env 파일 생성
touch .env
```

### 2단계: 환경 변수 추가

`.env` 파일을 열고 다음 내용 추가:

```bash
# Phase 3-2: 고객 지원 채팅
VITE_SUPPORT_ENABLED=true

# Firebase 설정 (선택)
VITE_USE_FIREBASE=true
VITE_FIREBASE_PROJECT_ID=hp-kal

# 기타 Phase 3 기능 (선택)
VITE_DELIVERY_ENABLED=true
VITE_POINTS_ENABLED=true
```

### 3단계: 개발 서버 재시작

```bash
# 기존 서버 중단 (Ctrl+C)
# 새로 시작
npm run dev
```

## 🔧 문제 해결

### Q1: 여전히 비활성화 메시지가 나와요

**A:** 개발 서버를 재시작했나요?

```bash
# 반드시 재시작 필요!
Ctrl+C (서버 중단)
npm run dev (재시작)
```

Vite는 `.env` 파일 변경을 자동으로 감지하지 않습니다.

### Q2: .env 파일이 어디에 있어야 하나요?

**A:** 프로젝트 **루트 디렉토리**에 있어야 합니다.

```
현풍닭칼국수/
├── .env          ← 여기!
├── .env.example
├── package.json
├── vite.config.ts
├── src/
└── ...
```

### Q3: Mock 모드로 테스트하고 싶어요

**A:** `.env` 파일 설정:

```bash
VITE_USE_FIREBASE=false    # Mock 모드
VITE_SUPPORT_ENABLED=true  # 기능 활성화
```

- localStorage 기반 시뮬레이션
- Firebase 없이 테스트 가능

### Q4: Firebase 모드로 사용하고 싶어요

**A:** `.env` 파일 설정:

```bash
VITE_USE_FIREBASE=true
VITE_SUPPORT_ENABLED=true
VITE_FIREBASE_PROJECT_ID=hp-kal
# ... 나머지 Firebase 설정
```

- Firestore 실시간 동기화
- `support_sessions`, `support_messages` 컬렉션 사용
