## 🔴 필수 확인 사항 (즉시 확인)

### 1. 주문 상태 머신 동작 확인

#### 1.1 주문 생성 및 표시
- [ ] 고객앱에서 주문 생성
- [ ] 관리자 대시보드 "접수대기" 탭에 새 주문이 표시되는지 확인
- [ ] 주문 상태가 `pending`으로 표시되는지 확인

#### 1.2 상태 변경 플로우
- [ ] 관리자가 "접수하기" 클릭 → 상태가 `accepted`로 변경되는지
- [ ] "접수확인" 탭으로 자동 이동하는지
- [ ] 관리자가 "조리중" 클릭 → 상태가 `cooking`으로 변경되는지
- [ ] "조리중" 탭에 표시되는지
- [ ] 관리자가 "배달" 클릭 → 상태가 `delivering`으로 변경되는지
- [ ] 관리자가 "완료" 클릭 → 상태가 `completed`로 변경되는지
- [ ] "완료" 탭으로 이동하는지

#### 1.3 고객앱 상태 표시
- [ ] 고객앱 주문내역에서 상태가 올바르게 표시되는지
- [ ] `pending`/`accepted` → "주문접수"로 표시되는지
- [ ] `cooking` → "조리중"으로 표시되는지
- [ ] `delivering` → "배달중"으로 표시되는지
- [ ] `completed` → "배달완료"로 표시되는지

## 📋 확인 방법

### 브라우저 개발자 도구 활용
1. **콘솔 확인**
   - F12 → Console 탭
   - 에러나 경고 메시지 확인

2. **네트워크 확인**
   - F12 → Network 탭
   - API 호출이 정상적으로 이루어지는지 확인

3. **로컬 스토리지 확인**
   - F12 → Application → Local Storage
   - Mock 데이터가 올바르게 저장되는지 확인

### 테스트 시나리오
1. **고객앱에서 주문 생성**
   - 메뉴 선택 → 장바구니 추가 → 결제 진행
   - 주문 완료 후 주문번호 확인

2. **관리자 대시보드 확인**
   - 새 주문 알림 확인
   - 상태 변경 테스트
   - 각 탭에서 주문 표시 확인

3. **샘플 데이터 확인**
   - 각 관리자 페이지 접속
   - 빈 상태 메시지 확인

## ⚠️ 주의 사항

1. **브라우저 오디오 정책**
   - 일부 브라우저는 사용자 상호작용 없이 오디오 재생을 차단할 수 있음
   - 알림음이 재생되지 않으면 브라우저 설정 확인 필요

2. **프린트 기능**
   - 브라우저 프린트 다이얼로그가 열리지 않으면 프린터 설정 확인 필요
   - 프린터가 없어도 다이얼로그는 열려야 함

3. **5초 폴링**
   - 현재는 5초마다 주문을 확인하므로 실시간은 아님
   - 최대 5초 지연이 발생할 수 있음
