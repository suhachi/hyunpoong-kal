## 📝 사용 방법

각 폴더의 파일들은 내용별로 분류되어 있습니다. 필요한 문서를 해당 폴더에서 찾아보세요.

## 🔍 파일 찾기

특정 주제의 문서를 찾으려면:
1. 폴더명을 확인하여 관련 카테고리로 이동
2. 파일명에서 키워드 검색
3. 필요시 전체 검색 기능 활용
