## 🐛 문제 해결

### 문제 1: npm install 실패

**증상:**
```
npm ERR! code ERESOLVE
npm ERR! ERESOLVE unable to resolve dependency tree
```

**해결:**
```bash
# package-lock.json 삭제 후 재시도
rm package-lock.json
npm install

# 또는 강제 설치
npm install --legacy-peer-deps
```

---

### 문제 2: Firebase import 오류

**증상:**
```typescript
Cannot find module 'firebase/app' or its corresponding type declarations
```

**해결:**
```bash
# node_modules 재설치
rm -rf node_modules package-lock.json
npm install

# TypeScript 재시작 (VSCode)
Cmd/Ctrl + Shift + P -> "TypeScript: Restart TS Server"
```

---

### 문제 3: Tailwind CSS 오류

**증상:**
```
Error: Cannot find module 'tailwindcss'
```

**해결:**
```bash
# Tailwind 재설치
npm install -D tailwindcss@^4.0.0 autoprefixer@^10.4.18 postcss@^8.4.35
```

---

### 문제 4: 빌드 실패

**증상:**
```
error TS2307: Cannot find module
```

**해결:**
```bash
# 캐시 클리어
rm -rf dist .vite

# 재빌드
npm run build
```
