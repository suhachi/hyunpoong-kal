## 📋 개요

### 목표
관리자 설정 센터를 추가하여 API 키 및 시스템 설정의 **상태 진단**과 **안전한 입력/가이드**를 제공합니다.

### 보안 원칙
- **서버 비밀키**: `functions:config`에만 저장
- **클라이언트 키**: `.env.local`에 저장 (공개 가능한 키만)
- **UI 마스킹**: 키 입력 필드는 저장하지 않고 CLI 명령어 미리보기에만 바인딩

---

## 🎯 핵심 기능

### 1. 5개 설정 탭
```
┌─────────────────────────────────────────────┐
│ [결제] [배달대행] [지도/지오] [알림/FCM] [운영/보안] │
└─────────────────────────────────────────────┘
```

#### 1.1 결제 (NICEPAY)
- **상태 패널**: Functions Config 연결 상태, 필수 키 존재 여부
- **가이드**: CLI 명령어 복사, Return/Cancel URL, 테스트/프로덕션 모드

#### 1.2 배달대행
- **설정**: Provider 선택 (mock/providerA/custom)
- **배달비**: 최대 거리, 거리별 요금표, 야간 추가비
- **가이드**: Webhook 비밀키 CLI 명령어

#### 1.3 지도/지오코딩
- **상태 패널**: Kakao/Google Maps API 키 설정 여부
- **가이드**: API 키 발급 방법, 플랫폼 등록, .env 템플릿

#### 1.4 알림/FCM
- **진단**: FCM 지원, Service Worker, VAPID 키
- **가이드**: Firebase Console 설정, Service Worker 파일, 체크리스트

#### 1.5 운영/보안
- **배포 스크립트**: Firestore Rules/Indexes, Functions, Hosting
- **CORS**: Storage CORS 설정 가이드
- **참고 문서**: 배포 가이드, 환경변수 가이드 링크
