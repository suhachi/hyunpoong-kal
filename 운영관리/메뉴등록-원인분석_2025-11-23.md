## 🔍 문제 요약

### 증상
- `/admin/menus` 페이지에서 "메뉴 등록 → 저장" 클릭
- UI에서는 성공 메시지가 보이지 않거나 에러 발생
- Firestore Console에서 `stores/hyunpoong-main/menus` 컬렉션에 문서가 생성되지 않음

### 가능한 원인 (우선순위별)

1. **🔴 Firestore Security Rules 문제** (가능성 高)
   - `stores/{storeId}/menus` 컬렉션에 대한 쓰기 권한이 없음
   - `permission-denied` 에러 발생

2. **🟠 환경 변수 문제**
   - `VITE_STORE_ID`가 설정되지 않았거나 잘못된 값
   - `VITE_USE_FIREBASE=false`로 설정됨

3. **🟡 네트워크/연결 문제**
   - Firebase 연결 실패
   - 인터넷 연결 문제

  - 콘솔에 상세 에러 정보 출력
  - 사용자 친화적인 에러 메시지 제공

**코드 변경**:
```typescript
// FirebaseError 타입 import 추가
import { type FirebaseError } from 'firebase/firestore';

// 에러 핸들링 개선
catch (error) {
  if (error && typeof error === 'object' && 'code' in error) {
    const firebaseError = error as FirebaseError;
    if (firebaseError.code === 'permission-denied') {
      console.error('[createMenu] Firestore permission error:', {
        code: firebaseError.code,
        message: firebaseError.message,
        storeId: getStoreId(),
        collectionPath: `stores/${getStoreId()}/menus`,
      });
      throw new Error('메뉴 등록에 실패했습니다. Firestore Security Rules에서 stores/{storeId}/menus 쓰기 권한을 허용해야 합니다.');
    }
  }
  throw error;
}
```
