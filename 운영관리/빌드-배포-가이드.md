## 📋 빌드 명령어

### 프로덕션 빌드

```bash
npm run build
```

**빌드 결과**: `dist/` 폴더에 생성됨

**빌드 시간**: 약 1-2분

**주요 출력물**:
- `dist/index.html` - 메인 HTML 파일
- `dist/assets/` - 번들된 JS/CSS 파일
- `dist/icons/` - PWA 아이콘
- `dist/offline.html` - 오프라인 페이지
- `dist/sw.js` - Service Worker

### 빌드 크기 분석

```bash
npm run analyze:dist
```

빌드 후 각 파일의 크기를 분석하여 출력합니다.

### 미리보기 (로컬 테스트)

```bash
npm run preview
```

빌드된 결과를 로컬에서 미리 확인할 수 있습니다.
- 기본 포트: `http://localhost:4173`

## 🔥 Firebase 배포

### 전체 배포

```bash
firebase deploy
```

다음 항목을 모두 배포합니다:
- Hosting (웹 앱)
- Firestore Rules (데이터베이스 규칙)
- Firestore Indexes (데이터베이스 인덱스)
- Functions (클라우드 함수)

### 개별 배포

#### Hosting만 배포

```bash
firebase deploy --only hosting
```

**배포 대상**: `dist/` 폴더  
**배포 URL**: `https://hyun-poong.web.app`

#### Firestore Rules만 배포

```bash
firebase deploy --only firestore:rules
```

**배포 파일**: `firestore.rules`

#### Firestore Indexes만 배포

```bash
firebase deploy --only firestore:indexes
```

**배포 파일**: `firestore.indexes.json`

#### Functions만 배포

```bash
firebase deploy --only functions
```

**배포 소스**: `src/functions/`

## ✅ 배포 전 체크리스트

배포 전에 다음 항목을 확인하세요:

### 1. 환경 변수 확인

- [ ] `.env.local` 파일에 모든 Firebase 설정이 올바른지 확인
- [ ] `VITE_USE_FIREBASE=true` 설정 확인
- [ ] `VITE_STORE_ID` 설정 확인

### 2. 빌드 테스트

- [ ] `npm run build` 성공 확인
- [ ] `npm run preview`로 빌드 결과 확인
- [ ] 주요 페이지가 정상 작동하는지 확인

### 3. Firebase 설정 확인

- [ ] Firebase 프로젝트가 올바른지 확인 (`hyun-poong`)
- [ ] Firestore Rules가 올바른지 확인
- [ ] Firestore Indexes가 필요한 인덱스를 포함하는지 확인

### 4. CORS 설정 확인

- [ ] Firebase Storage CORS 설정이 올바른지 확인
- [ ] `src/cors.json` 파일이 올바른 도메인을 포함하는지 확인

### 5. 기능 테스트

- [ ] 로그인/회원가입 작동 확인
- [ ] 메뉴 조회/등록 작동 확인
- [ ] 주문 생성/조회 작동 확인
- [ ] 이미지 업로드 작동 확인

## 🚨 배포 시 주의사항

### 1. Firestore Rules

현재 개발용 규칙 (모든 읽기/쓰기 허용)이 적용되어 있습니다.
프로덕션 배포 전에는 반드시 엄격한 인증/권한 규칙으로 변경해야 합니다.

### 2. 환경 변수

`.env.local` 파일은 Git에 커밋하지 마세요.
각 환경별로 별도의 환경 변수 파일을 사용하세요.

### 3. 빌드 크기

일부 청크가 500KB를 초과합니다. 필요시 코드 스플리팅을 고려하세요.

### 4. Functions 배포

Functions를 배포할 때는 Node.js 버전을 확인하세요.
현재 설정: `nodejs20`
