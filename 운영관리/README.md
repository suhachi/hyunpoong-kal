## 🚀 빌드/배포 가이드

### 빌드 명령어

```bash
# 프로덕션 빌드
npm run build

# 빌드 크기 분석
npm run analyze:dist

# 미리보기 (빌드 결과 확인)
npm run preview
```

### 배포 명령어

```bash
# Firebase 배포
firebase deploy

# Firestore 규칙만 배포
firebase deploy --only firestore:rules

# Firestore 인덱스만 배포
firebase deploy --only firestore:indexes

# Functions만 배포
firebase deploy --only functions

# Hosting만 배포
firebase deploy --only hosting
```

### 배포 전 체크리스트

배포 전에 `04-배포-전-최종-체크리스트.md` 파일을 확인하세요.
