## 🔍 알려진 이슈 및 해결 방안

### 1. 이미지 업로드 blob URL 문제

**현상:**
- 메뉴 등록 시 이미지가 `blob:` URL로 저장됨
- `net::ERR_FILE_NOT_FOUND` 에러 발생

**원인 분석:**
- `USE_FIREBASE` 플래그가 `false`일 가능성
- `uploadMenuImage()` 함수에서 에러 발생 후 fallback

**해결 방안:**
1. 콘솔에서 `[MenuCreateDialog] USE_FIREBASE:` 로그 확인
2. `.env.local` 파일의 `VITE_USE_FIREBASE=true` 확인
3. Firebase Storage 권한 설정 확인
4. `[uploadMenuImage]` 로그로 에러 원인 파악

**추가된 디버그 로그:**
- `[MenuCreateDialog] USE_FIREBASE:`
- `[uploadMenuImage] Starting upload`
- `[uploadImageToStorage] Starting upload`
- `[uploadImageToStorage] Upload successful`

---

### 2. getMenuStats 경고 메시지

**현상:**
- 콘솔에 `[getMenuStats] Firebase implementation pending` 경고 표시

**원인:**
- 빌드된 파일이 아직 반영되지 않음

**해결:**
- ✅ 코드에서 경고 메시지 제거 완료
- ✅ 빌드 및 배포 완료
- 새로고침 후 경고 메시지 사라질 예정
