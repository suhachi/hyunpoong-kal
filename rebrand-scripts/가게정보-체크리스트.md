## 📝 참고사항

- **관리자 페이지**에서 입력한 정보는 **Firebase Firestore**에 저장됩니다
- Mock 모드를 사용하는 경우, `localStorage`에 저장됩니다

## ❓ 문제 해결

### Q: 관리자 페이지에서 가게 정보를 저장했는데 반영이 안 돼요

**A:** 다음을 확인하세요:
1. Firebase 연결 상태 확인 (`.env.local` 파일의 `VITE_USE_FIREBASE=true`)
2. 관리자 권한 확인 (로그인한 계정이 관리자 권한인지)
3. 브라우저 콘솔에서 에러 확인
4. 개발 서버 재시작

### Q: 푸터나 연락처 페이지 정보를 변경했는데 반영이 안 돼요

**A:** 다음을 확인하세요:
1. 파일 저장 확인 (Ctrl+S)
2. 개발 서버 재시작 (`npm run dev`)
3. 브라우저 캐시 삭제 (Ctrl+Shift+R)

### Q: 가게 위치(지도)가 표시되지 않아요

**A:** 다음을 확인하세요:
1. `src/config/env.ts`의 `KAKAO_MAP_APP_KEY` 설정 확인
2. 카카오맵 API 키 발급 및 등록
3. 주소를 먼저 입력한 후 지도에서 위치 클릭
