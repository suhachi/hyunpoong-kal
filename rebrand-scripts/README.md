## 🚀 빠른 시작

### 1. 권한 부여 (최초 1회)

```bash
chmod +x rebrand-scripts/rebrand.sh
```

### 2. 스크립트 실행

```bash
./rebrand-scripts/rebrand.sh "새가게명" "#Primary" "#Secondary" "#Accent"
```

**예시:**
```bash
./rebrand-scripts/rebrand.sh "부산갈비집" "#8B4513" "#FF6B35" "#D4AF37"
```

## ✅ 스크립트 경로 자동 처리

스크립트는 `src/` 경로를 우선 확인하고, 없으면 루트 경로를 자동으로 확인합니다.

**자동 처리:**
- ✅ `src/config/env.ts` 우선 확인
- ✅ `src/constants/colors.ts` 우선 확인
- ✅ `src/styles/globals.css` 우선 확인
- ✅ 없으면 루트 경로 자동 확인

**사용 방법:**
프로젝트 루트(`hyunpoong-kal/`)에서 바로 실행하면 됩니다:
```bash
./rebrand-scripts/rebrand.sh "새가게명" "#Primary" "#Secondary" "#Accent"
```

## 🔧 문제 해결

문제가 발생하면 다음을 확인하세요:

1. **권한 오류**: `chmod +x rebrand-scripts/rebrand.sh`
2. **파일을 찾을 수 없음**: 스크립트 경로 확인
3. **컬러 형식 오류**: `#000000` 형식 확인
4. **백업 복원**: `backup-*` 디렉토리 확인

자세한 문제 해결 방법은 **`배달앱-복제-스크립트-상세-가이드.md`**의 "문제 해결" 섹션을 참조하세요.
