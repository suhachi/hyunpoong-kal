## 🎯 개요

### 무엇을 하는 스크립트인가?

`rebrand.sh`는 **현풍닭칼국수 PWA**를 **다른 음식점의 배달앱**으로 자동 변환하는 Bash 스크립트입니다.

### 핵심 가치

```
✅ 시간 절약: 수동 변경 30분 → 자동 변경 5분
✅ 실수 방지: 자동으로 정확하게 변경
✅ 백업 자동: 원본 파일 자동 보존
✅ 복원 가능: 언제든 되돌리기 가능
✅ 화이트라벨: 한 번의 명령으로 새 브랜드 탄생
```

### 지원 기능

- ✅ 가게명 자동 변경
- ✅ 브랜드 컬러 3가지 자동 변경 (Primary/Secondary/Accent)
- ✅ CSS 변수 자동 업데이트
- ✅ HTML 메타 태그 자동 변경
- ✅ 자동 백업 생성
- ✅ 변경 사항 검증

## 📦 사전 준비

### 1. 필수 요구사항

- ✅ **Bash 쉘**: macOS, Linux, Git Bash (Windows)
- ✅ **실행 권한**: 스크립트에 실행 권한 부여 필요
- ✅ **프로젝트 루트**: `hyunpoong-kal/` 디렉토리에서 실행

### 2. 필요한 정보

스크립트 실행 전에 다음 정보를 준비하세요:

1. **새 가게명** (예: "부산갈비집")
2. **Primary 컬러** (hex 형식, 예: `#8B4513`)
3. **Secondary 컬러** (hex 형식, 예: `#FF6B35`)
4. **Accent 컬러** (hex 형식, 예: `#D4AF37`)

### 3. 컬러 선택 팁

컬러를 선택할 때는 다음 도구를 활용하세요:

- **Adobe Color**: https://color.adobe.com
- **Coolors**: https://coolors.co
- **Paletton**: http://paletton.com

**권장 컬러 조합**:
- Primary: 메인 브랜드 컬러 (강조 버튼, 로고)
- Secondary: 포인트 컬러 (액션 버튼, 배지)
- Accent: 보조 컬러 (강조 텍스트, 아이콘)

## 🚀 스크립트 실행 방법

### Step 1: 프로젝트 디렉토리로 이동

```bash
cd hyunpoong-kal
```

### Step 2: 스크립트 실행 권한 부여 (최초 1회만)

**macOS / Linux:**
```bash
chmod +x rebrand-scripts/rebrand.sh
```

**Windows (Git Bash):**
```bash
chmod +x rebrand-scripts/rebrand.sh
```

**PowerShell (대안):**
```powershell
# Git Bash를 사용하거나 WSL 사용 권장
```

### Step 3: 스크립트 실행

```bash
./rebrand-scripts/rebrand.sh "새가게명" "#Primary" "#Secondary" "#Accent"
```

**파라미터 설명:**
- `"새가게명"`: 새로운 가게 이름 (따옴표 필수!)
- `"#Primary"`: Primary 브랜드 컬러 (hex 형식)
- `"#Secondary"`: Secondary 브랜드 컬러 (hex 형식)
- `"#Accent"`: Accent 브랜드 컬러 (hex 형식)

### Step 4: 확인 프롬프트

스크립트가 변경 사항을 보여주고 확인을 요청합니다:

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🏪 브랜드 변경 스크립트 v2.0
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

가게명: 부산갈비집
Primary: #8B4513 (메인 컬러)
Secondary: #FF6B35 (포인트 컬러)
Accent: #D4AF37 (엑센트 컬러)

계속하시겠습니까? (y/N):
```

**`y` 입력** → 변경 시작  
**`N` 입력** → 취소

### Step 5: 완료 확인

스크립트가 8단계로 나누어 변경을 진행합니다:

```
[1/8] 백업 생성 중...
```

완료되면 다음 메시지가 표시됩니다:

## 🔍 작동 원리

### 1. 백업 생성 (Step 1/8)

스크립트는 먼저 원본 파일을 백업합니다:

```bash
BACKUP_DIR="./backup-$(date +%Y%m%d-%H%M%S)"
mkdir -p "$BACKUP_DIR"

# src/ 경로 우선, 없으면 루트 경로 사용
cp src/config/env.ts "$BACKUP_DIR/" 2>/dev/null || cp config/env.ts "$BACKUP_DIR/" 2>/dev/null || true
cp src/constants/colors.ts "$BACKUP_DIR/" 2>/dev/null || cp constants/colors.ts "$BACKUP_DIR/" 2>/dev/null || true
cp src/constants/design-tokens.ts "$BACKUP_DIR/" 2>/dev/null || cp constants/design-tokens.ts "$BACKUP_DIR/" 2>/dev/null || true
cp src/styles/globals.css "$BACKUP_DIR/" 2>/dev/null || cp styles/globals.css "$BACKUP_DIR/" 2>/dev/null || true
cp src/styles/design-lock.css "$BACKUP_DIR/" 2>/dev/null || cp styles/design-lock.css "$BACKUP_DIR/" 2>/dev/null || true
cp index.html "$BACKUP_DIR/"
```

**결과**: `backup-20241107-153042/` 디렉토리 생성

### 2. 가게명 변경 (Step 2/8)

**파일**: `src/config/env.ts`

**Before:**
```typescript
export const APP_CONFIG = {
  name: '현풍닭칼국수',
  // ...
};
```

**After:**
```typescript
export const APP_CONFIG = {
  name: '부산갈비집',
  // ...
};
```

**변경 방법**: `sed` 명령으로 `name: '.*'` 패턴을 찾아 새 가게명으로 교체

### 3. 브랜드 컬러 변경 (Step 3/8)

**파일**: `src/constants/colors.ts`

**Before:**
```typescript
export const BRAND_COLORS = {
  primary: '#D61C1C',      // 현풍레드
  secondary: '#F37021',    // 신칼오렌지
  accent: '#C7A45A',       // 황동식기색
} as const;
```

**After:**
```typescript
export const BRAND_COLORS = {
  primary: '#8B4513',      // 갈비 브라운
  secondary: '#FF6B35',     // 불꽃 오렌지
  accent: '#D4AF37',        // 골드
} as const;
```

**변경 방법**: `sed` 명령으로 각 컬러 값을 정규식으로 찾아 교체

### 4. 디자인 토큰 변경 (Step 4/8)

**파일**: `src/constants/design-tokens.ts`

**변경 내용**:
- `hyunpungRed: '#D61C1C'` → `hyunpungRed: '#8B4513'` (새 Primary)
- `shinkalOrange: '#F37021'` → `shinkalOrange: '#FF6B35'` (새 Secondary)
- `brassGold: '#C7A45A'` → `brassGold: '#D4AF37'` (새 Accent)

### 5. CSS 변수 변경 (Step 5-6/8)

**파일**: `src/styles/globals.css`, `src/styles/design-lock.css`

**변경 내용**:
- `#D61C1C` → 새 Primary 컬러 (모든 인스턴스)
- `#F37021` → 새 Secondary 컬러 (모든 인스턴스)
- `#C7A45A` → 새 Accent 컬러 (모든 인스턴스)

**변경 방법**: `sed` 명령으로 모든 컬러 코드를 일괄 교체

### 6. HTML 메타 태그 변경 (Step 7/8)

**파일**: `index.html`

**Before:**
```html
<title>현풍닭칼국수 - 주문 & 포장 웹앱</title>
<meta name="description" content="현풍닭칼국수 공식 주문/포장 전용 PWA입니다..." />
```

**After:**
```html

<meta name="description" content="부산갈비집 온라인 주문" />
```

1. `src/config/env.ts` 우선 확인
2. 없으면 `config/env.ts` 확인
3. 둘 다 없으면 에러 (현재는 모두 존재)

#### ✅ 프로젝트 완성도 확인

## 🛠️ 문제 해결

### 문제 1: 권한 오류

**증상:**
```
bash: ./rebrand-scripts/rebrand.sh: Permission denied
```

**해결:**
```bash
chmod +x rebrand-scripts/rebrand.sh
```

---

### 문제 2: 파일을 찾을 수 없음

**증상:**
```
cp: src/config/env.ts: No such file or directory
```

**원인**: 파일 경로 문제

**해결**: 스크립트가 자동으로 `src/` 경로와 루트 경로를 모두 확인합니다. 만약 문제가 발생하면:

1. **프로젝트 루트에서 실행 확인**
   ```bash
   pwd  # hyunpoong-kal 디렉토리인지 확인
   ```

2. **파일 존재 확인**
   ```bash
   ls -la src/config/env.ts
   ls -la src/constants/colors.ts
   ```

---

### 문제 3: sed 오류 (macOS)

**증상:**
```
sed: 1: "src/config/env.ts": invalid command code
```

**원인**: macOS의 `sed`는 `-i` 옵션 뒤에 공백이 필요합니다.

**해결**: 스크립트가 자동으로 처리합니다. 만약 문제가 발생하면 스크립트를 확인하세요.

---

### 문제 4: 파라미터 부족

**증상:**
```
❌ 사용법: ./rebrand-scripts/rebrand.sh <가게명> <Primary> <Secondary> <Accent>
```

**해결**: 4개 파라미터를 모두 입력하세요.

```bash
./rebrand-scripts/rebrand.sh "가게명" "#컬러1" "#컬러2" "#컬러3"
```

---

### 문제 5: 컬러 형식 오류

**증상:**
```
❌ 오류: 컬러는 #000000 형식이어야 합니다
```

**해결**: 컬러는 반드시 `#`으로 시작하고 6자리 hex 코드여야 합니다.

**올바른 형식:**
- ✅ `#8B4513`
- ✅ `#FF6B35`
- ✅ `#D4AF37`

**잘못된 형식:**
- ❌ `8B4513` (앞에 `#` 없음)
- ❌ `#8B4` (6자리가 아님)
- ❌ `rgb(139, 69, 19)` (hex 형식 아님)

---

### 문제 6: 컬러가 적용 안 됨

**원인**: 브라우저 캐시

```bash
# 1. 개발 서버 재시작
npm run dev

# 2. 브라우저 하드 리프레시
# Windows/Linux: Ctrl + Shift + R
# Mac: Cmd + Shift + R
```
