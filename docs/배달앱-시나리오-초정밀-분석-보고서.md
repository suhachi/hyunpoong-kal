## 시나리오 요약

### 배달 시나리오
1. 고객이 배달앱에 가입
2. 배달앱 메뉴를 선택
3. 배달 선택
4. 배달앱에서 결제 또는 만나서 결제(카드, 현금) 선택 후 결제
5. 매장에서 관리자 대시보드에서 주문 알림(팝업 알림과 알림음)
6. 주문 접수 버튼을 클릭
7. 팝업이 사라지고 알림음이 중단됨과 동시에 주문 접수 완료로 이동(고객의 배달앱에 접수 완료 팝업과 동시에 주문 내역에서 완료 표시)
8. 접수 완료로 이동하면서 주문서가 출력됨
9. 매장에서 조리(조리 중 선택하고 클릭, 고객의 배달앱에서 접수 완료에서 조리 중으로 이동) 버튼을 누르면 조리 중으로 고객 배달앱에 표시
10. 조리 완료 후 배달 대행 앱으로 배달 기사를 호출
11. 배달 기사가 콜을 받아 매장으로 이동, 배달 기사가 픽업을 하면 배달 대행 API 연동으로 인해 대시보드와 고객 배달앱에 배달 중으로 나타남
12. 배달 기사가 배달 완료를 하면 관리자 대시보드에는 완료, 고객 앱에도 완료와 동시에 리뷰 작성 버튼이 완료 창에 활성화됨

### 포장 시나리오
1. 고객이 배달앱에 가입
2. 배달앱 메뉴를 선택
3. 포장 선택
4. 관리자 대시보드에 주문 알림음* 포장 주문으로 표시
5. 관리자 대시보드의 접수 버튼을 누르면 고객 앱에 접수 완료로 표시
6. 관리자 대시보드에서는 접수 완료로 표시됨과 동시에 알림음이 중단되고 주문서가 출력됨
7. 관리자 대시보드에 조리 중을 누르면 고객 앱에 조리 중으로 표시
8. 조리 완료 클릭 후 포장이 완료되면 포장 완료 버튼을 관리자 대시보드에서 누르면 고객 앱에서는 조리 완료 표시 후 포장 완료가 되면 포장 완료가 표시되고 팝업 알림이 뜸

## 총평 및 권장 사항

### 전체 시나리오 준수도: **75%**

#### ✅ 잘 구현된 부분
1. **고객 여정 (가입 → 메뉴 선택 → 결제 → 주문 추적 → 리뷰)**: 완벽하게 구현됨
2. **관리자 주문 관리**: 주문 알림, 접수, 상태 변경이 잘 구현됨

4. **주문서 출력**: 영수증 프린터 호환 포맷으로 잘 구현됨

3. **자동화**: 주문서 자동 출력, 포장 완료 팝업 등 자동화 기능 부족
