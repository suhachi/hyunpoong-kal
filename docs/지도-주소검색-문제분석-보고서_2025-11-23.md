## 🔍 문제 분석

### 현재 상황
1. **주소 검색 기능 누락**
   - `AddressSearch.tsx` 파일이 비어있음
   - 주소 입력란은 일반 `Input`으로만 구현됨
   - 주소 검색 버튼(Q 아이콘)이 있지만 기능이 없음

2. **지도 로딩 문제**
   - `StoreLocationPicker`는 초기 마운트 시에만 지도를 로드 (`useEffect(() => {...}, [])`)
   - 주소 검색 후 `lat`/`lng`가 변경되어도 지도가 이미 로드된 경우에만 마커 위치만 업데이트
   - 지도가 아직 로드되지 않았거나, `lat`/`lng`가 `null`이면 지도가 표시되지 않음

3. **지도 컨테이너 크기 문제**
   - 현재 높이가 280px로 작아서 지도가 제대로 표시되지 않을 수 있음

4. **사용자 흐름 문제**
   - 사용자가 기대하는 흐름:
     1. 주소 입력 → 검색 버튼 클릭
     2. "주소를 찾았습니다" 알림 표시
     3. 지도가 자동으로 로드되어 해당 위치 표시
     4. 지도에서 핀포인트로 위치 지정
   - 현재 실제 흐름:
     1. 주소 입력만 가능 (검색 기능 없음)
     2. 지도는 초기 마운트 시에만 로드 (서울 시청 기본 위치)
     3. 주소 검색 후 좌표가 설정되어도 지도가 업데이트되지 않음

## 🎯 해결 방안

### 1. 주소 검색 기능 구현
- **파일**: `src/components/admin/AddressSearch.tsx`
- **기능**:
  - 카카오맵 Geocoding API를 사용하여 주소를 좌표로 변환
  - 검색 성공 시 `onChange` 콜백으로 `lat`/`lng` 전달
  - 검색 성공 시 "주소를 찾았습니다" 알림 표시 (toast 또는 인라인 메시지)

### 2. 지도 로딩 로직 개선
- **파일**: `src/components/admin/StoreLocationPicker.tsx`
- **개선 사항**:
  - `lat`/`lng`가 변경되면 지도가 이미 로드되어 있으면 중심을 이동
  - 지도가 아직 로드되지 않았으면 즉시 로드하도록 수정
  - 지도 로딩 상태를 명확히 표시

### 3. 지도 컨테이너 크기 확대
- **파일**: `src/components/admin/StoreLocationPicker.tsx`
- **변경 사항**:
  - 지도 컨테이너 높이: 280px → 400px
  - 로딩/에러 상태도 동일한 높이로 통일

### 4. StoreInfoTab 통합
- **파일**: `src/pages/admin/Settings/StoreInfoTab.tsx`
- **변경 사항**:
  - 주소 입력란 옆에 검색 버튼 추가
  - `AddressSearch` 컴포넌트 통합
  - 주소 검색 성공 시 `storeInfo.address.lat`/`lng` 업데이트
  - 업데이트된 좌표가 `StoreLocationPicker`에 전달되어 지도 자동 업데이트
