## 🚨 근본 원인 분석

### 문제점 1: 데이터 소스 불일치

| 컴포넌트 | 데이터 소스 | 문제 |
|---------|------------|------|
| `MenuList` | `getMenus()` API | ✅ 정상 |
| `MenuDetail` | 정적 `menus.json` 파일 | ❌ **문제** |

**영향**:
- `MenuList`는 API로 메뉴를 가져오는데, `MenuDetail`은 정적 JSON에서만 찾음
- Firebase 모드로 운영 중이면, Firestore의 메뉴를 `MenuDetail`에서 찾을 수 없음
- Mock 모드에서도 localStorage에 저장된 메뉴 변경사항이 `MenuDetail`에 반영되지 않음

### 문제점 2: 메뉴 ID 불일치 가능성

**시나리오**:
1. `MenuList`가 `getMenus()`로 메뉴를 가져옴 (예: `menu-001`)
2. 사용자가 메뉴를 클릭 → `/menu/menu-001`로 이동
3. `MenuDetail`이 `menus.json`에서 `menu-001`을 찾음
4. 만약 `menus.json`에 해당 메뉴가 없거나 ID가 다르면 → "메뉴를 찾을 수 없습니다"

**수정 후 코드** (해결):
```typescript
import { useState, useEffect } from 'react';
import { useParams, useNavigate } from 'react-router-dom';
import { getMenuById } from '../../lib/admin/menus.api';
import type { Menu } from '../../types/menu';

export function MenuDetail() {
  const { menuId } = useParams<{ menuId: string }>();
  const navigate = useNavigate();
  const [menu, setMenu] = useState<Menu | null>(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    if (!menuId) {
      navigate('/menu');
      return;
    }

    const loadMenu = async () => {
      try {
        setLoading(true);
        const loadedMenu = await getMenuById(menuId);
        if (!loadedMenu) {
          // 메뉴를 찾을 수 없으면 목록으로 리다이렉트
          navigate('/menu');
          return;
        }
        setMenu(loadedMenu);
      } catch (error) {
        console.error('Failed to load menu:', error);
        navigate('/menu');
      } finally {
        setLoading(false);
      }
    };

    loadMenu();
  }, [menuId, navigate]);

  if (loading) {
    return (
      <div className="flex items-center justify-center min-h-[60vh]">
        <div className="text-[#2E1C10]/60">로딩 중...</div>
      </div>
    );
  }

  if (!menu) {
    return null; // navigate로 리다이렉트되므로 여기 도달하지 않음
  }

  // ... 나머지 코드는 동일
```
