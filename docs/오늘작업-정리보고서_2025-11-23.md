### 1. 다이얼로그 배경색 문제 해결 ✅

**문제**: 
- 관리자 대시보드의 모든 다이얼로그/모달 배경이 투명하거나 흰색으로 표시됨
- 사용자가 회색 배경(`bg-gray-50`)을 요청했으나 적용되지 않음

**원인 분석**:
- `dialog.tsx`의 기본값을 `bg-gray-50`으로 변경했지만
- 각 개별 다이얼로그 컴포넌트에서 `bg-white`를 명시적으로 지정하여 덮어씀
- CSS 우선순위 문제로 `tailwind-merge`가 클래스를 병합할 때 기본값이 무시됨

**해결 방법**:
- 모든 다이얼로그에 `!bg-gray-50` (important) 적용
- 기본 UI 컴포넌트(`dialog.tsx`, `sheet.tsx`)의 기본값도 `!bg-gray-50`으로 변경

**수정된 파일 (9개)**:
1. `src/components/ui/dialog.tsx` - 기본값 `!bg-gray-50`
2. `src/components/ui/sheet.tsx` - 기본값 `!bg-gray-50`
3. `src/components/admin/MenuCreateDialog.tsx` - `!bg-gray-50`
4. `src/components/admin/MenuEditDialog.tsx` - `!bg-gray-50`
5. `src/components/admin/MenuCSVImport.tsx` - `!bg-gray-50`
6. `src/components/admin/TimeSettingDialog.tsx` - `!bg-gray-50`
7. `src/components/admin/common/Modal.tsx` - `!bg-gray-50`
8. `src/components/admin/OptionGroupsManagement.tsx` - `!bg-gray-50` (2개 다이얼로그)
9. `src/components/admin/OrderDetailDrawer.tsx` - `!bg-gray-50`

**결과**: ✅ 모든 다이얼로그/모달이 회색 배경으로 일관되게 표시됨

### 2. 메뉴 등록/수정 다이얼로그에 시간제 판매 설정 추가 ✅

**문제**: 
- 메뉴 등록/수정 모달에 시간제 판매 설정 기능이 없음
- 별도의 `TimeSettingDialog`를 열어야만 설정 가능

**해결 방법**:
- `MenuCreateDialog`에 시간제 판매 설정 UI 추가 (Clock import 누락 수정)
- `MenuEditDialog`에 시간제 판매 설정 UI 추가
- `Menus.tsx`의 `handleSaveEdit`에서 `availableHours` 처리 로직 추가

**수정된 파일**:
1. `src/components/admin/MenuCreateDialog.tsx`
   - Clock 아이콘 import 추가
   - 시간제 판매 설정 UI 이미 존재 (확인 완료)

2. `src/components/admin/MenuEditDialog.tsx`
   - Clock 아이콘 import 추가
   - Checkbox import 추가
   - 시간제 판매 설정 state 추가 (`timeLimitEnabled`, `timeLimitStart`, `timeLimitEnd`)
   - useEffect에서 기존 `availableHours` 초기화 로직 추가
   - handleSubmit에서 `availableHours` 업데이트 로직 추가
   - hasChanges 계산에 `availableHours` 포함
   - 시간제 판매 설정 UI 추가 (체크박스, 시작/종료 시간 입력, 안내 메시지)

3. `src/pages/admin/Menus.tsx`
   - `handleSaveEdit` 함수 타입에 `availableHours` 추가
   - `availableHours` 업데이트 시 `updateMenuAvailableHours` API 호출
   - 데이터 갱신을 위해 `loadData()` 호출

**결과**: ✅ 메뉴 등록/수정 시 시간제 판매 설정을 바로 할 수 있음
