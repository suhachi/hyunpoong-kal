### 1. 코드 수정 (Null-safe 가드)

#### 1.1. `src/lib/admin/settingsCenter.api.ts`

**수정 전**:
```typescript
const data = docSnap.data();
return {
  delivery: data.delivery || DEFAULT_DELIVERY_SETTINGS,
  // ...
  updatedAt: data.updatedAt?.toDate() || new Date(),
};
```

**수정 후**:
```typescript
const data = docSnap.data() || {};  // ← null guard
return {
  delivery: data.delivery || DEFAULT_DELIVERY_SETTINGS,
  // ...
  updatedAt: data.updatedAt?.toDate?.() || new Date(),  // ← optional chaining 추가
};
```

**효과**:
- `docSnap.data()` 결과가 null일 때 방어
- `toDate()` 메서드 undefined 접근 방지
