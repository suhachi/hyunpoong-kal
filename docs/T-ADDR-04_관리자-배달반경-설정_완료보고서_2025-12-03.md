## 📋 작업 개요

T-ADDR-03에서 구현한 배달 반경 체크 기능을 확장하여, **Admin 가게 설정 화면에서 점주가 직접 배달 가능 범위(km)를 설정**할 수 있는 기능을 추가했습니다.

### 기존 상태 (T-ADDR-03)
- 배달 반경이 `.env`의 `VITE_MAX_DELIVERY_RADIUS_KM`로 전역 고정
- Checkout에서 `MAX_DELIVERY_RADIUS_KM`를 사용해 배달 가능 범위 가드 수행

### 이번 작업 (T-ADDR-04)
- 점주가 Admin 설정 화면에서 직접 배달 반경 설정 가능
- **우선순위: 매장별 설정 값 → env 기본값 → OFF**
- 기존 동작 100% 보존 (env 기반 fallback 유지)

## ✅ 구현 완료 항목

### 1. Store 타입 확장 (`src/lib/firebase/firestore-schema.ts`)

**이미 완료됨 (T-ADDR-03에서 추가됨):**
```typescript
export interface StoreDoc {
  // ... 기존 필드들
  deliveryRadiusKm?: number; // 배달 가능 반경 (km, 없으면 env 기본값)
}
```

- `deliveryRadiusKm`는 optional 필드로 정의
- 값이 없거나 0이면 env 기본값 사용

### 2. Admin 가게 설정 UI 추가 (`src/pages/admin/Settings/StoreInfoTab.tsx`)

#### 입력 필드 추가
```tsx
<div className="space-y-2">
  <Label htmlFor="store-delivery-radius">배달 가능 범위 (km)</Label>
  <Input
    id="store-delivery-radius"
    type="number"
    min={0}
    step={0.1}
    value={storeInfo.deliveryRadiusKm ?? ""}
    onChange={(e) => {
      const val = e.target.value;
      setStoreInfo({
        ...storeInfo,
        deliveryRadiusKm: val === "" ? undefined : Number(val),
      });
    }}
    placeholder="예: 3"
    className="bg-gray-50"
  />
  <p className="text-sm text-[#2E1C10]/60">
    0 또는 비워두면 시스템 기본값을 사용합니다. 예: 3 → 매장 기준 3km 이내만 배달
  </p>
</div>
```

**위치:** "영업 설정" 카드 내, "기본 배달비" 필드 바로 아래

**특징:**
- `type="number"`, `min={0}`, `step={0.1}` - 숫자만 입력, 0 이상, 0.1km 단위
- 빈 값 처리: `val === "" ? undefined` - Firestore에 필드 생략
- 명확한 helper text로 사용법 안내

#### 저장 로직 수정
```typescript
const updateData: Partial<StoreDoc> = {
  // ... 기존 필드들
  deliveryRadiusKm:
    typeof storeInfo.deliveryRadiusKm === "number" && storeInfo.deliveryRadiusKm > 0
      ? storeInfo.deliveryRadiusKm
      : undefined,
  // ...
};
```

**안전 장치:**
- 숫자가 아니거나 0 이하면 `undefined`로 저장 (필드 생략)
- Firestore에 불필요한 필드 저장 방지

### 3. Checkout 배달 반경 로직 수정 (`src/pages/app/Checkout.tsx`)

#### 우선순위 적용 로직
```typescript
// 배달 가능 범위 체크 (T-ADDR-03, T-ADDR-04)
// 우선순위: storeInfo.deliveryRadiusKm > MAX_DELIVERY_RADIUS_KM > OFF
const storeRadiusKm = storeInfo?.deliveryRadiusKm;
const effectiveRadiusKm =
  typeof storeRadiusKm === "number" && storeRadiusKm > 0
    ? storeRadiusKm
    : MAX_DELIVERY_RADIUS_KM;

if (
  deliveryType === "delivery" &&
  effectiveRadiusKm > 0
) {
  // ... 거리 계산 및 차단 로직
  if (distanceKm > effectiveRadiusKm) {
    toast.error(
      `배달 가능 범위(${effectiveRadiusKm}km)를 벗어났습니다. 매장 인근 주소로 다시 시도해 주세요.`,
    );
    setIsProcessing(false);
    return;
  }
}
```

**우선순위 정책:**
1. **1순위:** `storeInfo.deliveryRadiusKm` (매장별 설정)
2. **2순위:** `MAX_DELIVERY_RADIUS_KM` (env 기본값)
3. **3순위:** OFF (둘 다 0 또는 없으면 체크 스킵)

**특징:**
- `effectiveRadiusKm` 변수로 최종 사용할 반경 계산
- 토스트 메시지에도 실제 적용된 반경 값 표시
- 기존 좌표 체크 및 안전 모드 로직 100% 유지

## 🔒 안전 장치 및 호환성

### 1. 기존 동작 100% 보존
- **env 기반 동작 유지:** `deliveryRadiusKm`가 없으면 기존 `MAX_DELIVERY_RADIUS_KM` 사용

- **좌표 없는 경우 안전 모드:** 기존 T-ADDR-03 로직 그대로 유지

### 2. 최소 침투 수정
- **수정 파일:** 2개만 수정 (StoreInfoTab.tsx, Checkout.tsx)
- **타입 변경 없음:** `StoreDoc`는 이미 T-ADDR-03에서 필드 추가됨
- **API/결제 로직 무변경:** 주문 생성, 결제 처리 코드는 전혀 건드리지 않음

### 3. 데이터 안전성
- **Firestore 마이그레이션 불필요:** optional 필드이므로 기존 문서와 호환
- **잘못된 값 방지:** 숫자 validation, 0 이하 값 제거
- **기본값 fallback:** 매장 설정 없으면 자동으로 env 기본값 사용

## 🎯 동작 시나리오

### 시나리오 1: 매장별 반경 설정 우선 적용
1. Admin → 가게 설정 → "배달 가능 범위(km)" 에 **1** 입력
2. `.env`에 `VITE_MAX_DELIVERY_RADIUS_KM=5` 설정되어 있음
3. Checkout에서 배달 주문 시:
   - 실제 적용 반경: **1km** (매장 설정 우선)
   - 1.5km 거리 주소 → **차단** ("1km를 벗어났습니다")

### 시나리오 2: env 기본값 fallback
1. Admin → 가게 설정 → "배달 가능 범위(km)" 비워둠 (또는 0)
2. `.env`에 `VITE_MAX_DELIVERY_RADIUS_KM=3` 설정
3. Checkout에서 배달 주문 시:
   - 실제 적용 반경: **3km** (env 기본값 사용)
   - 2.5km 거리 주소 → **통과**
   - 4km 거리 주소 → **차단** ("3km를 벗어났습니다")

### 시나리오 3: 배달 반경 체크 OFF
1. Admin → 가게 설정 → "배달 가능 범위(km)" 비워둠
2. `.env`에 `VITE_MAX_DELIVERY_RADIUS_KM=0` (또는 미설정)
3. Checkout에서 배달 주문 시:
   - 배달 반경 체크 **스킵**
   - 모든 주소에서 주문 가능 (기존 동작)

### 시나리오 4: 동적 반경 변경
1. Admin → 가게 설정 → "배달 가능 범위(km)" 에 **5** 입력 → 저장
2. 즉시 반영: 다음 Checkout에서 5km 반경 적용
3. Admin → 가게 설정 → "배달 가능 범위(km)" 에 **2** 로 변경 → 저장

## 📝 설정 가이드

### Admin 설정 방법
1. **Admin 로그인** → 설정 → 가게 정보 탭
2. "영업 설정" 카드에서 **"배달 가능 범위 (km)"** 찾기
3. 원하는 반경(km) 입력
   - 예: `3` → 매장 기준 3km 이내만 배달
   - 예: `0` 또는 비워둠 → 시스템 기본값 사용
4. **"저장"** 버튼 클릭

### 우선순위 정책 정리
```
effectiveRadiusKm 결정 로직:
├─ storeInfo.deliveryRadiusKm 존재 && > 0
│   └─> storeInfo.deliveryRadiusKm 사용 (매장별 설정 우선)
│
└─ 그 외
    └─> MAX_DELIVERY_RADIUS_KM 사용 (env 기본값)
    
effectiveRadiusKm > 0
├─ YES → 거리 체크 수행
└─ NO → 거리 체크 스킵 (OFF 모드)
```

### `.env` 설정 예시
```env
# 시스템 기본 배달 반경 (매장별 설정이 없을 때 사용)
VITE_MAX_DELIVERY_RADIUS_KM=3

# 배달 반경 체크 비활성화 (전역)
# VITE_MAX_DELIVERY_RADIUS_KM=0
```
