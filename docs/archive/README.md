# Archive 폴더

이 폴더는 프로젝트 개발에 직접적인 영향이 없는 과거 작업 문서들을 보관합니다.

## 📁 폴더 구조

### 작업 완료 보고서
- Phase0, Phase1, Phase2 관련 보고서
- T2-* 작업 완료 보고서
- 작업일지

### 문제 분석 보고서
- 해결 완료된 문제 분석 보고서
- 문제 해결 방법 가이드

### 배포 보고서
- 과거 버전 배포 완료 보고서
- 배포 체크리스트

### 프로젝트 분석 보고서
- 프로젝트 전체 분석 보고서
- 프로젝트 평가 문서

### 기타
- 최종 완료 보고서 (과거 버전)
- 프로젝트 템플릿
- 운영 가이드 (참고용)

## 📝 참고

현재 개발에 필요한 문서들은 `docs/` 루트에 유지됩니다:
- 환경 설정 가이드
- Firestore 규칙 가이드
- 최신 작업 보고서
- 남은 작업 정리
