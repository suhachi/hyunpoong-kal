## 🔍 문제 1: 샘플 데이터 미완전 제거 (고객 지원)

### 발견 위치
- **파일:** `src/pages/admin/Support.tsx`
- **함수:** `createSampleSessions()` (190-350줄 근처)
- **호출 위치:** `loadSessionsMock()` 함수 내 (169줄)

### 문제 상세

**현재 동작:**
```typescript
// Mock 데이터 로드
async function loadSessionsMock() {
  const sessionsData = localStorage.getItem('chat_sessions') || '{}';
  let sessionsObj: Record<string, ChatSession> = JSON.parse(sessionsData);
  
  // 첫 실행 시 샘플 데이터 생성
  if (Object.keys(sessionsObj).length === 0) {
    sessionsObj = createSampleSessions();  // ← 여기서 샘플 데이터 생성
    localStorage.setItem('chat_sessions', JSON.stringify(sessionsObj));
  }
  // ...
}
```

**샘플 데이터 내용:**
- `session_001`: 김민수 - "배달이 너무 늦어요. 확인 부탁드립니다."
- `session_002`: 박지영 - "메뉴 변경이 가능한가요?" (진행 중)
- `session_003`: 이철수 - "결제가 안되는데 도와주세요." (완료)

**영향:**
- Mock 모드(`USE_FIREBASE=false`)에서 고객 지원 화면에 샘플 문의가 표시됨
- 초기 설치 직후 상태와 맞지 않음 (문의 0개여야 함)

### 해결 방법

**방법 1: 샘플 데이터 생성 로직 제거 (권장)**
```typescript

  let sessionsObj: Record<string, ChatSession> = JSON.parse(sessionsData);
  
  // 샘플 데이터 생성 제거 - 초기 상태는 빈 배열
  // if (Object.keys(sessionsObj).length === 0) {
  //   sessionsObj = createSampleSessions();
  //   localStorage.setItem('chat_sessions', JSON.stringify(sessionsObj));
  // }
  
  const sessionsList = Object.values(sessionsObj);
  // ...
}
```

**방법 2: createSampleSessions 함수 완전 제거**
- `createSampleSessions()` 함수 전체 삭제
- 관련 주석도 제거

**예상 변경 파일:**
- `src/pages/admin/Support.tsx` (약 160줄의 샘플 데이터 코드 제거)

## 🔍 문제 2: 지도 API 입력창 사라짐

### 발견 위치
- **파일:** `src/pages/admin/Settings/MapsTab.tsx`
- **현재 상태:** `.env.local` 파일에 직접 입력하도록 안내만 표시

### 문제 상세

**현재 구현:**
- 지도 API 상태만 표시 (Kakao Maps / Google Maps 설정 여부)
- API 키 발급 가이드만 제공
- `.env.local` 파일에 직접 입력하도록 안내

**사용자 기대:**
- 관리자 설정 페이지에서 직접 API 키를 입력하고 저장할 수 있는 Input 필드
- 입력한 키가 자동으로 `.env.local` 또는 설정에 저장되는 기능

**현재 코드 구조:**
```typescript
// MapsTab.tsx - 현재는 읽기 전용
const kakaoKey = getEnv('VITE_KAKAO_MAP_KEY');
const googleKey = getEnv('VITE_GOOGLE_MAPS_API_KEY');
// Input 필드 없음, 안내만 표시
```

**설정 저장 구조 확인:**
- `src/lib/admin/settingsCenter.api.ts`에 `saveAdminSettings()` 함수 존재
- `AdminSettings` 타입에 `maps` 필드 존재 (`DEFAULT_MAPS_SETTINGS`)
- 하지만 `MapsTab.tsx`에서 이 저장 기능을 사용하지 않음

### 해결 방법

**방법 1: Input 필드 추가 + 설정 저장 기능 구현 (권장)**

1. **MapsTab.tsx 수정:**
   - Kakao Maps API 키 Input 필드 추가
   - Google Maps API 키 Input 필드 추가
   - 저장 버튼 추가
   - `saveAdminSettings()` 호출하여 저장

2. **주의사항:**
   - `.env.local` 파일은 빌드 타임에 읽히므로, 런타임에 저장해도 즉시 반영되지 않음
   - 대신 `AdminSettings`의 `maps` 필드에 저장하고, 런타임에 이 값을 사용하도록 변경 필요
   - 또는 `.env.local` 파일을 직접 수정하는 방식은 보안상 권장하지 않음

**방법 2: 안내 메시지 개선 (임시)**
- 현재 구조 유지하되, "자동 등록 기능은 준비 중입니다" 안내 추가
- `.env.local` 파일 수정 후 서버 재시작 필요 안내 강조

**예상 변경 파일:**
- `src/pages/admin/Settings/MapsTab.tsx` (Input 필드 및 저장 로직 추가)
- `src/types/adminSettings.ts` (maps 설정 타입 확인)
- `src/lib/admin/settingsCenter.api.ts` (maps 설정 저장 로직 확인)

## 🔍 문제 3: FCM 설정 경고

### 발견 위치
- **파일:** `src/pages/admin/Settings/FCMTab.tsx`
- **함수:** `runFCMDiagnostics()` (자동 실행)
- **API:** `src/lib/admin/settingsCenter.api.ts`의 `runFCMDiagnostics()`

### 문제 상세

**현재 동작:**
- FCM 탭 진입 시 자동으로 `runFCMDiagnostics()` 실행
- 진단 결과에 따라 경고/에러 표시

**예상 원인:**
1. **VAPID 키 미설정**
   - `VITE_FCM_VAPID_KEY` 환경 변수가 설정되지 않음
   - 진단 결과: "VITE_FCM_VAPID_KEY가 설정되지 않았습니다"

2. **Service Worker 미등록**
   - `firebase-messaging-sw.js` 파일이 없거나 등록되지 않음
   - 진단 결과: "Service Worker가 등록되지 않았습니다"

3. **FCM 지원 확인**
   - 브라우저가 FCM을 지원하는지 확인
   - 일반적으로 정상 (Chrome/Edge 등)

**현재 진단 체크 항목 (예상):**
- FCM 지원 여부
- Service Worker 등록 여부
- VAPID 키 설정 여부

### 해결 방법

**방법 1: 환경 변수 설정 (실제 해결)**
```bash
# .env.local 파일에 추가
VITE_FCM_VAPID_KEY=YOUR_VAPID_KEY
```

**방법 2: Service Worker 파일 생성**
- `public/firebase-messaging-sw.js` 파일 생성
- Firebase 초기화 코드 추가

**방법 3: 경고 메시지 개선 (임시)**
- "FCM 설정에 문제가 있습니다" 메시지를 더 구체적으로 변경
- 어떤 항목이 문제인지 명확히 표시 (이미 진단 결과에 표시됨)
- "선택사항" 또는 "나중에 설정 가능" 안내 추가

**방법 4: Mock 모드에서는 경고 비활성화 (권장)**
- `USE_FIREBASE=false`일 때는 FCM이 필요 없으므로 경고를 표시하지 않음
- 또는 "Mock 모드에서는 FCM이 비활성화됩니다" 안내만 표시

**예상 변경 파일:**
- `src/lib/admin/settingsCenter.api.ts` (runFCMDiagnostics 함수)
- `src/pages/admin/Settings/FCMTab.tsx` (경고 표시 로직)
