# T2-21 작업 요약
**Cart E2E localStorage 동기화 문제 해결 완료**

---

## ✅ 해결된 문제

### 핵심 이슈
Cart 페이지 진입 시 localStorage 데이터가 소실되어 E2E 테스트 실패

### 근본 원인
CartContext의 초기화 로직에서 읽기/쓰기 순서 문제:
1. 초기 마운트 시 빈 배열로 시작
2. 빈 배열이 먼저 localStorage에 저장됨
3. 그 후 loadFromStorage()가 빈 배열을 다시 로드

### 적용한 해결책
```typescript
// useRef로 초기 마운트 감지
const isInitialMount = useRef(true);

// 저장 useEffect: 첫 렌더 스킵
useEffect(() => {
  if (isInitialMount.current) {
    isInitialMount.current = false;
    return; // 초기 마운트 시 저장하지 않음
  }
  localStorage.setItem(...);
}, [items, ...]);

// 초기화 useEffect: items 의존성 제거
useEffect(() => {
  loadFromStorage();
  // ...
}, []); // 한 번만 실행
```
