### 2. 날짜 유틸 함수 안정화

**파일**: `src/lib/utils/date.ts`

**문제점**:
- Mock 주문 데이터의 `createdAt` 필드가 `{ seconds: number, nanoseconds: number }` 형태
- 기존 `convertToDate` 헬퍼가 이 형식을 처리하지 못함
- Orders 테이블에서 날짜 포맷팅 실패 가능성

**해결책**:
```typescript
// FirebaseTimestamp 형태 지원 추가
function convertToDate(
  date: Date | Timestamp | string | { seconds?: number; nanoseconds?: number }
): Date | null {
  // ... 기존 로직 ...
  
  // FirebaseTimestamp 형태 지원: { seconds, nanoseconds }
  if (date && typeof date === 'object' && 'seconds' in (date as any) && typeof (date as any).seconds === 'number') {
    return new Date((date as any).seconds * 1000);
  }
  
  // ISO string 파싱 시 유효성 검증
  if (typeof date === 'string') {
    const d = new Date(date);
    return isNaN(d.getTime()) ? null : d;
  }
  
  return null;
}
```

**효과**:
- ✅ Mock 데이터와 Firebase 데이터 모두 처리 가능
- ✅ ISO string 파싱 실패 시 null 반환으로 안정성 강화
- ✅ `formatDate`, `formatDateTime`, `formatRelativeTime` 모두 안정화

### 4. OrderDetailDrawer 타임라인 정렬 안정화

**파일**: `src/components/admin/OrderDetailDrawer.tsx`

**변경 전**:
```typescript
// 단순 seconds 필드 기반 정렬 (타입 안전하지 않음)

```

**변경 후**:
```typescript
// 다양한 타임스탬프 형식 처리 가능한 정렬
.sort((a, b) => {
  const toMs = (t: any) => {
    if (!t) return 0;
    if (typeof t === 'string') {
      const ms = Date.parse(t);
      return isNaN(ms) ? 0 : ms;
    }
    if (typeof t === 'object') {
      if ('seconds' in t && typeof (t as any).seconds === 'number') 
        return (t as any).seconds * 1000;
      if ('toDate' in t && typeof (t as any).toDate === 'function') 
        return (t as any).toDate().getTime();
    }
    return 0;
  };
  return toMs(a.timestamp) - toMs(b.timestamp);
});
```

**효과**:
- ✅ ISO string, FirebaseTimestamp, Timestamp 객체 모두 처리
- ✅ 타임라인 순서 정확성 보장
- ✅ null/undefined 안전 처리
