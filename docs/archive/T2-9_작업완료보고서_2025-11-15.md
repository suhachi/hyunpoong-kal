- 목표: 브라우저 권한요청 + 토큰 발급/저장 + SW push 핸들러(Mock) 뼈대 구축

## 1) 변경 사항 요약
- Vite `publicDir`를 `src/public`로 지정하여 `/sw.js` 노출 보장
- `src/public/sw.js`에 FCM push 뼈대 주석 표기 유지 (기존 핸들러 활용)
- `src/lib/fcm.ts`
  - `ensureFcmToken()` 신규: 권한 요청 → 토큰 발급 → `localStorage('hp_kal_fcm_token')` 저장
  - 기존 `requestNotificationPermission()`도 동일 키 사용, `getMessaging`/`isSupported` 안전화
  - VAPID 키 읽기: `VITE_FCM_VAPID_KEY` 우선, 없으면 `VITE_FIREBASE_VAPID_KEY` 폴백
  - `setupForegroundMessageListener()`에서 `getMessaging(app)`로 수정
- `src/App.tsx` 진입 시 1회 `ensureFcmToken()` 트리거(useEffect) 추가
- `.env.example`에 `VITE_FCM_VAPID_KEY` 주석 추가

## 2) 변경 파일
- `vite.config.ts` (publicDir 추가)
- `src/public/sw.js` (주석 보강, 기존 push 핸들러 유지)
- `src/lib/fcm.ts` (토큰 유틸 추가/안전화)
- `src/App.tsx` (앱 진입 시 토큰 요청 트리거)
- `.env.example` (VAPID 키 항목 주석)

## 3) 현재 동작 수준(목표 대비)
