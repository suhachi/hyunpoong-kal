**테스트 케이스** (7개):

| # | 테스트명 | 검증 내용 |
|---|---|---|
| 1 | `Settings page loads without errors` | 기본 페이지 로딩, 타이틀 확인 |
| 2 | `Payment tab renders correctly` | NicePay/Toss 선택 UI 확인 |
| 3 | `Delivery tab renders correctly` | 배달 대행사 설정 UI 확인 |
| 4 | `Maps tab renders correctly` | Kakao/Google Maps 가이드 확인 |
| 5 | `FCM tab renders correctly` | FCM 진단 UI 확인 |
| 6 | `Operations tab renders correctly` | 배포 스크립트 표시 확인 |
| 7 | `All tabs can be switched without errors` | 전체 탭 순환 전환 + 에러 0개 |

**각 테스트 구조**:
```typescript
test('Payment tab renders correctly', async ({ page }) => {
  // 1. 콘솔 에러 수집
  const errors: string[] = [];
  page.on('console', (msg) => {
    if (msg.type() === 'error') errors.push(msg.text());
  });

  // 2. 탭 클릭
  const paymentTab = page.getByRole('tab', { name: /결제/i });
  await paymentTab.click();
  await page.waitForTimeout(100);

  // 3. 핵심 UI 요소 확인
  await expect(page.getByText(/NicePay|나이스페이/i)).toBeVisible();

  // 4. 에러 검증
  expect(errors, 'No console errors on Payment tab').toEqual([]);
});
```

**특징**:
- `beforeEach`에서 `/admin/settings` 자동 진입
- Mock 사용자 자동 주입
- 탭별 핵심 UI 요소 선택적 검증
- 정규식 사용으로 한글/영문 텍스트 유연하게 매칭

### 4. `package.json` 스크립트 추가

**변경 전**:
```json
"scripts": {
  "dev": "vite",
  "build": "vite build"
}
```

**변경 후**:
```json
"scripts": {
  "dev": "vite",
  "build": "vite build",
  "test:e2e": "playwright test -c src/playwright.config.ts",
  "test:e2e:admin": "playwright test -c src/playwright.config.ts --project=chromium --grep @admin",
  "test:e2e:admin:routes": "playwright test -c src/playwright.config.ts admin-routes.spec.ts --project=chromium",
  "test:e2e:admin:settings": "playwright test -c src/playwright.config.ts admin-settings.spec.ts --project=chromium",
  "test:e2e:ui": "playwright test -c src/playwright.config.ts --ui",
  "test:e2e:report": "playwright show-report"
}
```

**스크립트 설명**:

| 스크립트 | 용도 | 실행 내용 |
|---|---|---|
| `test:e2e` | 전체 E2E 테스트 | 모든 테스트 파일 실행 (5개 브라우저) |
| `test:e2e:admin` | 관리자 전체 테스트 | `@admin` 태그 테스트만 (Chromium) |
| `test:e2e:admin:routes` | Routes 테스트만 | 11개 라우트 테스트 |
| `test:e2e:admin:settings` | Settings 테스트만 | 5개 탭 테스트 (7개 케이스) |
| `test:e2e:ui` | UI 모드 | 인터랙티브 디버깅 |
| `test:e2e:report` | 리포트 확인 | HTML 리포트 브라우저 열기 |

**실행 예시**:
```powershell
# 전체 관리자 테스트
pnpm test:e2e:admin

# 개별 테스트
pnpm test:e2e:admin:routes
pnpm test:e2e:admin:settings

# UI 모드 (디버깅)
pnpm test:e2e:ui
```
