## ✅ Firebase 모드 활성화를 위한 필요 작업

### 1단계: 환경 변수 설정

**필요한 작업:**
1. `.env.local` 파일 생성
2. Firebase 프로젝트 설정 값 입력

**예시:**
```env
VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=hyun-poong.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=hyun-poong
VITE_FIREBASE_STORAGE_BUCKET=hyun-poong.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=123456789
VITE_FIREBASE_APP_ID=1:123456789:web:abcdef
VITE_FIREBASE_MEASUREMENT_ID=G-XXXXXXXXXX
```

---

### 2단계: USE_FIREBASE 플래그 수정

**현재:**
```typescript
export const USE_FIREBASE = false;  // 하드코딩
```

**수정 필요:**
```typescript
export const USE_FIREBASE = getEnv('VITE_USE_FIREBASE', 'false') === 'true';
```

**또는:**
```typescript
export const USE_FIREBASE = getEnv('VITE_USE_FIREBASE', ENV === 'production' ? 'true' : 'false') === 'true';
```
