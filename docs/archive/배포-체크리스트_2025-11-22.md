## 1단계 – Firebase 모드 ON + 빌드/배포 (필수)

### 1-1. .env.local 최종 세팅

**현재 상태**: `VITE_USE_FIREBASE=false` ❌

**필요한 설정** (프로젝트 루트의 `.env.local` 파일):

```env
# ✅ 필수: Firebase 모드 활성화
VITE_USE_FIREBASE=true

# ✅ 필수: 매장 ID
VITE_STORE_ID=hyunpoong_main

# Firebase 설정 (이미 세팅되어 있으면 그대로 유지)
VITE_FIREBASE_API_KEY=...
VITE_FIREBASE_AUTH_DOMAIN=hyun-poong.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=hyun-poong
VITE_FIREBASE_STORAGE_BUCKET=hyun-poong.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=...
VITE_FIREBASE_APP_ID=...
VITE_FIREBASE_MEASUREMENT_ID=...

# FCM 웹푸시 키
VITE_FIREBASE_VAPID_KEY=...
```

**확인 방법**:
1. 프로젝트 루트의 `.env.local` 파일 열기
2. `VITE_USE_FIREBASE=true` 확인
3. `VITE_STORE_ID=hyunpoong_main` 확인
4. 나머지 Firebase 설정 값들이 모두 채워져 있는지 확인

---

### 1-2. 빌드 + Hosting 배포

터미널에서 순서대로 실행:

```bash
# 1) 의존성 최신화
npm install

# 2) 빌드
npm run build

# 3) Firebase 로그인 (이미 되어있으면 생략 가능)
firebase login

# 4) 프로젝트 선택 (이미 use 설정해두었으면 생략 가능)
firebase use hyun-poong

# 5) Hosting만 재배포
firebase deploy --only hosting
```

**예상 결과**:
- 빌드 성공: `✓ built in XX.XXs`
- 배포 성공: `✔ Deploy complete!`
- 배포 URL: `https://hyun-poong.web.app`


## 예상 문제 및 해결 방법

### 문제 1: 빌드 실패
**원인**: TypeScript 에러 또는 의존성 문제  
**해결**: `npm install` 후 `npm run build` 재실행, 에러 메시지 확인

### 문제 2: 배포 실패
**원인**: Firebase 로그인 안 됨 또는 프로젝트 미선택  
**해결**: `firebase login` 및 `firebase use hyun-poong` 실행

### 문제 3: 로그인 후에도 마이페이지 접근 불가
**원인**: 인증 체크 로직 문제  
**해결**: 브라우저 콘솔에서 에러 확인, `AuthContext` 상태 확인

### 문제 4: 주문이 Firestore에 생성되지 않음
**원인**: Firestore 보안 규칙 또는 컬렉션 경로 문제  
**해결**: Firestore 콘솔에서 규칙 확인, 브라우저 콘솔에서 에러 확인
