### 1차 문제: AuthContext와 getCurrentUser() 불일치

#### 근본 원인
```

getCurrentUser()   : localStorage.getItem('mockRole')  // 문자열
```

**결과**: 두 시스템이 다른 키를 읽어서 동기화 실패

#### 해결 방안 (완료)
- `getCurrentUser()`를 `mockUser` 기반으로 수정
- `mockLogin/mockLogout`에서 `mockRole` 제거
- `AdminLayout`을 `useAuth()` 훅 사용으로 전환

**수정 파일**:
1. `src/lib/auth.ts` (getCurrentUser, mockLogin, mockLogout)
2. `src/pages/admin/_layout/AdminLayout.tsx` (useAuth 훅 전환)

### 2차 문제: Firebase 모드로 작동 중 ⚠️ **현재 이슈**

#### 발견 과정
```javascript
// 브라우저 콘솔 로그
[Firebase] 초기화 완료
user: {uid: 'R6XTPaYSwtS7dPRai3ELVbQuGfA3', role: 'customer', ...}
```

→ localStorage에 `mockUser`가 있지만, Firebase Auth의 `customer` 역할 사용자가 로드됨

#### 근본 원인
**`.env` 파일 설정**:
```bash
VITE_USE_FIREBASE=true  # ❌ Firebase 모드
```

**결과**:
- Firebase Auth에 로그인된 사용자(`customer` 역할)가 로드됨
- `ProtectedRoute`에서 `roles: ["owner", "admin"]` 체크 실패
- `/admin` 접근 시 `/`로 리다이렉트

#### 수정 내용 (완료)
```bash
# .env
VITE_USE_FIREBASE=false  # ✅ Mock 모드
```

## 🛠️ 수정 작업 상세

### T1-1: AuthContext 통일 작업 (완료)

#### 1. `src/lib/auth.ts` - getCurrentUser() 수정

```typescript
// Before
export function getCurrentUser(): AuthUser | null {
  if (USE_FIREBASE) return null;
  const mockRole = localStorage.getItem('mockRole') || 'owner';
  return mockRole === 'owner' || mockRole === 'admin' ? MOCK_ADMIN : MOCK_CUSTOMER;
}

// After
export function getCurrentUser(): AuthUser | null {
  if (USE_FIREBASE) return null;
  
  try {
    const data = localStorage.getItem('mockUser');
    if (!data) return null;
    return JSON.parse(data) as AuthUser;
  } catch (error) {
    console.error('[getCurrentUser] mockUser parse error:', error);
    return null;
  }
}
```

#### 2. `src/lib/auth.ts` - mockLogin/mockLogout 간소화

```typescript
// Before
export function mockLogin(role: UserRole): void {
  const mockUser = role === 'owner' || role === 'admin' ? MOCK_ADMIN : MOCK_CUSTOMER;
  localStorage.setItem('mockUser', JSON.stringify(mockUser));
  localStorage.setItem('mockRole', role);  // ❌ 제거
  window.location.reload();
}

// After
export function mockLogin(role: UserRole): void {
  const mockUser = role === 'owner' || role === 'admin' ? MOCK_ADMIN : MOCK_CUSTOMER;
  localStorage.setItem('mockUser', JSON.stringify(mockUser));
  window.location.reload();
}
```

#### 3. `src/pages/admin/_layout/AdminLayout.tsx` - useAuth() 훅 사용

```typescript
// Before
import { getCurrentUser, mockLogout, type AuthUser } from '../../../lib/auth';

export function AdminLayout() {
  const [user, setUser] = useState<AuthUser | null>(null);
  const [loading, setLoading] = useState(true);
  
  useEffect(() => {
    checkAuth();
  }, []);
  
  async function checkAuth() {
    const authUser = getCurrentUser();
    if (!authUser) {
      navigate('/');
      return;
    }
    setUser(authUser);
    setLoading(false);
  }
  // ...
}

// After
import { useAuth } from '../../../contexts/AuthContext';
import { mockLogout } from '../../../lib/auth';

export function AdminLayout() {
  const { user, loading } = useAuth();  // ✅ 훅 사용
  const [sidebarOpen, setSidebarOpen] = useState(false);
  
  if (loading) {
    return <div>로딩 중...</div>;
  }
  
  if (!user) {
    navigate('/dev', { replace: true });
    return null;
  }
  // ...
}
```
