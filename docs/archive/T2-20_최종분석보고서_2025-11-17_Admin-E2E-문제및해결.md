# 관리자 E2E/주문 API 작업 보고서 (2025-11-17)

## 1. 문제 원인 분석

### 1.1. Playwright 테스트 실패
- 모든 관리자 라우트 E2E 테스트가 "console errors"로 실패
- 최근 환경 복구(Playwright 최신 버전, node_modules 재설치) 후에도 동일 증상
- 테스트 결과 첨부 이미지 기준, 각 라우트 진입 시 콘솔 에러 발생

### 1.2. Vite 빌드/런타임 에러
- `src/lib/admin/orders.api.ts` 577라인 부근에서 "Expression expected" 문법 오류 발생
- 원인: 함수/블록 닫힘(`}`)이 중복되어 불필요한 중괄호가 남아있음
- 실제 코드:
  ```typescript
  }
  }
  /** ... */
  ```
  → 마지막 `}`가 불필요하게 남아있어 문법 오류 유발

### 1.3. 영향
- 관리자 주문 API 전체가 정상적으로 빌드/실행되지 않음
- 모든 관리자 라우트/설정 페이지에서 데이터 로드/권한/렌더링 실패
- E2E 테스트 및 실제 서비스 기능 모두 정상 동작 불가

## 2. 지금까지의 작업 내용

### 2.1. E2E/관리자 기능 리팩토링
- Firebase/Mock 환경 통합: `USE_FIREBASE` 플래그 기반 분기
- AuthContext 리팩토링: 외부 AuthResolver 적용, localStorage fallback 강화
- 주문 API 리팩토링: Firestore/Mock/LocalStorage 기반 데이터 로드 및 상태 변경, 로그, 통계 함수 구현
- Fallback 유틸리티 도입: `parseJSONSafe`, `getMockUser`, `getOrdersFallback` 등
- E2E 테스트 스크립트 개선: mockUser 구조 보강, localStorage 초기화, 필수 필드 주입

### 2.2. 환경 복구 및 테스트
- Playwright 최신 버전으로 재설치
- node_modules 전체 삭제 후 `pnpm install`로 의존성 복구
- 브라우저 바이너리 재설치
- config 경로 및 testDir 구조 점검
- 관리자 라우트 E2E 테스트 재실행

### 2.3. 문제 발생 및 진단
- Playwright 프로젝트 인식 오류(구버전/설치 문제) → 최신 버전으로 해결
- Vite 빌드 시 주문 API 파일에서 문법 오류 발생 → 중복/불필요한 중괄호
- 모든 관리자 라우트/설정 페이지 E2E 테스트 실패 지속
