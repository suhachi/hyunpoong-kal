### 2단계: 지도 API 탭 안내문 정리

#### 목표
- 설정 > 지도/지오(Tab: maps) 화면에서 "왜 입력창이 없는지" 명확히 안내
- Kakao/Google Maps API 키는 빌드 시점 환경변수로만 관리한다는 점 명확화
- 향후 복사 스크립터가 `.env.local`을 자동 생성할 때 기준이 될 수 있도록 환경변수 이름 노출

#### 작업 내용
- **파일:** `src/pages/admin/Settings/MapsTab.tsx`
- **변경 사항:**
  1. **상단 안내 배너 추가**
     - "보안 및 복제 편의를 위해 지도 API 키는 화면에서 직접 입력하지 않고 `.env.local` 파일과 복사 스크립트로만 관리합니다" 안내
  2. **Kakao Maps 섹션 개선**
     - 제목: "Kakao Maps API (.env로 설정)"
     - "이 화면에서는 API 키를 직접 저장하지 않습니다" 안내 추가
     - 환경변수 이름 명시: `VITE_KAKAO_MAP_KEY`
     - JavaScript 키 발급 안내
     - 배포 후 재배포 필요 안내
  3. **Google Maps 섹션 개선**
     - "이 화면에서는 API 키를 직접 저장하지 않습니다" 안내 추가
     - 환경변수 이름 명시: `VITE_GOOGLE_MAPS_API_KEY`
     - 브라우저 키(Browser Key) 발급 안내
     - 배포 후 재배포 필요 안내

### 3단계: Mock 모드에서 FCM 경고 비활성화

#### 목표
- `USE_FIREBASE === false` (Mock 모드)일 때 FCMTab의 "진단 결과"를 정보(info) 상태로 표시
- "FCM 설정에 문제가 있습니다" 토스트/경고 배너를 띄우지 않음
- 대신 "Mock 모드에서는 실제 FCM 푸시를 사용하지 않으므로 경고를 무시해도 된다"는 안내 표시

#### 작업 내용
- **파일:** 
  - `src/pages/admin/Settings/FCMTab.tsx`
  - `src/types/adminSettings.ts`
- **변경 사항:**
  1. **USE_FIREBASE import 추가**
  2. **Mock 모드 단축 리턴 가드 추가**
     - `runDiagnostics()` 함수에 Mock 모드 체크 추가
     - Mock 모드일 때 정보 상태 결과 생성
     - Mock 모드에서는 toast 에러/경고 띄우지 않음
  3. **초기 렌더 시 자동 진단 차단**
     - `useEffect`에서 Mock 모드일 때 실제 진단 실행하지 않음
  4. **Mock 모드 안내 배너 추가**
     - FCMTab 상단에 Mock 모드 안내 배너 추가
     - Mock 모드에서만 표시되도록 조건부 렌더링
  5. **타입 정의 수정**
     - `DiagnosticResult.overall`에 `'info'` 타입 추가
     - `DiagnosticCheck.status`에 `'info'` 타입 추가
  6. **UI 업데이트**
     - 전체 상태 배지에 'info' 상태 추가 (파란색 배지)
     - 진단 결과 체크 항목에 'info' 아이콘 추가 (파란색 AlertCircle)

#### 변경 전/후

**변경 전:**
```tsx
const runDiagnostics = async () => {
  const result = await runFCMDiagnostics();
  setDiagnostics(result);
  
  if (result.overall === 'pass') {
    toast.success('모든 FCM 설정이 정상입니다');
  } else {
    toast.error('FCM 설정에 문제가 있습니다'); // Mock 모드에서도 경고
  }
};
```

**변경 후:**
```tsx
const runDiagnostics = async () => {
  // Mock 모드 전용: 경고 대신 정보 상태만 설정
  if (!USE_FIREBASE) {
    const mockResult: DiagnosticResult = {
      overall: 'info',
      checks: [
        {
          name: 'Mock 모드',
          status: 'info',
          message: '현재 Mock 모드(USE_FIREBASE=false)에서는 FCM 푸시를 사용하지 않습니다.',
        },
      ],
    };
    setDiagnostics(mockResult);
    // Mock 모드에서는 toast를 띄우지 않음
    return;
  }
  // 실서비스 모드: 기존 진단 로직 실행
  // ...
};
```
