## 🔍 발견된 문제 요약

### 1. Firestore 인덱스 누락 (Critical) ✅ 해결됨

#### 문제
다음 쿼리들이 Firestore 인덱스를 필요로 하지만, `firestore.indexes.json`이 비어있었음:

1. **메뉴 조회** (`stores/{storeId}/menus`)
   - `category` + `order` + `createdAt` 정렬
   - `category` + `name` + `createdAt` 정렬
   - `category` + `price` (ASC/DESC) + `createdAt` 정렬

2. **리뷰 조회** (`stores/{storeId}/reviews`)
   - `isVisible` + `rating` (DESC/ASC) + `createdAt` (DESC) 정렬
   - `isVisible` + `createdAt` (DESC) 정렬

3. **고객지원 세션** (`support_sessions`, `support_messages`)
   - `open` + `lastAt` (DESC) 정렬
   - `assignedTo` + `lastAt` (DESC) 정렬
   - `sessionId` + `at` (ASC) 정렬

#### 해결
✅ `firestore.indexes.json`에 **10개 인덱스** 추가 완료  
✅ `firebase deploy --only firestore:indexes` 배포 완료

**배포 결과**:
```
+ firestore: deployed indexes in firestore.indexes.json successfully
+ Deploy complete!
```

**⚠️ 주의**: 인덱스 생성에는 **몇 분에서 수십 분**이 걸릴 수 있습니다. Firebase 콘솔에서 인덱스 생성 상태를 확인하세요.
