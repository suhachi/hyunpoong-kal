## 📋 작업 개요

### 목표

v1.0 Firebase 실연동을 위한 **Cloud Functions 기본 셋업 + 주문/리뷰/스케줄러 트리거 + FCM 알림 흐름 구현** 완료. 주문 상태 변경, 리뷰 작성, 포인트/쿠폰 만료 스케줄러를 서버에서 감지하여 포인트 트랜잭션 및 알림까지 연결하는 골격 구현.

### 작업 범위

- ✅ `firebase.json`에 functions 섹션 추가/정리
- ✅ Functions TypeScript 프로젝트 셋업 (기존 구조 활용)
- ✅ Functions 공통 헬퍼 구현 (config / firestore / points / fcm)
- ✅ 주문 상태 변경 트리거 구현 (`onOrderStatusChanged`)
- ✅ 리뷰 작성 트리거 구현 (`onReviewCreatedV1`)
- ✅ 포인트 만료 스케줄러 구현 (`onScheduleExpirePoints`)
- ✅ 쿠폰 만료 스케줄러 구현 (`onScheduleExpireCoupons`)
- ✅ 빌드/배포 스크립트 및 루트 package.json 연동
- ✅ 최소 테스트 및 로그 주석 추가
- ✅ 빌드 검증 완료

**중요**: 이번 스텝에서는 **기본 골격과 트리거 구조**를 만들고, 실제 쿼리/업데이트 로직은 향후 확장 가능하도록 TODO로 남겨두었습니다. FCM 토큰 저장 구조는 향후 확장 예정입니다.

## 📊 트리거별 동작 요약

### 1. `onOrderStatusChanged`: 주문 상태 변경 → 포인트 적립/환불 설계 + FCM 설계

**시나리오**:
1. `stores/{storeId}/orders/{orderId}` 문서의 `status` 필드가 변경됨
2. `prevStatus !== 'completed' && nextStatus === 'completed'`인 경우:
   - 포인트 적립: `finalAmount * 1%` 계산 → `earnPointsServer` 호출
   - FCM 알림: `notifyUser` 호출 (현재는 로깅만)
3. `nextStatus === 'cancelled'`인 경우:
   - 환불 로직 (TODO)

**로그 예시**:
```
[onOrderStatusChanged] { storeId: 'hyunpoong_main', orderId: 'order-123', prevStatus: 'pending', nextStatus: 'completed' }
[onOrderStatusChanged] Earning points { userId: 'user-001', storeId: 'hyunpoong_main', orderId: 'order-123', amount: 100 }
[onOrderStatusChanged] Points earned and notification sent { userId: 'user-001', amount: 100 }
```

## 💡 참고 사항

### 주의사항

1. **기존 트리거와의 호환성**:
   - 기존 트리거 (`onReviewCreated`, `onOrderUpdated` 등)는 그대로 유지

   - 실제 쿼리/업데이트 로직은 다음 단계에서 구현 예정

4. **에러 처리**:
   - 모든 트리거에 `try/catch` 블록 추가
   - 에러 발생 시 콘솔 로그로 기록

5. **로그 포맷**:
   - 모든 트리거에 일관된 로그 접두사 적용
   - `[onOrderStatusChanged]`, `[onReviewCreatedV1]`, `[SCHEDULE]` 등
