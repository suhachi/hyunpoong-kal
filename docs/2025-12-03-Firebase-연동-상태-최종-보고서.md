#### 2-2. `firestore.rules` - 보안 규칙

**주요 규칙**:
```javascript
// 인증 확인
function isAuthenticated() {
  return request.auth != null;
}

// 본인 확인
function isOwner(userId) {
  return isAuthenticated() && request.auth.uid == userId;
}

// 관리자 확인
function isAdmin() {
  return isAuthenticated() && 
    exists(/databases/$(database)/documents/admins/$(request.auth.uid));
}
```

**컬렉션별 규칙**:
- `users`: 본인 또는 Admin만 읽기/쓰기
- `orders`: 본인 또는 Admin만 읽기, 생성은 인증된 사용자
- `reviews`: 공개 읽기, 본인만 작성
- `menus`: 공개 읽기, Admin만 쓰기
- `stores`: 공개 읽기, Admin만 쓰기

**상태**: ✅ 보안 규칙 완비

#### 2-3. `firestore.indexes.json` - 인덱스
