## ✅ 완료된 작업

### 1. 환경 변수 추가

**파일**: `src/config/env.ts`

**추가된 변수**:
```typescript
// Map Provider 설정
// VITE_MAP_PROVIDER 환경 변수를 읽어서 사용 (google | kakao)
// 기본값: google (구글맵 우선)
export const MAP_PROVIDER = getEnv('VITE_MAP_PROVIDER', 'google') as 'google' | 'kakao';
```

**환경 변수 파일 설정**:
`.env.local` 파일에 다음 항목 추가:
```env
# Map Provider (google | kakao)
# 기본값: google
# 카카오맵 심사 통과 후 kakao로 변경
VITE_MAP_PROVIDER=google
```

### 2. 통합 지도 로더 생성

**파일**: `src/lib/maps.ts` (신규 생성)

**기능**:
- `loadPrimaryMap()`: 환경 변수에 따라 기본 지도 제공자 로드
- `loadSecondaryMap()`: 기본 지도 실패 시 fallback 지도 제공자 로드

**코드 구조**:
```typescript
export async function loadPrimaryMap(): Promise<any> {
  if (MAP_PROVIDER === 'kakao') {
    return loadKakaoMaps();
  }
  return loadGoogleMaps();
}

export async function loadSecondaryMap(): Promise<any> {
  if (MAP_PROVIDER === 'kakao') {
    return loadGoogleMaps();
  }
  return loadKakaoMaps();
}
```

## 🎯 주요 개선 사항

### 1. 에러 수정

**문제**: `kakaoReady is not defined` 에러

**원인**: `AddressSearch` 컴포넌트에서 `kakaoReady` 변수를 참조했지만, 실제로는 `mapsReady`로 변경되었음

**해결**: 
- `kakaoReady` → `mapsReady`로 변경
- `mapProvider` → `currentProvider`로 변경
- 구글맵/카카오맵 모두 지원하도록 로직 개선

### 2. 통합 로더 시스템

**이전**: 각 컴포넌트에서 직접 `loadGoogleMaps()` / `loadKakaoMaps()` 호출

**현재**: `loadPrimaryMap()` / `loadSecondaryMap()` 통합 함수 사용

**장점**:
- 환경 변수 한 줄 변경으로 전체 앱의 지도 제공자 변경
- 코드 중복 제거
- 유지보수 용이
