## 📋 구현 계획

### 1. 관리자 대시보드: 가게 정보 입력란

**파일**: `src/pages/admin/Settings/StoreInfoTab.tsx` (신규)

**구조**:
```typescript
import { useState, useEffect } from 'react';
import { doc, getDoc, setDoc, serverTimestamp } from 'firebase/firestore';
import { db } from '../../../lib/firebase';
import { storeDocRef, type StoreDoc } from '../../../lib/firebase/firestore-schema';
import { STORE_ID } from '../../../config/env';
import { useAuth } from '../../../contexts/AuthContext';

export function StoreInfoTab() {
  const { user } = useAuth();
  const [storeInfo, setStoreInfo] = useState<Partial<StoreDoc>>({});

  // 가게 정보 로드
  useEffect(() => {
    loadStoreInfo();
  }, []);

  const loadStoreInfo = async () => {
    try {
      const docRef = storeDocRef(STORE_ID);
      const docSnap = await getDoc(docRef);
      if (docSnap.exists()) {
        setStoreInfo(docSnap.data() as StoreDoc);
      } else {
        // 기본값 설정
        setStoreInfo({
          storeId: STORE_ID,
          name: '',
          address: { full: '', detail: '' },
          phone: '',
          businessHours: {
            open: '10:00',
            close: '22:00',
            days: ['mon', 'tue', 'wed', 'thu', 'fri', 'sat', 'sun'],
          },
          isOpen: true,
          deliveryAvailable: true,
          minOrderAmount: 15000,
          deliveryFee: 3000,
        });
      }
    } catch (error) {
      console.error('Failed to load store info:', error);
    }
  };

  const handleSave = async () => {
    if (!user) return;
    try {
      const docRef = storeDocRef(STORE_ID);
      await setDoc(docRef, {
        ...storeInfo,
        updatedAt: serverTimestamp(),
        updatedBy: user.uid,
        updatedByName: user.displayName || '관리자',
      }, { merge: true });
      toast.success('가게 정보가 저장되었습니다');
    } catch (error) {
      toast.error('저장에 실패했습니다');
    }
  };

  return (
    // 폼 UI...
  );
}
```

### 2. 마이페이지: 가게 정보 버튼 및 표시

**파일**: `src/pages/app/My.tsx` (수정)

**추가할 내용**:
1. 가게 정보 버튼 추가
2. 가게 정보 모달/페이지 추가

```typescript
import { useState } from 'react';
import { getDoc } from 'firebase/firestore';
import { storeDocRef, type StoreDoc } from '../../lib/firebase/firestore-schema';
import { STORE_ID } from '../../config/env';
import { Store, Phone, MapPin, Clock } from 'lucide-react';

export function My() {
  const [showStoreInfo, setShowStoreInfo] = useState(false);
  const [storeInfo, setStoreInfo] = useState<StoreDoc | null>(null);

  const loadStoreInfo = async () => {
    try {
      const docRef = storeDocRef(STORE_ID);
      const docSnap = await getDoc(docRef);
      if (docSnap.exists()) {
        setStoreInfo(docSnap.data() as StoreDoc);
      }
    } catch (error) {
      console.error('Failed to load store info:', error);
    }
  };

  const handleStoreInfoClick = () => {
    loadStoreInfo();
    setShowStoreInfo(true);
  };

  return (
    <div>
      {/* 기존 코드... */}
      
      {/* 가게 정보 버튼 추가 */}
      <Button onClick={handleStoreInfoClick}>
        <Store className="w-4 h-4 mr-2" />
        가게 정보
      </Button>

      {/* 가게 정보 모달 */}
      {showStoreInfo && storeInfo && (
        <Dialog open={showStoreInfo} onOpenChange={setShowStoreInfo}>
          <DialogContent>
            <DialogHeader>
              <DialogTitle>{storeInfo.name}</DialogTitle>
            </DialogHeader>
            <div className="space-y-4">
              <div className="flex items-center gap-2">
                <Phone className="w-4 h-4" />
                <span>{storeInfo.phone}</span>
              </div>
              <div className="flex items-center gap-2">
                <MapPin className="w-4 h-4" />
                <span>{storeInfo.address.full}</span>
                {storeInfo.address.detail && (
                  <span className="text-sm text-gray-500">
                    {storeInfo.address.detail}
                  </span>
                )}
              </div>
              <div className="flex items-center gap-2">
                <Clock className="w-4 h-4" />
                <span>
                  {storeInfo.businessHours.open} - {storeInfo.businessHours.close}
                </span>
              </div>
            </div>
          </DialogContent>
        </Dialog>
      )}
    </div>
  );
}
```

**핵심**: Firestore 직접 읽기, 별도 API 없음

## 🤔 API의 용도 (필요한 경우)

### API가 필요한 경우:
1. **Mock 모드 지원**: 개발 중 Mock 데이터 사용
2. **에러 처리 통일**: 모든 에러를 일관되게 처리
3. **캐싱**: 가게 정보를 메모리에 캐싱
4. **검증 로직**: 입력 데이터 검증
5. **변환 로직**: Firestore 타입 ↔ 도메인 타입 변환

### API가 불필요한 경우 (현재 상황):
1. **간단한 CRUD**: 읽기/쓰기만 필요
2. **실서비스**: Mock 모드 불필요
3. **직접 접근**: Firestore 헬퍼 함수로 충분

---

## 📊 비교: API vs 직접 접근

| 항목 | 별도 API | 직접 접근 |
|------|---------|----------|
| 코드 복잡도 | 높음 | 낮음 |
| 파일 수 | +1개 | 0개 |
| Mock 지원 | 가능 | 불가능 |
| 유지보수 | 중간 | 쉬움 |
| 타입 안정성 | 높음 | 높음 (동일) |
| 에러 처리 | 통일 | 개별 처리 |
