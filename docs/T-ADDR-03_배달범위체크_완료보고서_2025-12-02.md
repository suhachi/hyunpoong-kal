## 📋 작업 개요

매장 좌표와 고객 배송지 좌표를 이용하여, **배달 가능 범위(반경 N km)를 벗어나면 주문을 막고 안내하는 가드**를 Checkout 단계에 추가했습니다.

### 목표
- 매장과 고객 주소 간 거리 계산
- 설정된 반경을 초과하면 주문 차단
- 기존 결제/주문 플로우 100% 보존

---

## ✅ 구현 완료 항목

### 1. 환경 변수 설정 (`src/config/env.ts`)
```typescript
// 배달 가능 범위 (km) - 0이면 범위 제한 없음
export const MAX_DELIVERY_RADIUS_KM = Number(
  getEnv("VITE_MAX_DELIVERY_RADIUS_KM", "0")
);
```

**사용법:**
- `.env` 파일에 추가:
  ```
  VITE_MAX_DELIVERY_RADIUS_KM=3  # 3km 이내만 배달 가능
  ```
- 기본값: `0` (범위 제한 없음, 기능 OFF)

### 2. 거리 계산 유틸리티 (`src/lib/distance.ts`)
- **Haversine 공식** 구현
- 두 좌표(위도/경도) 간 정확한 거리 계산 (km 단위)
- 지구 반지름 6371km 기준

```typescript
export function calculateDistanceKm(
  lat1: number,
  lng1: number,
  lat2: number,
  lng2: number,
): number
```

### 3. Checkout 페이지 배달 범위 가드 (`src/pages/app/Checkout.tsx`)
**주문하기 버튼 클릭 시점에 다음 로직 실행:**

1. **조건 확인**
   - 배달 주문인지 확인 (`deliveryType === "delivery"`)
   - `MAX_DELIVERY_RADIUS_KM > 0` (기능 활성화 여부)

2. **좌표 검증**
   - 매장 좌표: `storeInfo.address.lat/lng`
   - 고객 좌표: `deliveryAddress.lat/lng`
   - **좌표가 둘 중 하나라도 없으면**: 거리 체크 **스킵** (안전 모드)

3. **거리 계산 및 차단**
   - `calculateDistanceKm()` 함수로 거리 계산
   - 거리 > 설정 반경 → 토스트 에러 + 주문 중단

```typescript
if (distanceKm > MAX_DELIVERY_RADIUS_KM) {
  toast.error(
    `배달 가능 범위(${MAX_DELIVERY_RADIUS_KM}km)를 벗어났습니다. 매장 인근 주소로 다시 시도해 주세요.`,
  );
  setIsProcessing(false);
  return;
}
```

### 4. 매장 정보 로드
- `useEffect`를 통해 Firestore에서 매장 정보 자동 로드
- `storeDocRef(STORE_ID)`로 매장 주소/좌표 가져오기
- 로드 실패 시에도 앱 동작 유지 (배달 범위 체크만 스킵)

### 5. 타입 확장
- `PaymentRequest` 인터페이스에 `returnUrl`, `cancelUrl` 추가 (기존 코드와의 호환성)

## 🔒 안전 장치

### 1. 기존 플로우 보존
- NICEPAY, MEET_CARD, MEET_CASH 결제 방식 모두 정상 동작
- 배달 범위 체크는 **주문 생성 전**에만 실행
- 기존 validation(주소, 전화번호 등)과 독립적으로 동작

### 2. 안전 모드 (Safe Mode)
다음 경우 배달 범위 체크를 **자동 스킵**:
- `MAX_DELIVERY_RADIUS_KM`가 `0` 또는 미설정
- 매장 좌표가 없음
- 고객 주소 좌표가 없음
- 주문 타입이 `pickup`

### 3. UX 고려
- 좌표 없는 구주소 사용 시: 기존처럼 주문 허용 (차단하지 않음)
- 명확한 에러 메시지: "배달 가능 범위(Nkm)를 벗어났습니다"

## 🎯 동작 시나리오

### 시나리오 1: 정상 배달 (범위 내)
1. 고객이 매장 근처 주소 입력 (3km 이내)
2. Checkout → "주문하기" 클릭
3. 거리 체크: 2.5km → **통과**
4. 주문 생성 및 결제 진행 ✅

### 시나리오 2: 범위 초과
1. 고객이 먼 지역 주소 입력 (예: 10km)
2. Checkout → "주문하기" 클릭
3. 거리 체크: 10km > 3km → **차단**
4. 토스트 에러: "배달 가능 범위(3km)를 벗어났습니다" 🚫
5. 주문 생성되지 않음

### 시나리오 3: 안전 모드 (좌표 없음)
1. 고객이 구주소 입력 (lat/lng 없음)
2. Checkout → "주문하기" 클릭
3. 거리 체크 **스킵** (좌표 없음)
4. 기존처럼 주문 생성 및 결제 진행 ✅

### 시나리오 4: 기능 OFF
1. `VITE_MAX_DELIVERY_RADIUS_KM=0` 또는 미설정
2. 모든 주문에서 거리 체크 **스킵**
3. 기존 동작 그대로 유지 ✅
