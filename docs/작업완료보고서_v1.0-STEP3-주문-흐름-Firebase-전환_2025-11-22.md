## 🔧 변경된 파일 목록

### 1. `src/lib/orders.api.ts` (전면 수정)

**변경 내용**:
- Order ↔ OrderDoc 매퍼 함수 추가
- Mock 모드 함수 분리 (코드 구조 개선)
- Firebase 분기를 stores/{storeId}/orders 구조로 전환
- Firestore 스키마 헬퍼 함수 사용

**주요 변경 사항**:

#### 1-1. Order ↔ OrderDoc 매퍼 함수

**`buildOrderDocFromPayload`**: 도메인 Order → Firestore OrderDoc 변환
- `CreateOrderPayload`를 받아 `OrderDoc` 형태로 변환
- `serverTimestamp()` 사용하여 `createdAt`, `updatedAt`, `timeline.pending` 설정
- 주문 생성 시 사용

**`buildOrderFromDoc`**: Firestore OrderDoc → 도메인 Order 변환
- Firestore `Timestamp`를 도메인 `string` (ISO 형식)로 변환
- Mock 모드 호환성 유지 (`{ seconds, nanoseconds }` 형태도 처리)
- 주문 조회 시 사용

#### 1-2. Mock 모드 함수 분리

- `createOrderMock`: 기존 localStorage 기반 주문 생성 로직
- `getOrdersByUserMock`: 기존 localStorage 기반 사용자 주문 목록 조회
- `getOrderByIdMock`: 기존 localStorage 기반 주문 단건 조회

**효과**: Mock 모드와 Firebase 모드가 명확히 분리되어 코드 가독성 향상

#### 1-3. Firebase 분기 구현

**`createOrder`**:
- 기존: `collection(db, 'orders')` 직접 사용
- 변경: `storeOrdersCollection(storeId)` 사용 (stores/{storeId}/orders 구조)
- `buildOrderDocFromPayload`로 OrderDoc 생성 후 `addDoc` 호출
- 생성된 문서를 `getDoc`으로 읽어서 `buildOrderFromDoc`로 변환하여 반환

**`getOrdersByUser`**:
- 기존: `collection(db, 'orders')` 직접 사용
- 변경: `storeOrdersCollection(storeId)` 사용
- `where('userId', '==', userId)`, `orderBy('createdAt', 'desc')` 쿼리
- 결과를 `buildOrderFromDoc`로 변환하여 반환

**`getOrderById`**:
- 기존: `doc(db, 'orders', orderId)` 직접 사용
- 변경: `storeOrderDocRef(storeId, orderId)` 사용
- 결과를 `buildOrderFromDoc`로 변환하여 반환

## 📊 Order ↔ OrderDoc 매핑 상세

### 도메인 Order 타입 (기존)

```typescript
interface Order {
  orderId: string;
  userId: string;
  storeId: string;
  items: OrderItem[];
  // ...
  createdAt: FirebaseTimestamp | string;  // Mock: string, Firebase: Timestamp
  updatedAt: FirebaseTimestamp | string;
  timeline: {
    pending?: Timestamp;
    accepted?: Timestamp;
    preparing?: Timestamp;  // OrderDoc의 cooking과 매핑
    completed?: Timestamp;
    canceled?: Timestamp;
  };
}
```

### Firestore OrderDoc 타입 (STEP 2에서 정의)

```typescript
interface OrderDoc {
  orderId: string;
  userId: string;
  storeId: string;
  items: Array<{...}>;
  // ...
  createdAt: Timestamp;  // Firestore Timestamp
  updatedAt: Timestamp;
  timeline: {
    pending?: Timestamp;
    accepted?: Timestamp;
    cooking?: Timestamp;  // Order의 preparing과 매핑
    delivering?: Timestamp;
    completed?: Timestamp;
    canceled?: Timestamp;
  };
}
```

### 변환 로직

1. **Timestamp → string 변환**:
   - Firestore `Timestamp.toDate().toISOString()` 사용
   - Mock 모드 호환: `{ seconds, nanoseconds }` 형태도 처리

2. **필드 매핑**:
   - `OrderDoc.timeline.cooking` → `Order.timeline.preparing`
   - `OrderDoc.timeline.delivering` → `Order.timeline.delivering` (향후 확장)

3. **옵션 필드 처리**:
   - `couponId`, `email`, `requests`, `deliveryAddress`, `cashReceipt`, `taxInvoice` 등 선택 필드 정확히 매핑
