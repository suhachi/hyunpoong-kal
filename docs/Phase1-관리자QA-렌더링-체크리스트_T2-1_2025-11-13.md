## 검사 방법

1) DevTools 콘솔에서 에러 수집 도우미 설치
```js
// 1. 에러/경고 수집기 설치 (페이지 내 전역)
window.__qa = { errors: [], unhandled: [] };
(function(){
  const origError = console.error;
  console.error = function(...args){
    try { window.__qa.errors.push({ path: location.pathname, args }); } catch {}
    origError.apply(console, args);
  }
  window.addEventListener('error', (e)=>{
    try { window.__qa.unhandled.push({ path: location.pathname, msg: e.message }); } catch {}
  });
})();
```

2) 아래 11개 메뉴를 순서대로 클릭해 화면이 보이는지 확인
3) 완료 후 콘솔에서 수집 결과 출력
```js
({ errors: window.__qa?.errors, unhandled: window.__qa?.unhandled })
```
