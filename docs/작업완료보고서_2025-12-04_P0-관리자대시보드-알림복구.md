## 📊 작업 개요

### 문제 상황
- **사용자 보고**: "만나서결제뿐만아니라 배달,포장 모두다 주문시 관리자대시보드에는 아무런반응이없어"
- **심각도**: 🔴 P0 Critical
- **영향 범위**: 모든 주문 유형 (배달/포장/만나서결제)
- **비즈니스 영향**: 관리자가 신규 주문을 실시간으로 인지할 수 없음

### 근본 원인
1. **Dashboard.tsx가 완전히 정적인 페이지**
   - Firestore `onSnapshot` 리스너가 한 줄도 없음
   - 페이지 로드 시 1회만 데이터 fetch
   - 실시간 알림 시스템 미구현

2. **완성된 알림 컴포넌트가 미사용 상태**
   - `AdminOrderAlert` 컴포넌트는 이미 완벽하게 구현됨
   - Dashboard에서 import조차 하지 않음
   - Orders 페이지는 자체 알림 로직으로 정상 작동

3. **PRD 설계는 완벽했으나 구현 누락**
   - 설계 문서에는 실시간 알림 시스템이 상세히 명시됨
   - 실제 코드 작성 시 핵심 기능이 완전히 빠짐
