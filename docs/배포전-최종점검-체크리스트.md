## 🔍 로컬에서 최종 점검 (배포 전 필수)

### 1. 개발 서버 실행
```bash
cd hyunpoong-kal
npm run dev
```
- **URL**: http://localhost:5173
- **용도**: 실시간 개발 환경에서 모든 기능 테스트

### 2. 빌드 후 미리보기 (프로덕션 빌드 테스트)
```bash
npm run build
npm run preview
```
- **용도**: 실제 배포될 빌드와 동일한 환경에서 테스트
- **확인 사항**: 빌드 산출물이 정상 작동하는지
