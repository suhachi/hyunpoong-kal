## 4. 스크립터 주요 특징

### 4-1. 기술 스택

- **Node.js 내장 모듈만 사용**
  - `node:fs/promises`: 파일 시스템 작업
  - `node:path`: 경로 처리
  - `node:readline`: CLI 입력 처리
- **외부 의존성 없음**: `fs-extra`, `prompts` 등 불필요
- **ESM 스타일**: `import` 문 사용

### 4-2. 안전장치

1. **원본 레포 보호**
   - 원본 프로젝트 코드는 절대 수정하지 않음
   - `clones/` 디렉터리 아래에만 출력

2. **자동 롤백**
   - 복제 중 오류 발생 시 생성된 디렉터리 자동 삭제
   - 친절한 에러 메시지 출력

3. **중복 방지**
   - 대상 디렉터리가 이미 존재하면 오류 메시지 출력 후 종료

### 4-3. 생성되는 파일

1. **package.json** (자동 수정)
   - `name`: `hp-store-{storeId}`
   - `version`: `0.1.0`
   - `description`: `{storeName} 전용 현풍닭칼국수 PWA 앱`

2. **.env.local.example** (새로 생성)
   - Firebase 설정 placeholder (`__FILL_ME__`)
   - 지도 API 키 placeholder (`__OPTIONAL__`)

3. **README_STORE.md** (새로 생성)
   - 점주용 사용설명서
   - 검증 체크리스트 포함
   - 롤백 방법 안내

4. **docs/STORE_SETUP_GUIDE_{storeId}.md** (새로 생성)
   - 상세 셋업 가이드
   - 필수 체크리스트
