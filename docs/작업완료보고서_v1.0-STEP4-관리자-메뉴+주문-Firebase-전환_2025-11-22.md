## 📋 작업 개요

### 목표

v1.0 Firebase 실연동을 위한 **관리자 영역 메뉴/주문 관리 API Firebase 전환** 완료. 관리자 메뉴 관리(CRUD) 및 주문 관리(조회 + 상태 변경)를 Firestore 기반으로 동작하도록 전환하되, Mock 모드는 그대로 유지.

### 작업 범위

- ✅ Menu ↔ MenuDoc 매퍼 함수 구현
- ✅ 관리자 메뉴 API Firebase 분기 구현 (`src/lib/admin/menus.api.ts`)
  - `getMenus` (목록 조회)
  - `getMenuById` (단건 조회)
  - `createMenu` (생성)
  - `updateMenu` (수정)
  - `deleteMenu` (삭제)
  - `toggleMenuAvailability` (품절/판매 토글)
  - `updateMenuAvailableHours` (시간제 설정)
- ✅ 관리자 주문 API Firebase 분기 구현 (`src/lib/admin/orders.api.ts`)
  - `fetchOrders` (목록 조회, 필터/정렬)
  - `fetchOrderById` (단건 조회)
  - `updateOrderStatus` (상태 변경)
- ✅ Mock 모드 완전 보전 (기존 로직 100% 유지)
- ✅ 빌드 검증 완료

**중요**: 이번 스텝에서는 **Cloud Functions, 포인트/쿠폰/리뷰 연동은 하지 않음**. 관리자 메뉴/주문 관리에만 집중.

**`getMenus`**:
- 기존: localStorage 기반 필터링/정렬

- Firestore 쿼리: `where('category', '==', ...)`, `orderBy('order', 'asc')` 등
- 클라이언트 측 필터링: 검색어, `availableOnly` (Firestore 쿼리로 처리 어려운 경우)

**`getMenuById`**:
- 기존: localStorage에서 조회
- 변경: `storeMenuDocRef(storeId, menuId)` 사용

**`createMenu`**:
- 기존: localStorage에 저장
- 변경: `storeMenusCollection(storeId)`에 `addDoc` 호출
- 중복 확인: Firestore 쿼리로 동일 이름+카테고리 메뉴 확인

**`updateMenu`**:
- 기존: localStorage 업데이트
- 변경: `storeMenuDocRef(storeId, menuId)`에 `updateDoc` 호출
- 필드별 업데이트: `name`, `category`, `price`, `description`, `image` (→ `imageUrl`)

**`deleteMenu`**:
- 기존: localStorage에서 삭제
- 변경: `storeMenuDocRef(storeId, menuId)`에 `deleteDoc` 호출

**`toggleMenuAvailability`**:
- 기존: localStorage 업데이트
- 변경: `storeMenuDocRef(storeId, menuId)`에 `updateDoc` 호출 (`isAvailable` 필드)

**`updateMenuAvailableHours`**:
- 기존: localStorage 업데이트
- 변경: `storeMenuDocRef(storeId, menuId)`에 `updateDoc` 호출 (`availableHours` 필드)

## 📊 Menu ↔ MenuDoc 매핑 상세

### 도메인 Menu 타입 (기존)

```typescript
interface Menu {
  menuId: string;
  category: MenuCategory;
  name: string;
  price: number;
  description: string;
  image: string;  // Base64 또는 URL
  badges: MenuBadge[];
  options?: {...};
  optionGroups?: MenuOptionGroup[];
  allergens: string[];
  origin: string;
  isAvailable: boolean;
  availableHours?: { start: string; end: string };
  order: number;
  // createdAt, updatedAt는 타입에 없음 (필요시 추가 가능)
}
```

### Firestore MenuDoc 타입 (STEP 2에서 정의)

```typescript
interface MenuDoc {
  menuId: string;
  storeId: string;
  category: MenuCategory;
  name: string;
  price: number;
  description: string;
  imageUrl?: string;  // Firebase Storage URL
  imagePath?: string;  // Storage 경로 (업로드용)
  badges: MenuBadge[];
  options?: {...};
  optionGroups?: string[];  // 옵션 그룹 ID 참조
  allergens: string[];
  origin: string;
  isAvailable: boolean;
  availableHours?: { start: string; end: string };
  order: number;
  createdAt: Timestamp;
  updatedAt: Timestamp;
}
```

### 변환 로직

1. **필드 매핑**:
   - `Menu.image` → `MenuDoc.imageUrl` (생성/수정 시)
   - `MenuDoc.imageUrl` → `Menu.image` (조회 시)
   - `MenuDoc.imagePath`는 Storage 업로드 시 설정 (이번 STEP에서는 미사용)

2. **옵션 그룹**:
   - `Menu.optionGroups` (객체 배열) → `MenuDoc.optionGroups` (ID 문자열 배열)
   - 현재는 빈 배열로 처리, 향후 STEP 5~7에서 구현 예정

3. **Timestamp 변환**:
   - Firestore `Timestamp.toDate().toISOString()` 사용
   - Mock 모드 호환: `{ seconds, nanoseconds }` 형태도 처리
