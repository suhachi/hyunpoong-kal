## 🔧 기술적 세부사항

### Kakao Maps SDK 로드

**로드 방식**:
- 동적 스크립트 태그 생성
- `autoload=false`로 설정 후 수동 로드
- `libraries=services` 포함 (주소 검색 등 확장 대비)

**에러 처리**:
- 키가 없을 경우 콘솔 에러 + Promise reject
- 스크립트 로드 실패 시 에러 메시지 표시

### Firestore 저장 구조

**필드 경로**: `stores/{storeId}.address.lat`, `stores/{storeId}.address.lng`

**타입**: `number | undefined`

**저장 방식**:
- `setDoc(..., { merge: true })` 사용
- lat/lng가 없으면 `undefined`로 저장 (필드 생략)
