## 🔴 발견된 문제 요약

### 1. Firestore 인덱스 누락 (Critical)

다음 쿼리들이 Firestore 인덱스를 필요로 하지만, 현재 `firestore.indexes.json`이 비어있음:

#### 1-1. 메뉴 조회 인덱스 필요
**파일**: `src/lib/admin/menus.api.ts`  
**컬렉션**: `stores/{storeId}/menus`

**필요한 인덱스**:
1. `category` (ASC) + `order` (ASC) + `createdAt` (ASC)
2. `category` (ASC) + `name` (ASC) + `createdAt` (ASC)
3. `category` (ASC) + `price` (ASC) + `createdAt` (ASC)
4. `category` (ASC) + `price` (DESC) + `createdAt` (ASC)

**에러 메시지**:
```
Failed to fetch menus from Firestore: FirebaseError: The query requires an index.
```

---

#### 1-2. 리뷰 조회 인덱스 필요
**파일**: `src/lib/admin/reviews.api.ts`  
**컬렉션**: `stores/{storeId}/reviews`

**필요한 인덱스**:
1. `isVisible` (ASC) + `rating` (DESC)
2. `isVisible` (ASC) + `createdAt` (DESC)

**에러 메시지**:
```
Failed to fetch reviews from Firestore: FirebaseError: The query requires an index.
```

---

#### 1-3. 고객지원 세션 조회 인덱스 필요
**파일**: `src/lib/admin/support.api.ts`  
**컬렉션**: `support_sessions`, `support_messages`

**필요한 인덱스**:
1. `support_sessions`: `open` (ASC) + `lastAt` (DESC)
2. `support_sessions`: `assignedTo` (ASC) + `lastAt` (DESC)
3. `support_messages`: `sessionId` (ASC) + `at` (ASC)

**에러 메시지**:
```
Failed to load sessions: FirebaseError: The query requires an index.
```
