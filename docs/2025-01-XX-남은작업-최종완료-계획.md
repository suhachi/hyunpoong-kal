## 🔧 기술적 해결 방안

### Lazy Loading 문제 해결

**문제**: `AdminSettingsCenter`가 lazy loading으로 로드되어 Suspense fallback 동안 `admin-settings-page-root`가 없음

**해결 방안:**

1. **테스트 환경에서 일반 import 사용**
   ```typescript
   // App.tsx
   const AdminSettingsCenter = process.env.NODE_ENV === 'test'
     ? require('./pages/admin/Settings').AdminSettingsCenter
     : lazy(() => import('./pages/admin/Settings').then(m => ({ default: m.AdminSettingsCenter })));
   ```

2. **Suspense Fallback에 data-testid 추가**
   ```typescript
   <Suspense fallback={<div data-testid="admin-settings-page-root">로딩 중...</div>}>
     <Routes>...</Routes>
   </Suspense>
   ```

3. **대기 전략 개선**
   ```typescript
   // expect.poll() 사용
   await expect.poll(async () => {
    return await page.locator('[data-testid="admin-settings-page-root"]').count();
   }, {
    message: 'admin-settings-page-root should appear',
    timeout: 20000,
   }).toBeGreaterThan(0);
   ```

### 렌더링 타이밍 문제 해결

**문제**: React Router가 완전히 마운트되기 전에 테스트가 실행됨

**해결 방안:**

1. **더 긴 타임아웃 사용**
   ```typescript
   await expect(page.getByTestId('admin-settings-page-root')).toBeVisible({ timeout: 20000 });
   ```

2. **Polling 방식 사용**
   ```typescript
   await expect.poll(async () => {
     const count = await page.locator('[data-testid="admin-settings-page-root"]').count();
     return count;
   }, {
     message: 'admin-settings-page-root should appear',
     timeout: 20000,
   }).toBeGreaterThan(0);
   ```

3. **URL 확인 후 대기**
   ```typescript
   await expect(page).toHaveURL(/\/admin\/settings/, { timeout: 10000 });
   await page.waitForTimeout(1000);
   await expect(page.getByTestId('admin-settings-page-root')).toBeVisible({ timeout: 15000 });
   ```
