### 5. AddressSearch 업데이트

**파일**: `src/components/admin/AddressSearch.tsx`

**변경 사항**:
- 구글맵 Geocoding API 우선 사용
- 구글맵 실패 시 카카오맵 주소 검색 fallback
- `mapProvider` 상태로 현재 사용 중인 지도 서비스 추적

**구글맵 Geocoding**:
```typescript
const geocoder = new window.google.maps.Geocoder();
geocoder.geocode({ address: searchQuery }, (results, status) => {
  // results[0].formatted_address: 주소
  // results[0].geometry.location: 좌표
});
```

**카카오맵 주소 검색** (fallback):
```typescript
const geocoder = new window.kakao.maps.services.Geocoder();
geocoder.addressSearch(searchQuery, (result, status) => {
  // result[0].address_name: 주소
  // result[0].y, result[0].x: 좌표
});
```

## 🎯 주요 기능

### 1. 위치 선택 (관리자)

**경로**: `/admin/settings` → "가게 정보" 탭 → "위치(지도)"

**기능**:
- 구글맵 지도 표시
- 지도 클릭으로 위치 선택
- 마커 드래그로 위치 조정
- 선택한 좌표 자동 저장

### 2. 위치 표시 (고객)

**경로**: `/my` → "가게 정보" 버튼 → 모달 하단

**기능**:
- 구글맵 지도 표시 (읽기 전용)
- 가게 위치 마커 표시
- 좌표 없을 시 안내 문구

### 3. 주소 검색 (관리자)

**경로**: `/admin/settings` → "가게 정보" 탭 → "주소 *"

**기능**:
- 구글맵 Geocoding API 사용
- 주소 검색 시 자동으로 좌표 획득
- 검색 결과가 없으면 주소만 저장
