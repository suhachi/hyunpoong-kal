## 1. 작업 개요
**이슈명**: 결제 완료 후 `/order/:id`로 이동하지 않고 `/cart` 또는 `/` 로 잘못 리다이렉트 및 E2E 실패.  
**영향 범위**: 고객 주문 생성 플로우, OrderTracking 진입, 관리자 주문 조회 E2E.  
**목표**: 결제 성공 시 올바른 OrderTracking 페이지 이동 + 토스트 안정 검증 + 관리자 화면에서 동일 주문 확인 E2E 녹색화.

## 2. 초기 증상 & 오류 로그
| 증상 | 상세 | 원인 추정 단계 |
|------|------|----------------|
| 결제 후 `/cart`로 재리다이렉트 | useEffect(items.length===0) 발동 | clearCart() 실행 순서 문제 |
| 결제 후 `/` 루트로 남음 | `/order/:id` 라우트 미매칭 | 잘못된 라우트 정의 (`orders/:orderId`) |
| 토스트 미표시로 테스트 실패 | 텍스트 기반 selector flakiness | 네비게이션 즉시 발생 + 문자열 매칭 취약 |
| 관리자 화면 주문 ID 미검출 | 새 browser context에서 localStorage 비공유 | Mock 저장 방식 특성 |

---
## 3. 근본 원인 분석 (Root Cause)
1. **라우트 정의 불일치**: 실제 App에서 `orders/:orderId` 로 정의, 테스트 및 문서는 `/order/:orderId` 사용 → 매칭 실패 시 fallback.
2. **clearCart 시점**: navigate 이전 혹은 동일 tick 내 실행 → Checkout 잔존 useEffect가 빈 cart 감지 후 `/cart` 리다이렉트.
3. **토스트 탐지 불안정**: `toast.success('문자열')` 즉시 후 빠른 라우트 전환 → 가시 영역이 테스트 타임아웃내 잡히지 않는 경우 발생.
4. **Mock 저장소 분리**: 고객 context localStorage에 저장된 `orders` 객체가 관리자 전용 새 브라우저 context에는 존재하지 않아 목록에서 ID가 나타나지 않음.

## 5. 변경 코드 요약 (Key Diffs)
### App.tsx
- `Route path="orders/:orderId"` → `Route path="order/:orderId"`

### Checkout.tsx (핵심 부분)
```ts
// 주문 완료 플래그
isOrderCompleting.current = true;
// 토스트 + 짧은 지연 후 navigate
toast.success(<span data-testid="toast.order.success">주문이 접수되었습니다</span>, { duration: 5000 });
await new Promise(r => setTimeout(r, 75));
navigate(`/order/${orderId}?result=on_site`);
// clearCart 지연 처리
setTimeout(() => clearCart(), 100);
```

### order-flow.spec.ts (관리자 확인 로직)
```ts
const ordersRaw = await page.evaluate(() => localStorage.getItem('orders'));
const adminContext = await browser.newContext();
if (ordersRaw) {
  await adminContext.addInitScript(data => localStorage.setItem('orders', data as string), ordersRaw);
}
// orderId 포함 여부 폴링
await expect.poll(async () => {
  return await adminPage.evaluate(oid => (
    Array.from(document.querySelectorAll('[data-testid="admin.orders.item.summary"]'))
      .some(el => el.textContent?.includes(oid))
  ), orderId);
}).toBeTruthy();
```
