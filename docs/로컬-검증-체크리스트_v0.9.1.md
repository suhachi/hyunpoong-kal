## ⚠️ 문제 발견 시 대응

### 화면/콘솔 에러 발견

1. **콘솔 에러 메시지 확인**
   - 어떤 컴포넌트/파일에서 문제가 발생했는지 확인
   - 에러 스택 트레이스 확인

2. **관련 파일 확인**
   ```bash
   git diff src/pages/app/Home.tsx
   git diff src/pages/admin/Dashboard.tsx
   # 등 문제가 발생한 파일만 확인
   ```

3. **필요 시 롤백**
   ```bash
   git restore src/pages/app/Home.tsx
   # 또는 해당 파일만 롤백
   ```

4. **재검증**
   - `npm run dev` 재시작
   - 해당 경로 재검증
