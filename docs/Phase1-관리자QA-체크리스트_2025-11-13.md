## 📝 작성 방법

### 각 페이지 체크 순서
1. **해당 URL로 접속**
2. **페이지 로딩 확인**:
   - ✅ 정상: 체크박스 체크
   - ❌ 흰 화면/에러: 체크하지 않고 에러 기록
3. **브라우저 콘솔 확인** (F12 → Console 탭):
   - 🔴 빨간 에러 메시지가 있는지 확인
   - 있다면 복사하여 "발견된 에러"에 기록
4. **토스트 메시지 확인**:
   - 페이지 진입 시 자동으로 뜨는 에러 토스트가 있는지 확인
   - 있다면 내용을 "발견된 에러"에 기록
