### 문제 1: AuthContext의 초기화 로직

**파일**: `src/contexts/AuthContext.tsx` (Line 100-111)


- ✅ `setUser()` 호출로 user 상태 업데이트
- ⚠️ **BUT**: `localStorage.getItem('mockUser')`가 `null`이면 `user = null`

### 문제 2: getCurrentUser()의 불일치

**파일**: `src/lib/auth.ts` (Line 38-52)

```typescript
export function getCurrentUser(): AuthUser | null {
  if (USE_FIREBASE) {
    return null;
  }

  // Mock: localStorage에서 역할 가져오기 (테스트용)
  const mockRole = localStorage.getItem('mockRole') || 'owner'; // 기본값을 owner로 변경
  return mockRole === 'owner' || mockRole === 'admin' ? MOCK_ADMIN : MOCK_CUSTOMER;
}
```

**🔴 심각한 문제**:
1. `mockRole`을 읽음 (AuthContext와 다른 키!)
2. 기본값이 'owner'라서 권한이 있는 것처럼 보임
3. 하지만 `AuthContext`는 `mockUser`가 없으면 `user = null`
4. `ProtectedRoute`는 `useAuth()`를 사용 → `user = null` 감지 → 리다이렉트!

### 문제 3: mockLogin() 함수

**파일**: `src/lib/auth.ts` (Line 90-96)

```typescript
export function mockLogin(role: UserRole): void {
  const mockUser = role === 'owner' || role === 'admin' ? MOCK_ADMIN : MOCK_CUSTOMER;
  localStorage.setItem('mockUser', JSON.stringify(mockUser));
  localStorage.setItem('mockRole', role);
  window.location.reload();
}
```

**분석**:
- ✅ `mockUser` 저장 (AuthContext와 호환)
- ✅ `mockRole` 저장 (getCurrentUser와 호환)
- ✅ `window.location.reload()` 호출
- ⚠️ **BUT**: 페이지 새로고침 후 `AuthContext`가 `mockUser`를 읽어야 함

### 방안 B: ProtectedRoute 디버그 모드 활성화 (임시)

**목표**: 정확한 실패 지점 파악

**수정**: ProtectedRoute에 디버그 로그 추가

```typescript
// src/components/shared/ProtectedRoute.tsx

export function ProtectedRoute({ 
  children, 
  roles,
  requireAuth = true 
}: ProtectedRouteProps) {
  const { user, loading } = useAuth();
  const location = useLocation();

  // 🔍 디버그 로그
  useEffect(() => {
    console.group('🔒 ProtectedRoute Debug');
    console.log('pathname:', location.pathname);
    console.log('loading:', loading);
    console.log('user:', user);
    console.log('roles required:', roles);
    console.log('requireAuth:', requireAuth);
    
    if (user) {
      console.log('user.role:', user.role);
      console.log('roles.includes(user.role):', roles ? roles.includes(user.role) : 'N/A');
    }
    
    console.groupEnd();
  }, [user, loading, location.pathname]);

  // 기존 로직 유지
  if (loading) {
    console.log('🔒 ProtectedRoute: Loading...');
    return (
      <div className="min-h-screen bg-[#F9F6F3] flex items-center justify-center">
        <LoadingSkeleton type="page" />
      </div>
    );
  }

  if (requireAuth && !user) {
    console.log('🔒 ProtectedRoute: No user, redirecting to /login');
    return <Navigate to="/login" state={{ from: location }} replace />;
  }

  if (roles && user && !roles.includes(user.role)) {
    console.log('🔒 ProtectedRoute: Insufficient role, redirecting to /');
    return <Navigate to="/" replace />;
  }

  console.log('🔒 ProtectedRoute: Access granted');
  return <>{children}</>;
}
```
