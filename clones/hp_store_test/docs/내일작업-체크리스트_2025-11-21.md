## 🔍 문제 발생 시 대응

### 문제 1: 스크립터 실행 실패

**증상**: `npm run create:store` 실행 시 오류

**확인 사항**:
- Node.js 버전 확인 (`node --version`, 18+ 필요)
- `tsx` 패키지 설치 확인 (`npm list tsx`)
- 스크립트 파일 경로 확인

**해결 방법**:
```bash
# tsx 재설치
npm install --save-dev tsx

# 직접 실행 시도
npx tsx scripts/create-independent-store.ts
```

### 문제 2: 복제 중 오류

**증상**: 복제 중 에러 메시지 출력

**확인 사항**:
- 디스크 공간 확인
- 파일 권한 확인
- 대상 디렉터리 중복 확인

**해결 방법**:
- 스크립터가 자동으로 롤백함
- 수동 삭제: `rm -rf clones/{storeId}` (Mac/Linux) 또는 `rmdir /s /q clones\{storeId}` (Windows)

### 문제 3: 생성된 앱 빌드 실패

**증상**: `npm run build` 실패

**확인 사항**:
- `package.json`이 올바르게 수정되었는지
- 의존성이 모두 설치되었는지 (`npm install` 재실행)

**해결 방법**:
```bash
cd clones/hp_store_test
rm -rf node_modules package-lock.json
npm install
npm run build
```
