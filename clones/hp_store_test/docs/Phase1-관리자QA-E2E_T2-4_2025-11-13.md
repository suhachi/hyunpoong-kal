## 🔧 설정 파일 구조

### Playwright Config (`src/playwright.config.ts`)

```typescript
export default defineConfig({
  testDir: './e2e',                    // E2E 테스트 디렉토리
  fullyParallel: true,                 // 병렬 실행
  retries: process.env.CI ? 2 : 0,     // CI 환경에서만 재시도
  
  use: {
    baseURL: 'http://localhost:3000',  // 개발 서버 URL
    trace: 'on-first-retry',            // 재시도 시 trace 수집
    screenshot: 'only-on-failure',      // 실패 시 스크린샷
    video: 'retain-on-failure',         // 실패 시 비디오
  },

  projects: [
    { name: 'chromium', use: { ...devices['Desktop Chrome'] } },
    // firefox, webkit 등 추가 가능
  ],

  webServer: {
    command: 'pnpm dev',                // 테스트 전 dev 서버 시작
    url: 'http://localhost:3000',
    reuseExistingServer: true,          // 이미 실행 중이면 재사용
    timeout: 120000,                    // 최대 2분 대기
  },
});
```

**핵심 설정**:
- **baseURL**: `localhost:3000` (Vite dev server)
- **webServer**: 테스트 전 자동으로 `pnpm dev` 실행
- **timeout**: 120초 (dev 서버 시작 여유)

## 🚨 트러블슈팅

### 1. 포트 충돌 에러

**증상**:
```
Error: Port 3000 is already in use
```

**해결 방법**:
```powershell
# 기존 dev 서버 종료
Stop-Process -Name node -Force -ErrorAction SilentlyContinue
Stop-Process -Name vite -Force -ErrorAction SilentlyContinue

# 재실행
pnpm test:e2e:admin
```

---

### 2. USE_FIREBASE 환경변수 오류

**증상**:
```
Firebase is not initialized
```

**확인**:
- `src/config/env.ts` → `USE_FIREBASE = false` 하드코딩 확인

**해결 방법**:
```typescript
// src/config/env.ts
export const USE_FIREBASE = false; // Phase 1은 항상 false
```

---

### 3. Mock User 주입 실패

**증상**:
```
Error: Unauthorized - No user found
```

**확인**:
- Playwright의 `addInitScript`가 제대로 실행되는지 확인

**디버깅**:
```typescript
// 테스트 파일에서
test.beforeEach(async ({ page }) => {
  await page.addInitScript((admin) => {
    console.log('Injecting mock user:', admin);
    localStorage.setItem('mockUser', JSON.stringify(admin));
    localStorage.setItem('mockRole', 'owner');
  }, mockAdmin);
});
```

---

### 4. 타임아웃 에러

**증상**:
```
Test timeout of 30000ms exceeded
```

**해결 방법**:
```typescript
// playwright.config.ts
export default defineConfig({
  timeout: 60000, // 60초로 증가
  // ...
});
```

또는 개별 테스트에서:
```typescript
test('slow test', async ({ page }) => {
  test.setTimeout(60000); // 이 테스트만 60초
  // ...
});
```

---

### 5. 브라우저 설치 안 됨

**증상**:

```
Executable doesn't exist at ...
```

**해결 방법**:
```powershell
pnpm exec playwright install --with-deps chromium
```
