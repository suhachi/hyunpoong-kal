## 📋 Settings 페이지 개요

**실제 구조**: API 키 설정 가이드 센터  
**특징**: 대부분 읽기 전용 가이드, Delivery 탭만 입력 폼 제공

### 5개 탭 구성

1. **Payment** - 결제사 선택(NicePay/Toss) + CLI 가이드
2. **Delivery** - 배달 설정 입력 폼 (저장 가능)
3. **Maps** - 지도 API 가이드
4. **FCM** - FCM 진단 + 가이드
5. **Operations** - 배포 스크립트

```javascript
window.__QA__=(()=>{
  const errors=[];
  const unhandled=[];
  const push=(arr,type,args)=>arr.push({
    type,
    args:[...args],
    time:new Date().toISOString(),
    path:location.pathname
  });
  const orig=console.error;
  console.error=function(...a){
    push(errors,'console.error',a);
    return orig.apply(console,a);
  };
  window.addEventListener('error',e=>push(errors,'error',[e.message,e.error]));
  window.addEventListener('unhandledrejection',e=>unhandled.push({
    reason:e.reason,
    time:new Date().toISOString(),
    path:location.pathname
  }));
  return{dump:()=>({errors,unhandled})};
})()
```

## 📌 알려진 제한사항

### 1. Payment 탭
- **제한**: Health check는 Mock 데이터 반환 (Firebase Functions 미구현)
- **영향**: 실제 연결 상태 확인 불가 (UI는 정상 동작)

### 2. Delivery 탭
- **제한**: 저장은 Firestore Mock 모드 (USE_FIREBASE=false)
- **영향**: 실제 DB 저장 안 됨, localStorage 기반

### 3. Maps 탭
- **제한**: 환경 변수 읽기만 가능 (.env.local 수정은 수동)
- **영향**: UI에서 직접 키 입력 불가

### 4. FCM 탭
- **제한**: 진단 기능은 브라우저 API 기반
- **영향**: 실제 FCM 서버 연결 테스트 불가

### 5. Operations 탭
- **제한**: 읽기 전용 가이드 (배포 상태 실시간 확인 불가)
- **영향**: 실제 배포 실행은 CLI에서만 가능
