### 3. 번들 크기 분석 스크립트 생성

**파일:** `scripts/print-dist-size.cjs`

#### 기능:

- dist 디렉터리 전체 크기 계산 및 출력
- dist/assets 내 파일별 크기 출력 (크기 순 정렬)
- JS 파일 총합 및 개수 요약
- CSS 파일 총합 및 개수 요약
- 사용자 친화적인 바이트 포맷팅 (B, KB, MB, GB)

#### 사용 방법:

```bash
# 빌드 후 분석
npm run analyze:dist

# 또는 직접 실행
node scripts/print-dist-size.cjs
```

#### 출력 예시:

```
📦 dist 전체 크기: 1.74 MB

📁 dist/assets 파일별 크기:
- index-BmFDHzGH.js: 1.62 MB
- index-uXLsTfHE.css: 90.60 KB
- index.esm-Bku73gSK.js: 23.94 KB
- manifest-CJkVJblq.webmanifest: 553.00 B

📊 JS 파일 총합: 1.64 MB (2개 파일)
📊 CSS 파일 총합: 90.60 KB (1개 파일)

✅ 분석 완료
```
