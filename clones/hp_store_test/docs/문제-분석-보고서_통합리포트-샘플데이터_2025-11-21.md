## 🔍 문제 확인

### 발견된 문제
통합 리포트 페이지(`/admin/integrated-analytics`)에서 **Mock 모드일 때 하드코딩된 샘플 데이터**가 표시되고 있습니다.

### 영향 범위
- **파일:** `src/lib/admin/integrated-analytics.api.ts`
- **함수 수:** 10개 함수 모두 샘플 데이터 포함
- **표시되는 데이터:**
  - 시간대별 주문 분석 (10시~21시 주문 수)
  - 요일별 매출 (일~토 매출액)
  - 메뉴별 성과 (5개 메뉴)
  - 쿠폰 효과 (3개 쿠폰 타입)
  - 포인트 효과
  - 리뷰 분석
  - 배달 성과
  - 알림 효과
  - KPI 지표 (매출, 고객, 평점 등)

## 📝 권장 해결 방법

### 1단계: 모든 샘플 데이터를 0/빈 배열로 변경

각 함수에서 Mock 모드일 때:
- **숫자 값:** 0으로 변경
- **배열:** 빈 배열 `[]`로 변경
- **객체:** 기본값만 포함 (0 또는 빈 값)

### 2단계: 빈 상태 UI 처리

`IntegratedAnalytics.tsx`에서:
- 데이터가 모두 0일 때 "데이터가 없습니다" 메시지 표시
- 차트 대신 빈 상태 컴포넌트 표시

### 3단계: Mock 모드 안내 배너 추가 (선택)

FCMTab과 동일한 패턴으로:
- Mock 모드일 때 상단에 안내 배너 표시
- "현재 Mock 모드에서는 실제 데이터를 사용하지 않습니다" 안내
