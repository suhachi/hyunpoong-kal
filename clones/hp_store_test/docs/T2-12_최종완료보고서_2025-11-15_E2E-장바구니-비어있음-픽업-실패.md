## 1. 문제 요약 및 원인

- 두 테스트 모두 `#pickup` 라디오가 보이지 않아 실패
- localStorage에는 아이템이 정상적으로 담김 (테스트 로그: `장바구니 아이템 개수: 1`)
- Cart 컴포넌트는 `items.length === 0`일 때만 "장바구니가 비어있어요" 렌더링
- 테스트에서 페이지 이동 직후 UI가 비어있게 보임 → 상태 동기화 타이밍 문제

---

## 2. 코드 흐름 및 분석

- CartContext: localStorage와 React 상태를 동기화
- MenuDetail: addItem() 호출 시 localStorage에 아이템 저장, React 상태도 변경
- Cart: items.length === 0이면 "장바구니가 비어있어요"만 렌더링
- E2E 테스트: "담기" 클릭 후 바로 /cart로 이동 → React 상태가 아직 반영되지 않아 UI가 비어있음
