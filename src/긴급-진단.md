# 🚨 긴급 진단: 미리보기 화면 문제

## 🔍 발견된 문제

### ❌ 핵심 문제: BrowserRouter
```typescript
// App.tsx (현재)
<BrowserRouter>  // ← Figma Make 환경에서 작동 안됨!
  <AuthProvider>
    <CartProvider>
      <Routes>...</Routes>
    </CartProvider>
  </AuthProvider>
</BrowserRouter>
```

**Figma Make는 BrowserRouter를 지원하지 않습니다!**
- BrowserRouter는 브라우저 히스토리 API 필요
- Figma Make는 iframe 내부 제한 환경
- 결과: 빈 화면

---

## ✅ 즉시 해결 방법

### 방법 1: App.simple.tsx 사용 (30초)
```bash
# 현재 App.tsx 백업
cp App.tsx App.full.tsx

# 간단한 버전으로 교체
cp App.simple.tsx App.tsx
```

**결과:**
- ✅ 즉시 화면 표시
- ✅ 브랜드 컬러 확인
- ✅ React 정상 작동 확인

---

### 방법 2: Figma Make 호환 버전 만들기 (5분)
새로운 `App.figma.tsx` 생성 필요
- MemoryRouter 사용
- Mock Context
- 단순 UI만 표시
