## ⚡ **30초 빠른 시작**

### 방법 1: 명령어만 복사

```bash
npm install
cp .env.example .env
npm run dev
```

### 방법 2: Cursor AI에게 시키기

Cursor AI를 열고 다음을 복사:

