## 🚨 발견된 문제

### ❌ 1번 문제: BrowserRouter (핵심 원인)

**코드:**
```typescript
// App.tsx (이전)
import { BrowserRouter } from 'react-router-dom';

export default function App() {
  return (
    <BrowserRouter>  // ← Figma Make 미지원!
      <Routes>...</Routes>
    </BrowserRouter>
  );
}
```

**원인:**
- `BrowserRouter`는 브라우저의 History API 필요
- Figma Make는 iframe 내 제한된 환경
- History API 접근 불가 → 렌더링 실패

**증상:**
- ❌ 빈 화면
- ❌ 콘솔 에러: "Cannot read property 'pushState'"
- ❌ 라우팅 초기화 실패

---

### ❌ 2번 문제: Context Providers (Firebase 초기화)

**코드:**
```typescript
// App.tsx (이전)
<AuthProvider>  // ← Firebase 초기화 시도
  <CartProvider>  // ← Firebase 초기화 시도
    {children}
  </CartProvider>
</AuthProvider>
```

**원인:**
- `AuthProvider`에서 Firebase Auth 초기화
- `CartProvider`에서 Firestore 접근 시도
- Figma Make 환경에서 Firebase SDK 초기화 실패

**증상:**
- ⚠️ Firebase initialization warning
- ⚠️ Network request timeout
- ⚠️ Context 초기화 지연

---

### ❌ 3번 문제: 복잡한 앱 구조

**통계:**
```
전체 라우트: 50+ 개
Context Providers: 3개 (Auth, Cart, Theme)
페이지 컴포넌트: 30+ 개
외부 API 호출: 10+ 개
```

**원인:**
- Figma Make는 간단한 미리보기 환경
- 복잡한 앱 구조 렌더링 부담
- 초기 로딩 타임아웃


## 🔍 상세 분석

### BrowserRouter vs 순수 JSX

**BrowserRouter 요구사항:**
```typescript
// BrowserRouter가 필요로 하는 것들
window.history.pushState     ❌ Figma Make 제한
window.history.replaceState  ❌ Figma Make 제한
window.location              ⚠️ 제한적
popstate event               ❌ iframe 내 제한
```

**순수 JSX 요구사항:**
```typescript
// 순수 JSX가 필요로 하는 것들
React.createElement          ✅ 항상 가능
Virtual DOM                  ✅ 항상 가능
inline styles                ✅ 항상 가능
```

### Context Providers 문제

**AuthProvider 초기화:**
```typescript
// contexts/AuthContext.tsx
export function AuthProvider({ children }) {
  useEffect(() => {
    // Firebase Auth 초기화
    const unsubscribe = onAuthStateChanged(auth, (user) => {
      // ❌ Figma Make에서 실패
      setUser(user);
    });
    return unsubscribe;
  }, []);
  
  return <AuthContext.Provider>{children}</AuthContext.Provider>;
}
```

**문제점:**
- Firebase SDK 네트워크 요청
- IndexedDB 접근 시도
- localStorage 접근
- 모두 Figma Make에서 제한적
