# 🏪 화이트라벨 배달앱 복제 가이드

**목적**: 현풍닭칼국수 PWA를 템플릿으로 사용하여 다른 음식점의 배달앱 만들기  
**난이도**: ⭐⭐ 중급  
**소요 시간**: 2시간

---

## 📋 개요

이 가이드는 현풍닭칼국수 PWA 프로젝트를 복제하여 **새로운 음식점의 배달앱**을 만드는 방법을 설명합니다.

### 변경 가능한 요소

```
✅ 가게명
✅ 브랜드 컬러 (3가지)
✅ 로고
✅ 메뉴 (전체)
✅ 연락처/주소
✅ 영업시간
✅ 배달비/최소주문금액
✅ Firebase 프로젝트
✅ NICEPAY MID
```

### 유지되는 요소

```
✅ 전체 기능 (주문/결제/배달추적/리뷰)
✅ 관리자 대시보드
✅ PWA 기능
✅ 디자인 시스템 구조
✅ 코드 구조
```

---

## 🎯 3단계 변경 프로세스

### **1단계: 브랜드 정보 변경** ⏱️ 30분

브랜드명, 컬러, 로고를 변경합니다.

### **2단계: 메뉴 데이터 변경** ⏱️ 30분

메뉴, 가격, 옵션을 변경합니다.

### **3단계: 설정 및 배포** ⏱️ 60분

Firebase, NICEPAY, 환경 변수를 설정하고 배포합니다.

### 2-3. 기본 설정 변경

**배달비 설정**

Firestore에서 직접 변경하거나, 관리자 대시보드 → 설정에서 변경:

```typescript
// 관리자 대시보드 → 설정 → 운영 설정
{
  deliveryFee: {
    base: 3000,           // 기본 배달비
    perKm: 500,           // km당 추가 비용
    freeThreshold: 30000  // 무료 배달 최소 금액
  },
  minOrderAmount: 15000   // 최소 주문 금액
}

# 1. Firebase Console에서 새 프로젝트 생성

# → API Key, Project ID 등
```

---

### 3-2. 환경 변수 설정

**파일**: `.env`

```bash
# 기존 (현풍닭칼국수)
VITE_FIREBASE_PROJECT_ID=hp-kal
VITE_NICEPAY_MID=HP_MID_001

# 새로운 가게 (부산갈비집)
VITE_FIREBASE_PROJECT_ID=busan-galbi        # ← 변경
VITE_FIREBASE_API_KEY=AIzaSy...             # ← 변경
VITE_FIREBASE_AUTH_DOMAIN=busan-galbi...    # ← 변경
VITE_FIREBASE_STORAGE_BUCKET=busan-galbi... # ← 변경
VITE_FIREBASE_MESSAGING_SENDER_ID=123...    # ← 변경
VITE_FIREBASE_APP_ID=1:123...               # ← 변경

# NICEPAY MID (새 가맹점 번호)
VITE_NICEPAY_MID=BUSAN_MID_001              # ← 변경
VITE_NICEPAY_CLIENT_KEY=your_new_key        # ← 변경
```

---

### 3-3. Firebase 프로젝트 연결

```bash
# 1. Firebase 로그인
firebase login

# 2. 새 프로젝트로 전환
firebase use busan-galbi

# 3. Functions Config 설정 (새 가맹점 정보)
firebase functions:config:set \
  nicepay.merchant_id="BUSAN_MID_001" \
  nicepay.merchant_key="YOUR_NEW_KEY" \
  delivery.secret="new_secret_key" \
  fcm.server_key="YOUR_FCM_KEY"

# 4. 확인
firebase functions:config:get
```
