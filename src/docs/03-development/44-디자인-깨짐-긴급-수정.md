### 구체적 문제점 (3가지)

#### **1. Margin/Padding 충돌 (라인 20-28)**

```css
/* ❌ 잘못된 코드 */
*,
*::before,
*::after {
  margin: 0 !important;
  padding: 0 !important;
  box-sizing: border-box !important;
}

* {
  margin: revert !important;  /* ← 위와 충돌! */
  padding: revert !important; /* ← 위와 충돌! */
}
```

**문제:**
- 먼저 모든 요소의 margin/padding을 0으로 강제
- 그 다음 revert로 되돌림
- 결과: 브라우저가 혼란스러워서 간격이 깨짐

**영향:**
- 모든 컴포넌트의 레이아웃이 무너짐
- 카드, 버튼, 텍스트 간격이 이상해짐

---

#### **2. 버튼 배경 제거 (라인 217)**

```css
/* ❌ 잘못된 코드 */
button {
  appearance: none !important;
  -webkit-appearance: none !important;
  -moz-appearance: none !important;
  background: none !important;  /* ← 모든 버튼 배경 제거! */
  border: none !important;
  cursor: pointer !important;
}
```

**문제:**
- 모든 버튼의 배경을 강제로 제거
- 버튼이 투명해져서 보이지 않음

**영향:**
- Primary 버튼이 안 보임
- CTA 버튼이 클릭 불가능해 보임
- 사용자 경험 완전 파괴

---

#### **3. GPU 가속 남용 (라인 472-476)**

```css
/* ❌ 잘못된 코드 */
* {
  /* GPU 가속 활성화 */
  will-change: transform !important;
  transform: translateZ(0) !important;  /* ← 모든 요소 변형! */
  backface-visibility: hidden !important;
}
```

**문제:**
- 모든 요소에 transform 적용
- 레이아웃이 3D 공간으로 이동
- 요소들이 정확한 위치에 표시되지 않음

**영향:**
- 컴포넌트 위치가 어긋남
- 텍스트가 흐릿해짐 (subpixel rendering 깨짐)
- 스크롤 성능 저하
