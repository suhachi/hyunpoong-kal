## ♿ Part 2: 접근성(a11y) 개선

### 구현 내용

#### 2.1 Skip to Content 링크
```
/components/shared/SkipToContent.tsx
```

**기능:**
- 스크린 리더 사용자를 위한 본문 바로가기 링크
- 키보드 포커스 시에만 표시
- Tab 키로 첫 번째 요소로 접근 가능

**사용 위치:**
- App.tsx 최상단

#### 2.2 ARIA 속성 추가

##### AppHeader.tsx
```typescript
✅ <header role="banner" aria-label="사이트 헤더">
✅ <nav role="navigation" aria-label="주요 네비게이션">
✅ 장바구니 링크: aria-label="장바구니 (3개 상품)"
✅ 아이콘: aria-hidden="true"
✅ 로고: role="img" aria-label="현풍닭칼국수 로고"
```

#### 2.3 키보드 탐색 개선

**포커스 스타일:**
- 모든 인터랙티브 요소에 명확한 포커스 스타일
- `focus:ring` 및 `focus:outline` 적용
- 색상 대비 4.5:1 이상 유지

**키보드 단축키:**
- Tab: 다음 요소로 이동
- Shift+Tab: 이전 요소로 이동
- Enter/Space: 버튼 활성화
- Escape: 모달/다이얼로그 닫기

#### 2.4 스크린 리더 지원

**레이블 추가:**
- 모든 폼 input에 label 연결
- 버튼에 명확한 aria-label
- 이미지에 alt 속성

**랜드마크 역할:**
- `<header role="banner">`
- `<nav role="navigation">`
- `<main role="main">` (main-content ID)
- `<footer role="contentinfo">`

#### 2.5 색상 대비

**브랜드 컬러 검증:**
- 현풍레드 (#D61C1C) on White: 4.53:1 ✅ AA
- 먹색 (#2E1C10) on White: 14.21:1 ✅ AAA
- 신칼오렌지 (#F37021) on White: 3.08:1 ⚠️ (큰 텍스트만)
- 황동식기색 (#C7A45A) on White: 4.02:1 ✅ AA

#### 2.6 WCAG 2.1 준수 사항

**Level A:**
- ✅ 1.1.1 비텍스트 콘텐츠 (alt 텍스트)

## 📱 Part 3: PWA 오프라인 지원

### 구현 내용

#### 3.1 Service Worker
```
/public/sw.js
```

**캐싱 전략:**
- Network First (네트워크 우선, 실패 시 캐시)
- Firebase API는 항상 네트워크 요청
- POST 요청은 캐시하지 않음

**캐시 관리:**
```javascript
const CACHE_NAME = 'hyunpung-chicken-v1.0.0';

// 정적 리소스 사전 캐싱
const STATIC_ASSETS = [
  '/',
  '/offline.html',
  '/manifest.json',
  '/icon-192.png',
  '/icon-512.png',
];
```

**이벤트 핸들러:**
- `install`: 정적 리소스 캐싱
- `activate`: 이전 캐시 삭제
- `fetch`: Network First 전략
- `sync`: 백그라운드 동기화 (향후 확장)
- `push`: 푸시 알림 (향후 확장)

#### 3.2 오프라인 페이지
```
/public/offline.html
```

**기능:**
- 인터넷 연결 끊김 시 표시
- 브랜드 디자인 적용
- 다시 시도 버튼
- 네트워크 연결 팁 제공

#### 3.3 PWA 유틸리티
```
/lib/utils/pwa.ts
```

**제공 기능:**

##### Service Worker 등록
```typescript
registerServiceWorker(): Promise<ServiceWorkerRegistration | null>
```

##### 온라인/오프라인 감지
```typescript
setupNetworkListeners(
  onOnline?: () => void,
  onOffline?: () => void
): () => void
```

##### PWA 설치 프롬프트
```typescript
setupInstallPrompt(
  onInstallable?: (event: Event) => void
): () => void

showInstallPrompt(
  deferredPrompt: any
): Promise<boolean>
```

##### 백그라운드 동기화
```typescript
registerBackgroundSync(tag: string): Promise<void>
```

##### 캐시 관리
```typescript
clearCache(cacheName?: string): Promise<void>
getCacheSize(): Promise<number>
formatCacheSize(bytes: number): string
```

#### 3.4 main.tsx 업데이트

**추가된 기능:**
```typescript
// Service Worker 등록 (프로덕션만)
if (import.meta.env.PROD) {
  registerServiceWorker();
}

// 온라인/오프라인 토스트 알림
setupNetworkListeners(
  () => toast.success('인터넷에 연결되었습니다.'),
  () => toast.error('인터넷 연결이 끊겼습니다.')
);
```

#### 3.5 PWA 기능 확장 (향후)

**백그라운드 동기화:**
- 오프라인에서 작성한 주문을 온라인 시 자동 전송
- IndexedDB에 임시 저장
- `sync` 이벤트로 동기화

**푸시 알림:**
- 주문 상태 변경 알림
- 프로모션 알림
- 리뷰 요청 알림
