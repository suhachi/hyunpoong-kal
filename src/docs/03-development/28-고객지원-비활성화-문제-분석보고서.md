## 문제 현상

### 스크린샷 분석

관리자 대시보드의 "고객 지원" 메뉴 접속 시 다음 메시지가 표시됩니다:

```
⚠️ 고객 지원 기능이 비활성화되어 있습니다. 
   환경 변수에서 VITE_SUPPORT_ENABLED=true로 설정하세요.
```

### 증상 정리

| 항목 | 상태 |
|------|------|
| 페이지 접근 | ✅ 가능 (라우팅 정상) |
| UI 렌더링 | ✅ 정상 (경고 메시지 표시) |
| 기능 실행 | 🔴 불가 (환경 변수 체크로 차단) |
| Firebase 연동 | ⚠️ 미실행 (기능 비활성화로 인해) |
| Mock 데이터 | ⚠️ 미실행 (기능 비활성화로 인해) |

## 원인 분석

### 1. 환경 변수 미설정

#### 현재 상태
프로젝트 루트에 `.env` 파일이 없거나, `VITE_SUPPORT_ENABLED` 환경 변수가 설정되지 않은 상태입니다.

#### 예상되는 파일 상태
```bash
# .env 파일이 없거나
# 또는 VITE_SUPPORT_ENABLED 값이 누락되거나
# 또는 false로 설정되어 있음
```

### 2. 기능 토글 로직

#### `/config/env.ts` (62번째 줄)
```typescript
export const FEATURE_FLAGS = {
  // ...
  
  // 고객 지원 채팅 기능
  support: getEnv('VITE_SUPPORT_ENABLED') === 'true',  // ← 여기서 체크
  
  // ...
};
```

**분석:**
- `getEnv('VITE_SUPPORT_ENABLED')`가 `'true'` 문자열이 아니면 `false` 반환
- 환경 변수가 없으면 기본값 `''` (빈 문자열) 반환
- `'' === 'true'` → `false` → 기능 비활성화

### 3. 페이지 레벨 체크

#### `/pages/admin/Support.tsx` (70-82번째 줄)
```typescript
export function AdminSupport() {
  // ...
  
  // 지원 기능 비활성화 체크
  if (!FEATURE_FLAGS.support) {
    return (
      <div className="p-6">
        <Alert>
          <AlertCircle className="h-4 w-4" />
          <AlertDescription>
            고객 지원 기능이 비활성화되어 있습니다. 
            환경 변수에서 VITE_SUPPORT_ENABLED=true로 설정하세요.
          </AlertDescription>
        </Alert>
      </div>
    );
  }
  
  // 실제 채팅 UI는 여기서 렌더링
  // ...
}
```

**분석:**
- `FEATURE_FLAGS.support`가 `false`이면 조기 반환 (early return)
- 경고 메시지만 표시하고 실제 채팅 UI는 렌더링하지 않음
- Firebase 연동, Mock 데이터 로드 등 모든 기능 실행 차단

## 코드 분석

### 환경 변수 로딩 흐름

```
1. Vite 시작
   ↓
2. import.meta.env에서 환경 변수 로드
   ↓
3. /config/env.ts의 getEnv() 함수 실행
   ↓
4. VITE_SUPPORT_ENABLED 값 확인
   ↓
5. FEATURE_FLAGS.support 설정
   ↓
6. /pages/admin/Support.tsx에서 체크
   ↓
7. false → 경고 메시지 표시
   true → 채팅 UI 렌더링
```

### getEnv 함수 분석

```typescript
// /config/env.ts (7-13번째 줄)
const getEnv = (key: string, defaultValue: string = ''): string => {
  try {
    return import.meta?.env?.[key] || defaultValue;
  } catch {
    return defaultValue;
  }
};
```

**동작:**
1. `import.meta.env.VITE_SUPPORT_ENABLED` 접근 시도
2. 값이 없으면 `defaultValue` (기본값 `''`) 반환
3. 에러 발생 시에도 `defaultValue` 반환

**결과:**
- `.env` 파일 없음 → `getEnv('VITE_SUPPORT_ENABLED')` → `''`
- `'' === 'true'` → `false`
- `FEATURE_FLAGS.support` → `false`

코드에서 직접 `true`로 하드코딩 (테스트 목적만):


⚠️ **주의:** 프로덕션 배포 시 반드시 환경 변수로 되돌려야 합니다.

### 3. 기본값 설정 개선

```typescript
// /config/env.ts (개선안)
export const FEATURE_FLAGS = {
  // ...
  
  // 고객 지원 채팅 기능
  // 개발 환경에서는 기본적으로 활성화
  support: ENV === 'development' 
    ? (getEnv('VITE_SUPPORT_ENABLED', 'true') === 'true')
    : (getEnv('VITE_SUPPORT_ENABLED') === 'true'),
  
  // ...
};
```

**장점:**
- 개발 환경에서는 환경 변수 없어도 기본 활성화
- 프로덕션 환경에서는 명시적 설정 필요
- 개발 편의성 ↑, 보안성 유지

### 4. 환경 변수 검증 스크립트

```typescript
// /scripts/verify-env.ts
import { FEATURE_FLAGS, USE_FIREBASE } from '../config/env';

console.log('FEATURE_FLAGS.support:', FEATURE_FLAGS.support);
console.log('FEATURE_FLAGS.delivery:', FEATURE_FLAGS.delivery);

```
