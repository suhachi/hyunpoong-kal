**대상:** 로컬 개발 환경  
**소요 시간:** 5분  
**개발사:** KS컴퍼니 (사업자번호: 553-17-00098)

## 🎯 현재 상황

### 문제
- 고객지원 기능이 "비활성화되어 있습니다" 메시지 표시
- 원인: `.env` 파일에 환경 변수 미설정

### 해결 방법
로컬 프로젝트 루트에 3개 파일을 직접 생성해야 합니다:
1. `.env` (환경 변수)
2. `.env.example` (템플릿)
3. `.gitignore` (Git 제외 설정)

터미널/명령 프롬프트를 열고:


## 🔧 문제 해결

### Q1: .env 파일이 보이지 않아요

**A:** 숨김 파일이라 안 보일 수 있습니다.

#### Mac/Linux
```bash
# 숨김 파일 표시
ls -la

# Finder에서 숨김 파일 보기
Cmd + Shift + . (점)
```

#### Windows
```bash
# 탐색기 > 보기 > 숨김 항목 체크
# 또는
dir /a
```

#### VS Code
- 자동으로 `.env` 파일이 보입니다
- 좌측 파일 탐색기에서 확인

### Q2: 서버를 재시작했는데도 비활성화 메시지가 나와요

**A:** 다음을 확인하세요:

1. `.env` 파일 위치가 올바른지 (프로젝트 루트)
2. `VITE_SUPPORT_ENABLED=true` 철자가 정확한지
3. 브라우저 캐시 삭제 (Ctrl+Shift+R)
4. 콘솔에 에러 메시지 확인

```bash
# 디버깅: 환경 변수 확인
# 브라우저 콘솔에서 실행
console.log(import.meta.env.VITE_SUPPORT_ENABLED);
// 예상 출력: "true"
```

### Q3: Git에 .env 파일이 커밋되었어요

**A:** 즉시 제거하세요!

```bash
# .env 파일을 Git에서 제거 (로컬 파일은 유지)
git rm --cached .env

# 커밋
git commit -m "Remove .env from Git"

# .gitignore 확인
cat .gitignore | grep .env

# 향후 실수 방지
git status  # .env 파일이 나오면 안 됨
```

### Q4: Mock 모드로 테스트하고 싶어요

**A:** `.env` 파일 수정:

```bash
VITE_USE_FIREBASE=false    # ← false로 변경
VITE_SUPPORT_ENABLED=true
```

개발 서버 재시작 필요!
