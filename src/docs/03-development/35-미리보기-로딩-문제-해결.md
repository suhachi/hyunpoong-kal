## 📋 문제 증상

미리보기 화면이 무한 로딩 상태에 빠져 앱이 표시되지 않음.

**증상:**
- 화면이 로딩 스피너만 표시
- 페이지가 렌더링되지 않음
- 콘솔에 특별한 에러 없음

---

## 🔍 원인 분석

### 1. AuthContext 로딩 상태 문제

**문제:**
```typescript
// AuthContext.tsx (수정 전)
if (USE_FIREBASE) {
  const unsubscribe = onAuthStateChanged(auth!, async (firebaseUser) => {
    // ... 사용자 정보 로드
    setLoading(false);
  });
} else {
  // Mock Auth
  const mockUserData = localStorage.getItem('mockUser');
  if (mockUserData) {
    setUser(JSON.parse(mockUserData));
  }
  setLoading(false);
}
```

**문제점:**
- `auth` 객체가 `null`일 수 있는데 `auth!`로 강제 사용
- 에러 처리 없음
- Firebase 초기화 실패 시 로딩 상태가 해제되지 않음

### 2. Firebase 초기화 체크 누락

```typescript
// 수정 전
if (USE_FIREBASE) {
  const unsubscribe = onAuthStateChanged(auth!, ...);
}

// 수정 후
if (USE_FIREBASE && auth) {
  const unsubscribe = onAuthStateChanged(auth, ...);
}
```

## ✅ 해결 방법

### 1. AuthContext.tsx 수정

#### 1.1 useEffect 수정

```typescript
useEffect(() => {
  if (USE_FIREBASE && auth) {
    // Firebase Auth 리스너
    const unsubscribe = onAuthStateChanged(auth, async (firebaseUser) => {
      try {
        if (firebaseUser) {
          // 사용자 정보 로드
          const userDoc = await getDoc(doc(db, 'users', firebaseUser.uid));
          const userData = userDoc.data();
          
          setUser({
            uid: firebaseUser.uid,
            email: firebaseUser.email || '',
            displayName: firebaseUser.displayName || '사용자',
            photoURL: firebaseUser.photoURL || undefined,
            role: userData?.role || 'customer',
            storeId: userData?.storeId,
            createdAt: userData?.createdAt?.toDate(),
          });
        } else {
          setUser(null);
        }
      } catch (error) {
        console.error('[AuthContext] 사용자 정보 로드 실패:', error);
        setUser(null);
      } finally {
        setLoading(false);  // ⭐ 반드시 실행
      }
    });

    return () => unsubscribe();
  } else {
    // Mock Auth
    try {
      const mockUserData = localStorage.getItem('mockUser');
      if (mockUserData) {
        setUser(JSON.parse(mockUserData));
      }
    } catch (error) {
      console.error('[AuthContext] Mock 사용자 로드 실패:', error);
    } finally {
      setLoading(false);  // ⭐ 반드시 실행
    }
  }
}, []);
```

**핵심 변경사항:**
1. `auth!` → `auth` (null 체크 추가)
2. `try-catch-finally` 블록 추가
3. `finally`에서 `setLoading(false)` 보장

## 🔧 문제 해결 체크리스트

### 로딩이 끝나지 않을 때

- [ ] F12 → Console에서 에러 확인
- [ ] `/debug` 페이지에서 "로딩 중" 상태 확인
- [ ] LocalStorage 초기화 후 새로고침
- [ ] 브라우저 캐시 삭제 (Ctrl+Shift+Del)

### Firebase 관련 에러

- [ ] `.env` 파일 확인 (없으면 Mock 모드로 동작)
- [ ] `VITE_USE_FIREBASE=false` 확인
- [ ] Firebase 설정 값 확인

### Mock 모드가 동작하지 않을 때

```bash
# LocalStorage 초기화
localStorage.clear();
location.reload();

# 또는 디버그 페이지에서 "LocalStorage 초기화" 버튼 클릭
```
