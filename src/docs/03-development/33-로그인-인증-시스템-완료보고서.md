## 🚀 배포 준비

### Firebase 프로젝트 설정

1. **Authentication 활성화**
```bash
# Firebase Console에서 설정
1. Authentication > 로그인 방법 > 이메일/비밀번호: 사용 설정
2. Authentication > 로그인 방법 > Google: 사용 설정
```

2. **Firestore 데이터베이스 생성**
```bash
# Collection: users
/users/{uid}
  - email: string
  - displayName: string
  - role: string ('customer' | 'owner' | 'admin')
  - photoURL: string (optional)
  - storeId: string (optional)
  - createdAt: timestamp
```

3. **Firestore 보안 규칙**
```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // users 컬렉션
    match /users/{userId} {
      // 본인만 읽기/쓰기 가능
      allow read, write: if request.auth != null && request.auth.uid == userId;
      
      // 관리자는 모든 사용자 읽기 가능
      allow read: if request.auth != null && 
                     get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role in ['owner', 'admin'];
    }
  }
}
```

4. **환경 변수 설정**
```env
# .env.production
VITE_USE_FIREBASE=true
VITE_FIREBASE_API_KEY=your_actual_api_key
VITE_FIREBASE_AUTH_DOMAIN=hyunpung-chicken.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=hyunpung-chicken
VITE_FIREBASE_STORAGE_BUCKET=hyunpung-chicken.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=123456789
VITE_FIREBASE_APP_ID=1:123456789:web:abcdef
VITE_FIREBASE_MEASUREMENT_ID=G-XXXXXXXXXX
```
