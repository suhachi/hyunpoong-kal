# 현풍닭칼국수 PWA 배달앱 - 단계별 프롬프트 가이드

## 📋 개요

이 디렉토리는 현풍닭칼국수 PWA 배달앱을 **처음부터 완성까지** 구축하기 위한 단계별 프롬프트 모음입니다.

각 프롬프트는 ATOMIC 단위로 설계되었으며, 순차적으로 실행하면 완전한 배달앱 시스템이 구축됩니다.

---

## 🎯 프로젝트 목표

**완성된 시스템:**
- ✅ 주문자 PWA 앱 (QR 스캔 → A2HS 설치 → 주문 → 결제 → 추적 → 리뷰)
- ✅ 가게 관리자 대시보드 (주문 관리, 메뉴 관리, 배달 관제, 통계 분석)
- ✅ Firebase 백엔드 (Firestore, Functions, Auth, FCM)
- ✅ NICEPAY 결제 연동
- ✅ 배달 대행사 API 연동
- ✅ 포인트/쿠폰 시스템
- ✅ 고객 지원 채팅
- ✅ E2E 테스트 + 접근성 개선
- ✅ PWA 오프라인 지원

---

## 📚 프롬프트 구조 (9개 파일, 19단계 포함)

### **Phase 0: 기획 및 설계** ✅
- `01-project-definition.md` - 프로젝트 정의 및 요구사항
- `02-design-system.md` - 디자인 시스템 및 브랜드 아이덴티티
- `DESIGN-GUIDE.md` - 🎨 **완벽 디자인 가이드** (디자인 환경, 구조, 모든 것)

### **Phase M0: 기초 인프라** ✅
- `03-project-setup.md` - 프로젝트 초기 설정 및 환경 구성

### **Phase 1: 주문자 앱 - 기본** ✅
- `04-landing-menu.md` - 랜딩 페이지 및 메뉴 시스템

### **Phase 2: 주문자 앱 - 주문/결제/리뷰** ✅
- `05-cart-checkout.md` - 장바구니 및 결제 플로우
- `06-order-tracking.md` - 주문 추적 및 히스토리 (Realtime)
- `07-review-system.md` - 리뷰 작성 및 조회 (별점, 이미지)

### **Phase 3-10: 관리자 + 고급 기능 통합** ✅
- `08-09-admin-basics.md` - 대시보드, 주문관리, 메뉴관리, CSV 임포트
- `10-19-remaining.md` - 모든 나머지 기능 통합
  - 리뷰 관리 및 통합 분석
  - 설정 센터 (결제/배달/FCM/지도/운영)
  - 포인트/쿠폰 시스템
  - 배달 추적 및 관제
  - 고객 지원 채팅
  - 인증 (로그인/회원가입/소셜)
  - E2E 테스트 + 접근성
  - PWA 최적화
  - Firebase 배포
  - 운영 매뉴얼

## 🚀 사용 방법

### 1️⃣ **순차적 실행**
```
01-project-definition.md 프롬프트 실행
  ↓
02-design-system.md 프롬프트 실행
  ↓
03-project-setup.md 프롬프트 실행
  ↓
... (순서대로 진행)
```

### 2️⃣ **각 프롬프트의 구조**
```markdown
# Phase X: 제목

## 🎯 목표
- 이번 단계에서 달성할 목표

## 📋 요구사항 (PRD)
- ATOMIC 단위의 상세 요구사항

## 📦 산출물
- 생성될 파일 목록

## 💬 프롬프트
실제 AI에게 입력할 프롬프트

## ✅ 검증 체크리스트
- 완료 확인 항목
```

### 3️⃣ **주의사항**
- ⚠️ 각 단계는 **이전 단계가 완료된 후** 진행해야 합니다
- ⚠️ 프롬프트를 **그대로 복사-붙여넣기** 하되, 환경에 맞게 일부 수정 필요
- ⚠️ Firebase 프로젝트 ID, API 키 등은 실제 값으로 대체 필요
