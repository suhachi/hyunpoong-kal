## 📚 5. Z-Index Hierarchy

### 5.1 레이어 정의

```css
--z-base: 0;              /* 기본 레이어 */
--z-dropdown: 50;         /* 드롭다운 메뉴 */
--z-sticky: 100;          /* 고정 헤더 ★ */
--z-fixed: 200;           /* 고정 요소 (사이드바) */
--z-modal-backdrop: 900;  /* 모달 배경 */
--z-modal: 1000;          /* 모달 창 */
--z-popover: 1050;        /* 팝오버 */
--z-toast: 1100;          /* 토스트 알림 */
--z-tooltip: 1200;        /* 툴팁 */
```

### 5.2 계층 구조

```
┌─────────────────────────────────┐
│ 1200 - Tooltip (최상위)          │
│ 1100 - Toast Notification       │
│ 1050 - Popover                  │
│ 1000 - Modal Dialog             │
│  900 - Modal Backdrop           │
│  200 - Fixed Sidebar            │
│  100 - Sticky Header ★          │
│   50 - Dropdown Menu            │
│    0 - Base Content             │
└─────────────────────────────────┘
```

### 5.3 사용 예시

```jsx
// 고정 헤더
<header 
  className="sticky top-0"
  style={{ zIndex: 'var(--z-sticky)' }}
>

// 모달
<Dialog 
  style={{ zIndex: 'var(--z-modal)' }}
>

// 또는 Tailwind 직접 입력
<div className="z-[100]">  // sticky
<div className="z-[1000]"> // modal
```

```css
  h2 { font-size: var(--text-xl); font-weight: 500; }
  h3 { font-size: var(--text-lg); font-weight: 500; }
  h4 { font-size: var(--text-base); font-weight: 500; }
  p { font-size: var(--text-base); font-weight: 400; }
}
```

### 6.2 ⚠️ 중요 원칙

**폰트 사이즈, 웨이트, 라인 높이는 Tailwind 클래스를 사용하지 마세요!**

```jsx
// ❌ 잘못된 예시

// ✅ 올바른 예시

```

**이유**: `globals.css`에 기본 타이포그래피가 정의되어 있어 자동 적용됨

## 🔧 10. Tailwind CSS v4 아키텍처

### 10.1 핵심 구조

```css
/* globals.css */

/* 1. Tailwind 엔진 임포트 */
@import "tailwindcss";

/* 2. CSS 변수 정의 */
:root {
  --color-hyunpung-red: #D61C1C;
  /* ... */
}

/* 3. Tailwind에 매핑 */
@theme inline {
  --color-hyunpung-red: var(--color-hyunpung-red);
  /* ... */
}

/* 4. 기본 스타일 */
@layer base {
  h1 { font-size: var(--text-2xl); }
  /* ... */
}
```

### 10.2 작동 원리

```
CSS 변수 정의 (:root)
         ↓
@theme inline 매핑
         ↓
Tailwind 유틸리티 생성
         ↓
className에서 사용
         ↓
bg-hyunpung-red → #D61C1C
```

### 10.3 장점

✅ **타입 안전성**: IDE 자동완성  
✅ **일관성**: 하나의 소스  
✅ **유지보수**: 변경 시 한 곳만 수정  
✅ **확장성**: 새 토큰 쉽게 추가  
✅ **성능**: Tailwind JIT 컴파일

## 🎨 14. 디자인 결정 (Design Decisions)

### 14.1 왜 `rounded-2xl`을 주로 사용하는가?

**결정**: 카드와 섹션에 `rounded-2xl` (32px) 사용

**이유**:
- ✅ 부드럽고 친근한 느낌
- ✅ 모바일에서 터치하기 좋은 크기
- ✅ 브랜드 정체성 (따뜻함, 가족적)
- ✅ 현대적이고 트렌디한 디자인

### 14.2 왜 Z-Index를 100으로 설정했는가?

**결정**: Sticky 헤더 `z-index: 100`

**이유**:
- ✅ 드롭다운(50)보다 위
- ✅ 모달(1000)보다 아래
- ✅ 명확한 계층 구조
- ✅ 향후 확장 여지

### 14.3 왜 Typography를 자동 적용하는가?

**결정**: `h1`, `h2` 등 기본 폰트 사이즈 자동 적용

**이유**:
- ✅ 일관성 유지
- ✅ 개발자 실수 방지
- ✅ 유지보수 용이
- ✅ 접근성 향상
