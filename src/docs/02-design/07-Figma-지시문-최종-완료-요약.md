```typescript
/>
```
**7가지 상태:**

4. `success` - 결제 완료!
5. `failed` - 결제 실패 (망취소 안내)
6. `timeout` - 시간 초과
7. `cancelled` - 결제 취소됨

- 타임아웃 타이머 (180초)
