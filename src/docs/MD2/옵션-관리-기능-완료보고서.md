## 📋 개요

### 요청 사항
관리자 대시보드 메뉴 관리 기능에서 옵션 메뉴에 관리자가 **옵션명, 가격, 수량 등을 입력할 수 있는 기능** 추가

### 현재 상태
✅ **이미 완전히 구현되어 있음**

---

## 🎯 구현된 기능

### 1. 옵션 그룹 관리
**위치:** `/admin/settings?tab=options`

관리자가 옵션 그룹을 생성하고 관리할 수 있습니다:

```typescript
옵션 그룹 생성/수정:
- 옵션 그룹 이름 (예: 면양, 맵기, 토핑)
- 필수 선택 여부
- 다중 선택 가능 여부
- 최대 선택 개수
```

### 2. 옵션 항목 관리
각 옵션 그룹 내에서 옵션 항목을 추가/수정할 수 있습니다:

```typescript
옵션 항목 생성/수정:
- 옵션명 (예: 보통, 곱빼기, 순한맛, 수육)
- 수량 (기본: 1)
- 추가 가격 (0원 = 무료)
```

### 3. 메뉴에 옵션 적용
**위치:** 메뉴 등록/수정 다이얼로그 > 옵션 탭

관리자가 메뉴를 생성/수정할 때 원하는 옵션 그룹을 선택할 수 있습니다.

### 타입 정의
```typescript
// types/menu.ts

// 옵션 항목
interface OptionItem {
  id: string;
  name: string;       // 옵션명
  quantity: number;   // 수량
  price: number;      // 추가 가격
}

// 옵션 그룹
interface OptionGroup {
  id: string;
  name: string;           // 그룹 이름
  required: boolean;      // 필수 선택
  multiSelect: boolean;   // 다중 선택
  maxSelect?: number;     // 최대 선택 개수
  items: OptionItem[];    // 옵션 항목들
  order: number;          // 표시 순서
}
```


## 🔧 사용 방법

### 1단계: 옵션 그룹 생성
1. 관리자 대시보드 접속
2. **설정** > **옵션 관리** 탭 이동
3. **[옵션 그룹 추가]** 버튼 클릭
4. 옵션 그룹 정보 입력:
   - 이름: 면양
   - ☑ 필수 선택
   - ☐ 다중 선택 가능
5. **[저장]** 클릭

### 2단계: 옵션 항목 추가
1. 생성한 옵션 그룹에서 **[옵션 추가]** 버튼 클릭
2. 옵션 항목 정보 입력:
   - 옵션명: 보통
   - 수량: 1
   - 추가 가격: 0원
3. **[저장]** 클릭
4. 추가 옵션 항목도 같은 방법으로 생성:
   - 곱빼기 (수량: 1, 가격: +2,000원)
   - 2배 (수량: 2, 가격: +3,000원)

### 3단계: 메뉴에 옵션 적용
1. **메뉴 관리** 페이지 이동
2. **[메뉴 등록]** 또는 기존 메뉴 **[편집]** 클릭
3. **옵션** 탭 선택
4. 적용할 옵션 그룹 체크박스 선택
5. **[등록]** 또는 **[저장]** 클릭
