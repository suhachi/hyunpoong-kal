## 🎯 구현된 기능

### 1. 5개 설정 탭

#### ✅ 결제 (NICEPAY)
```
기능:
- Functions Config 상태 표시 (연결됨/미설정)
- 필수 키 체크리스트 (endpoint/mid/key/return/cancel)
- CLI 명령어 복사 버튼
- NICEPAY 가이드 (MID/KEY 발급, URL 등록, 테스트/프로덕션)
- 참고 문서 링크

UI 구조:
- 좌측: 상태 패널
- 우측: CLI 설정 + 가이드 + 문서
```

#### ✅ 배달대행
```
기능:
- Provider 선택 (mock/providerA/custom)
- 최대 배달 거리 설정
- 거리별 요금표 (3개 구간)
- 야간 추가비 설정 (21:00~06:00)
- Webhook 비밀키 CLI 명령어
- Firestore 저장 (실시간 동기화)

UI 구조:
- 좌측: Provider 상태 + 요약
- 우측: 설정 폼 + Webhook CLI
```

#### ✅ 지도/지오코딩
```
기능:
- Kakao Maps API 상태 (설정됨/미설정)
- Google Maps API 상태 (선택사항)
- API 키 발급 가이드
- 플랫폼 등록 안내
- .env 템플릿 다운로드

UI 구조:
- 좌측: API 키 상태
- 우측: Kakao 가이드 + Google 가이드 + 템플릿
```

#### ✅ FCM 알림
```
기능:
- FCM 진단 실행 (7개 항목)
  • FCM 지원 여부
  • Service Worker 상태
  • VAPID 키 존재
  • 환경 변수 체크
  • Push Manager 지원
  • Notification 권한
  • Firebase Config
- Firebase Console 가이드
- VAPID 키 설정 안내
- 서버 키 CLI 명령어
- Service Worker 파일 예제
- 체크리스트 (8개 항목)

UI 구조:
- 좌측: 진단 결과 (실시간)
- 우측: Firebase 가이드 + Service Worker + 체크리스트
```

#### ✅ 운영/보안
```
기능:
- 배포 스크립트 (3단계)
  1. Firestore 인덱스 및 Rules
  2. Cloud Functions
  3. Hosting (빌드 포함)
- 전체 배포 스크립트 복사
- CORS 설정 가이드
- Firestore Rules/Indexes 관리
- 참고 문서 링크 (4개)

UI 구조:
- 배포 스크립트 카드
- CORS 설정 카드
- Firestore Rules/Indexes 카드
- 참고 문서 카드
```

### 2. 보안 설계

#### ✅ 비밀키 분리
```typescript
// ❌ 클라이언트에 절대 노출 금지
functions:config (서버):
- nicepay.mid
- nicepay.key
- delivery.secret
- delivery.provider_a_key
- fcm.server_key

// ✅ .env.local (공개 가능한 키만)
- VITE_FIREBASE_*
- VITE_FCM_VAPID_KEY
- VITE_KAKAO_MAP_KEY
- VITE_GOOGLE_MAPS_API_KEY
- VITE_NICEPAY_CLIENT_ID (mode도)
```

#### ✅ UI 마스킹
```typescript
// 키를 state에 저장하지 않음
// CLI 명령어 미리보기에만 바인딩
const command = `firebase functions:config:set nicepay.key="${inputValue}"`;
```

#### ✅ 접근 제어
```typescript
// owner|admin 역할만 접근 가능
if (!user || (user.role !== 'owner' && user.role !== 'admin')) {
  return <AccessDenied />;
}
```
