## 🔍 발견된 리팩토링 영역

### 1. Import 경로 불일치 (High Priority)

#### 문제
```typescript
// 현재: 혼재된 import 스타일

// 상대 경로 방식 (대부분)
import { Card } from '../../components/ui/card';
import { useCart } from '../../contexts/CartContext';
import type { Menu } from '../../types/menu';

// @/ alias 방식 (tsconfig.json에 정의됨)
// 거의 사용 안 함
```

#### 영향
- **파일 수:** ~120개 TypeScript/TSX 파일
- **Import 개수:** 추정 500+ 개
- **가독성:** 중간 (../../../ 가독성 저하)
- **유지보수:** 파일 이동 시 모든 경로 수정 필요

#### 해결 방안
```typescript
// Before
import { Card } from '../../components/ui/card';
import { useCart } from '../../contexts/CartContext';
import type { Menu } from '../../types/menu';

// After
import { Card } from '@/components/ui/card';
import { useCart } from '@/contexts/CartContext';
import type { Menu } from '@/types/menu';
```

#### 작업량
- **자동화 가능:** 90%
- **수동 확인 필요:** 10%
- **예상 시간:** 30-60분
- **파일 수:** ~100개

### 6. 코드 중복 제거 (Medium Priority)

#### 발견된 중복 패턴

##### 6.1 Loading State
```typescript
// 패턴 1: 여러 파일에서 동일한 로딩 UI
if (loading) {
  return (
    <div className="space-y-4">
      {[1, 2, 3].map(i => (
        <div key={i} className="h-64 bg-gray-100 rounded-lg animate-pulse" />
      ))}
    </div>
  );
}
```

**해결:**
```typescript
// components/shared/LoadingSkeleton.tsx
export function LoadingSkeleton({ count = 3, height = 64 }) {
  return (
    <div className="space-y-4">
      {Array.from({ length: count }).map((_, i) => (
        <div 
          key={i} 
          className="bg-gray-100 rounded-lg animate-pulse" 
          style={{ height: `${height}px` }}
        />
      ))}
    </div>
  );
}

// 사용
if (loading) {
  return <LoadingSkeleton count={3} height={64} />;
}
```

##### 6.2 Empty State
```typescript
// 패턴 2: 빈 상태 UI 중복
{items.length === 0 && (
  <div className="text-center py-12">
    <p className="text-[#8B7355]">데이터가 없습니다</p>
  </div>
)}
```

**해결:**
```typescript
// components/shared/EmptyState.tsx
export function EmptyState({ 
  icon: Icon, 
  message, 
  action 
}: EmptyStateProps) {
  return (
    <div className="text-center py-12">
      {Icon && <Icon className="w-12 h-12 mx-auto mb-4 text-[#8B7355]/40" />}
      <p className="text-[#8B7355]">{message}</p>
      {action && <div className="mt-4">{action}</div>}
    </div>
  );
}
```

##### 6.3 Toast Notifications
```typescript
// 패턴 3: Toast 사용 패턴 중복
```
