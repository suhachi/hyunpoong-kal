## 🎯 문제 상황

### 발생한 경고
```
⚠️ [Env] import.meta.env not available, using default for VITE_USE_FIREBASE
⚠️ [Env] import.meta.env not available, using default for VITE_FIREBASE_API_KEY
⚠️ [Env] import.meta.env not available, using default for VITE_FIREBASE_AUTH_DOMAIN
... (총 20개 경고)
```

### 원인
1. `.env` 파일이 없음
2. 모든 환경 변수에 대해 개별 경고 출력
3. 개발 환경에서는 기본값으로 정상 작동하지만 경고가 시끄러움

### 영향
- ✅ **앱 작동:** 정상 (기본값 사용)
- ⚠️ **콘솔:** 경고 메시지 20개
- ⚠️ **개발 경험:** 성가심

## ✅ 해결 방법

### 1. 경고 메시지 최적화

#### Before (문제)
```typescript
// config/env.ts - 수정 전
const getEnv = (key: string, defaultValue: string = ''): string => {
  try {
    if (typeof import.meta === 'undefined' || !import.meta.env) {
      // 모든 변수마다 경고 출력 ❌
      console.warn(`[Env] import.meta.env not available, using default for ${key}`);
      return defaultValue;
    }
    // ...
  }
};

// 결과: 20개 경고 메시지 💥
```

#### After (해결)
```typescript
// config/env.ts - 수정 후
let envWarningShown = false;  // ✅ 플래그 추가

const getEnv = (key: string, defaultValue: string = ''): string => {
  try {
    if (typeof import.meta === 'undefined' || !import.meta.env) {
      if (required) {
        console.error(`[Env] Required variable ${key} not available`);
      } else if (DEBUG && !envWarningShown) {
        // ✅ 최초 1회만 경고
        console.warn(`[Env] 💡 Using default values (no .env file detected). This is normal for development.`);
        envWarningShown = true;
      }
      return defaultValue;
    }
    // ...
  }
};

// 결과: 1개 경고 메시지만! ✅
```

### 변경 사항
- ✅ `envWarningShown` 플래그 추가
- ✅ 최초 1회만 경고 출력
- ✅ 친절한 메시지로 변경
- ✅ 에러 로깅 최소화

## 📊 FAQ

### Q1. .env 파일을 만들어야 하나요?
```
A: 아니오! 개발 환경에서는 필요 없습니다.
   기본값으로 모든 기능이 정상 작동합니다.
```

### Q2. 경고가 완전히 사라지나요?
```
A: 네! .env 파일을 만들면 경고가 완전히 사라집니다.
   또는 기본값을 사용하면 경고 1개만 표시됩니다.
```

### Q3. Firebase 연동은 어떻게 하나요?
```
A: .env 파일에 VITE_USE_FIREBASE=true 설정하고
   실제 Firebase 값을 입력하면 됩니다.
```

### Q4. .env 파일을 Git에 커밋해도 되나요?
```
A: 절대 안 됩니다! .gitignore에 포함되어 있어
   자동으로 제외됩니다.
```

### Q5. 프로덕션 배포 시 환경 변수는?
```
A: Firebase Hosting 환경 변수 또는
   .env.production 파일을 사용하세요.
```
