## 📊 프로젝트 개요

현풍닭칼국수 브랜드 아이덴티티를 기반으로 개발된 **완전한 PWA (Progressive Web App) 배달 주문 시스템**입니다.

### 핵심 기능
- 🛒 **주문 시스템**: 메뉴 선택 → 옵션 선택 → 장바구니 → 결제 → 추적
- 👤 **인증 시스템**: 이메일/구글 로그인, 역할 기반 접근 제어
- 🏪 **관리자 대시보드**: 주문/메뉴/리뷰/쿠폰/포인트/통합 분석
- 🚚 **배달 추적**: 실시간 GPS 위치, ETA 계산
- 💬 **고객 지원**: 1:1 채팅 시스템
- 🎁 **리워드**: 포인트 적립/사용, 쿠폰 시스템
- ⭐ **리뷰 시스템**: 별점/사진 리뷰, 관리자 답글
- 🔔 **푸시 알림**: FCM 기반 실시간 알림
- 📊 **통합 분석**: KPI 대시보드, CSV Export
