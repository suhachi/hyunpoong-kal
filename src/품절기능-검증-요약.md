## 🚀 기능 흐름

### 품절 처리
```
관리자 → 토글 클릭 → API 호출 → Firestore 업데이트
                   → UI 즉시 반영 → 토스트 메시지
                   → 감사 로그 기록 → 주문자 앱 동기화
```

### 주문 시도
```
주문자 → 메뉴 선택 → 품절 체크 → 주문 차단
                              → "품절이에요" 토스트
```
