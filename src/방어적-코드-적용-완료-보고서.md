### 📁 1. `/config/env.ts` 수정

#### ✅ 변경 1: ENV 상수 (라인 7-16)

**Before:**
```typescript
export const ENV = (() => {
  try {
    return import.meta.env.MODE || 'development';
  } catch {
    return 'development';
  }
})();
```

**After:**
```typescript
export const ENV = (() => {
  try {
    // import.meta 존재 여부 확인 (Figma Make 호환)
    if (typeof import.meta === 'undefined' || !import.meta.env) {
      console.log('[Env] Figma Make 또는 특수 환경 감지 - 개발 모드로 설정');
      return 'development';
    }
    return import.meta.env.MODE || 'development';
  } catch {
    return 'development';
  }
})();
```

**개선 효과:**
- ✅ `typeof import.meta` 체크로 Figma Make 환경 감지
- ✅ `import.meta.env` 체크로 환경 변수 존재 확인
- ✅ 명확한 로깅으로 디버깅 용이

#### ✅ 변경 2: getEnv 함수 (라인 22-46)

**Before:**
```typescript
const getEnv = (key: string, defaultValue: string = '', required: boolean = false): string => {
  try {
    const value = import.meta.env[key] || '';
    
    // 필수 변수인데 값이 없으면 오류
    if (!value && required && !defaultValue) {
      console.error(`[Env] Required environment variable ${key} is not set`);
      if (ENV === 'production') {
        throw new Error(`Required environment variable ${key} is not set`);
      }
    }
    
    return value || defaultValue;
  } catch (error) {
    if (DEBUG) {
      console.error(`[Env] Error accessing ${key}:`, error);
    }
    return defaultValue;
  }
};
```

**After:**
```typescript
const getEnv = (key: string, defaultValue: string = '', required: boolean = false): string => {
  try {
    // import.meta 안전 체크 (Figma Make 등 특수 환경 대응)
    if (typeof import.meta === 'undefined' || !import.meta.env) {
      if (DEBUG && required) {
        console.warn(`[Env] ${key} 접근 불가 (Figma Make?), 기본값 사용: ${defaultValue}`);
      }
      return defaultValue;
    }
    
    const value = import.meta.env[key] || '';
    
    // 필수 변수인데 값이 없으면 오류
    if (!value && required && !defaultValue) {
      console.error(`[Env] Required environment variable ${key} is not set`);
      if (ENV === 'production') {
        throw new Error(`Required environment variable ${key} is not set`);
      }
    }
    
    return value || defaultValue;
  } catch (error) {
    if (DEBUG) {
      console.warn(`[Env] ${key} 접근 에러, 기본값 사용:`, defaultValue, error);
    }
    return defaultValue;
  }
};
```

**개선 효과:**
- ✅ import.meta 접근 전 존재 확인
- ✅ Figma Make 환경에서 즉시 기본값 반환
- ✅ 상세한 경고 메시지로 디버깅 지원
- ✅ console.error → console.warn으로 변경 (더 적절함)

### 📁 2. `/main.tsx` 수정

#### ✅ 변경 1: Service Worker 등록 (라인 8-13)

**Before:**
```typescript
// Service Worker 등록 (프로덕션 환경)
if (import.meta.env.PROD) {
  registerServiceWorker();
}
```

**After:**
```typescript
// Service Worker 등록 (프로덕션 환경, Figma Make 호환)
try {
  if (typeof import.meta !== 'undefined' && import.meta.env?.PROD) {
    registerServiceWorker();
  }
} catch (error) {
  console.warn('[PWA] Service Worker 등록 실패 (환경 미지원):', error);
}
```

**개선 효과:**
- ✅ try-catch로 안전하게 감싸기
- ✅ `typeof import.meta` 체크
- ✅ Optional chaining (`?.`) 사용
- ✅ 명확한 에러 메시지

---

#### ✅ 변경 2: 네트워크 리스너 (라인 14-33)

**Before:**
```typescript
// 온라인/오프라인 상태 모니터링
setupNetworkListeners(
  () => {
    toast.success('인터넷에 연결되었습니다.', {
      description: '다시 온라인 상태입니다.',
    });
  },
  () => {
    toast.error('인터넷 연결이 끊겼습니다.', {
      description: '오프라인 모드로 전환되었습니다.',
      duration: 5000,
    });
  }
);
```

**After:**
```typescript
// 온라인/오프라인 상태 모니터링 (안전하게)
try {
  setupNetworkListeners(
    () => {
      toast.success('인터넷에 연결되었습니다.', {
        description: '다시 온라인 상태입니다.',
      });
    },
    () => {
      toast.error('인터넷 연결이 끊겼습니다.', {
        description: '오프라인 모드로 전환되었습니다.',
        duration: 5000,
      });
    }
  );
} catch (error) {
  console.warn('[PWA] 네트워크 리스너 설정 실패:', error);
}
```

**개선 효과:**
- ✅ try-catch로 안전하게 감싸기
- ✅ setupNetworkListeners 실패 시에도 앱 정상 작동
- ✅ 명확한 에러 메시지
