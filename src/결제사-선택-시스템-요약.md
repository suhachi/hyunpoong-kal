## 🔧 실제 사용 예시

### 기존 (나이스페이만)

```typescript
// pages/app/Checkout.tsx
import { requestNicePayment } from '../lib/nicepay';

const handlePayment = async () => {
  await requestNicePayment({...});
};
```

### 변경 후 (선택 가능)

```typescript
// pages/app/Checkout.tsx
import { getPaymentProvider } from '../lib/payment';

const handlePayment = async () => {
  const provider = await getPaymentProvider();
  await provider.requestPayment({...});
};
```


## 📞 계약 방법

### 나이스페이

```

2. "가맹점 문의" 클릭
```

```
5. 앱에 설정

⚡ 빠른 계약 (당일 가능)
```
